## 現在の画像方針
フィールド・歩行キャラクター・UIはレトロなドット／FC風表現を維持する。

戦闘背景・探索／イベント背景は、従来の単純なFC風から**高品質な2D JRPG／アニメ背景**方向へ変更済み。
敵が立つ中央域は描き込みを抑え、敵・文字・UIの視認性を優先する。

## NPC制作
NPC会話は、**はじまりのまちから物語順に、町・村ごとに整理して膨らませる**。
各NPCは基本2パターン程度の短い会話を持たせ、生活感・地域情報・事件・噂・攻略ヒントを分散する。
