# Monster Quest 0 Asset Library

This folder is organized for GitHub commits and future asset review.

## Structure

- `audio/music/wav/` - Audio: WAV music exports (10 files)
- `audio/music/midi/` - Audio: MIDI sources (13 files)
- `audio/packages/` - Audio: packages and archives (1 files)
- `docs/` - Project notes and readme files (9 files)
- `images/characters/sprites/` - Character sprite sheets and animation references (14 files)
- `images/characters/profiles/` - Character profile art and party illustrations (32 files)
- `images/monsters/cards/` - Monster card art (74 files)
- `images/monsters/portraits/` - Monster portraits and standalone creature art (45 files)
- `images/items-skills/cards/` - Item, spell, and skill card art (35 files)
- `images/maps/world/` - World maps and overworld references (23 files)
- `images/maps/towns/` - Town, village, harbor, and city maps (31 files)
- `images/maps/dungeons/` - Dungeons, temples, towers, ruins, castles, and forts (55 files)
- `images/maps/battle-backgrounds/` - Battle backgrounds, arenas, and encounter scenes (13 files)
- `images/maps/interiors-tilesets/` - Interior maps, tilesets, rooms, and building references (15 files)
- `images/ui/` - UI mockups and interface references (3 files)
- `images/promo/` - Promotional, cartridge, magazine, book, and key-art images (27 files)
- `images/gacha/` - Gacha machine and display references (5 files)
- `images/references/screenshots/` - Web, social, and app screenshots kept as visual references (20 files)
- `duplicates/` - Backup copies of duplicate data, grouped by original category (98 files)
- `uncategorized/images/` - Images that need human review (0 files)
- `uncategorized/incomplete-downloads/` - Incomplete browser downloads (*.crdownload) (104 files)
- `uncategorized/other/` - Other files that do not yet fit a category (0 files)

## Notes

- `manifest.csv` maps every original desktop filename to its organized path.
- `uncategorized/images/` is reserved for future files whose names and visual content are not sufficient for safe classification.
- `uncategorized/incomplete-downloads/` contains browser download leftovers and should be reviewed before committing.
- The previously uncategorized image set was visually reviewed and assigned to the categories above.
- `duplicates/` contains extra copies from duplicate groups; one canonical copy remains in its original category.
- No source files were deleted by this organizer.
