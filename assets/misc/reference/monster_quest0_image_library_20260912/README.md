# Monster Quest 0 Image Library Audit

このフォルダは、元のImageマスターを監査するための台帳置き場です。

画像・音声・資料本体は、ゲーム側の参照しやすい正式カテゴリへ割り振り済みです。

- 割り振り件数: 425
- `allocation_manifest.csv`: 元ライブラリパスと割り振り先、SHA-256の対応表
- `source_manifest.csv`: デスクトップImage全体の監査台帳
- `source_readme.md`: 元Image側の整理ルール
- デスクトップのImageマスターと`duplicates/`予備データは変更していません。
- 内容未確認の未完了ダウンロードは割り振っていません。

この監査フォルダ自体は、実装用アセットと参考資料の境界を説明するために残しています。
