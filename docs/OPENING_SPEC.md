# モンスタークエスト0 オープニング仕様

最終更新: 2026-09-12 JST

このファイルはタイトル画面から序盤の自由行動へ入るまでの正本。

## 1. 最重要方針
- **物語の始まりは、作品内でも特に密度を高くする重点区間。**
- 長い説明ムービーではなく、風景・音・短い台詞・主人公の反応・小さな操作で世界へ入らせる。
- 小学4年生でも「不思議な場所で目覚めて冒険が始まるRPG」として理解できる表層を保つ。
- 大人には主人公や世界の出自を考察できる裏構造を残す。
- プレイヤーへ直接「これはゲーム」「別バージョン」などと語りかけるメタ会話は行わない。

## 2. 主人公
- 主人公は男性。
- 本来は別のモンスタークエスト作品／別バージョン世界にいた、特別な勇者ではない**ただのNPCだった人物**。
- 世界間の異常でMQ0へ迷い込む。
- 序盤でこの事実を説明文として明かさない。
- 主人公自身も状況を完全には理解していない。
- 「選ばれし勇者」ではなく、何者でもなかった人物が一度だけ主人公になる構造を重視する。

## 3. 開始シーケンス
1. タイトル画面
2. 「はじめから」
3. **約5秒の短い制御されたバグ／異常画面**
4. 暗転または静かな切替
5. 焚き火の音・光
6. **No.01「はじまりのばしょ」夜版**で主人公が目覚める
7. 焚き火周辺を短く操作／観察
8. 少ない台詞・環境表現で違和感と世界への入口を作る
9. 昼版または次の導線
10. **No.02「はじまりのまち」**／フィールド側の通常RPG進行

正確な台詞、秒数、昼への切替条件はプレイ確認で調整する。

## 4. 開始直後の約5秒異常
旧「開始直後は異常を一切使わない」は廃止。

使用可能:
- 一瞬の画像崩れ
- 短い文字ノイズ
- 音の途切れ／ノイズ
- 別画面断片が混ざったように見える演出

禁止:
- 長時間操作不能
- 本当のフリーズ
- 実データ破損
- 開始直後の偽「ぼうけんのしょが きえました」
- 真相説明文章
- 最終戦級の大規模バグ

裏設定上、この約5秒は**主人公が元世界からMQ0へ迷い込む瞬間の断片**。
初見では説明せず、真エンディングで元世界を正常表示することで意味を回収する。

## 5. No.01「はじまりのばしょ」
- イベント専用小規模マップ。
- 正式管理番号はNo.01。
- 同一ロケーションの夜版／昼版を用意する。
- 物語開始時は夜版。
- 主人公は焚き火付近で目覚める。
- 大量NPCや広大な探索は置かない。

### 夜版の役割
- 知らない場所で目覚める
- 焚き火、夜空、風、静けさ
- 「ここにいた理由を知らない」状態を自然に見せる

### 昼版の役割
- 夜の不安から世界へ歩き出す感覚へ切り替える
- 時間経過と現実感
- No.02／通常RPG導線へつなぐ

## 6. 「始まりを濃くする」の意味
序盤を長くすることではない。

重点:
- 風景
- 焚き火
- 夜／朝
- BGMの入り方／無音
- 足音
- 少ない台詞
- 主人公の立ち止まり・視線
- 最初のNPC
- No.02へ入ったときの開放感
- 初戦闘までの緊張と安心

**プレイヤーが主人公と一緒にこの世界へ入っていく感覚**を濃くする。

## 7. No.01は終盤でも再利用する
No.01はオープニング専用の使い捨てマップではない。

オロチゾンビ1回目
→ 異常／フーフー
→ 偽リセット
→ 「もういちど」
の後、**同じNo.01「はじまりのばしょ」へ戻る**。

2回目の固定事項:
- New Gameではない。
- 主人公・タロサ・ミレイは前の出来事を覚えている。
- 初回と同じ焚き火・同じ場所を使う。
- 初回との差だけで「冒険は続いている」と理解させる。
- その後、わたべ加入／特殊参加とオロチゾンビ再戦へつながる。
- この一連は裏ワザとして扱う。

2回目の正確な配置、台詞、BGM／無音はTBD。

## 8. 世界の裏構造
- MQ0には異なる作品／バージョン由来の断片が混在する。
- 主人公も世界混線で迷い込んだ。
- 異なる世界の敵・ボスの混在、終盤の異常な強さへ意味を持たせる。
- 序盤では直接説明しない。

## 9. メタ表現のルール
禁止:
- 「プレイヤー」「ゲーム」「セーブデータ」「バージョン違い」等を登場人物が真相説明として直接口にする
- 主人公が画面外へ話しかける
- ナレーションで真相を説明する

許可:
- 世界観内では説明できない小さな違和感
- 主人公の記憶・居場所への違和感
- モンスターや伝承の食い違い
- 操作できる／できないというゲーム体験での表現

## 10. No.02「はじまりのまち」との関係
- No.01とNo.02は別マップ。
- 最初の目覚めはNo.01。
- その後、生活感のあるNo.02へつなぐ。
- 町では操作説明を詰め込まず、NPC・店・出口を通して自然に学ばせる。
- No.02内部設計データは `assets/maps/data/no02_start_town_interiors.json` を参照する。

## 11. 完成条件
- 約5秒で違和感を残せる
- 焚き火での目覚めが印象的
- 長い説明なしで「知らない世界」感が伝わる
- 早い段階で操作へ渡す
- 夜→昼→No.02の切替に意味がある
- 子どもは普通の冒険開始として楽しめる
- 大人は後で考察できる
- 本格世界崩壊を序盤で使い切らない
- 開始直後の偽セーブ消失を使わない
- 終盤No.01再訪時に、初回との対比が成立する
