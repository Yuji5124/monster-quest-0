# モンスタークエスト0 オープニング仕様

最終更新: 2026-09-11 JST

このファイルはタイトル画面から「はじまりのまち」で自由操作が始まるまでの正本。

## 1. 基本方針
- DQ1〜DQ6、モンクエ、こどもだってつらいよ等の古いRPG文化への敬意は持つが、具体的な画面・台詞・構図を直接模倣しない。
- 最初から説明しすぎず、「この世界を歩いてみたい」と思わせる。
- 作品の感情的な重点区間なので、他の通常地域より丁寧に作る。
- ただし長いムービーにはせず、早めにプレイヤー操作へ渡す。

## 2. 序盤で禁止する演出
- ゲーム開始直後のリセット演出
- ゲーム開始直後の偽「ぼうけんのしょが きえました」
- 序盤からの大規模な画面バグ
- 世界が失敗作であることの直接説明
- 最終解決方法やわたべの役割のネタバレ

リセット／偽異常は後半へ回す。旧仕様にある「起動直後の偽セーブ消失」は現行オープニングでは使用しない。

## 3. 基本シーケンス
1. タイトルロゴ表示
2. タイトルメニュー
3. 「はじめから」を選択
4. 短いオープニング導入
5. 主人公の存在と出発のきっかけを示す
6. はじまりのまちへ接続
7. プレイヤー操作開始

詳細台詞・カメラ・開始地点は `TBD`。AIが勝手に長編イベント化しない。

## 4. はじまりのまちで教えること
会話と操作で自然に以下を理解できるようにする。
- 移動
- 話す
- メニュー
- 町の外へ出られること
- 外にはモンスターがいること
- 回復・装備・所持金等の基本概念

一人のNPCに全部説明させず、生活会話へ分散する。

## 5. NPC密度
最新方針ではNPC・町サイズを従来案より約半分程度へ圧縮する。
- 人数を増やして説明量を稼がない。
- 重要NPC、生活NPC、軽いヒントNPC、変な一言NPCを少数でバランス配置する。
- タロサ等、まだ関係の薄い主要人物の話題へ過度に寄せない。

既存の「12人」等は旧設計値として扱い、最終人数はマップ縮小後に確定する。

## 6. 雰囲気
- 普通のレトロRPGとして安心して始まる。
- 少し古びた、誰も知らないゲームを見つけた感覚を大切にする。
- 序盤では不穏さを強調しすぎない。
- 後半の異常が効くよう、まず正常な世界を好きになってもらう。

## 7. 完成条件
- タイトルから操作開始までテンポが悪くない。
- 初見でも町を出る目的がわかる。
- 主要設定を説明しすぎない。
- 序盤にリセット／本格バグを使っていない。
- はじまりのまちのNPCが一つの話題へ偏っていない。
