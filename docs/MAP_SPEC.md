# Monster Quest 0 マップ仕様

更新日: 2026-09-09

## 1. 基本方針
- FC後期〜初期SFC風の見下ろし2Dマップ
- 基本タイルセットを共通利用する
- 地域固有素材は必要になった分だけ追加する
- マップを必要以上に巨大化させず、約5時間で完走できる密度を優先する
- AIで80%作り、人間が20%を視覚調整する

## 2. 制作方法
1. ChatGPTでエリアの目的・導線・イベントを整理
2. Claude Code + Phaser Game Agentでマップを実装
3. 地形、建物、Collision、Eventまで配置
4. ブラウザ上で実際に歩く
5. 人間が木、道、建物、装飾、余白を調整
6. 必要な不足タイルだけ追加する

## 3. 基本レイヤー
- Ground
- GroundDetail
- Road
- Building
- Object
- Collision
- Event
- AbovePlayer

`AbovePlayer` は木の葉、屋根、門など、主人公より前に表示する要素に使用する。

## 4. マップ品質ルール
- 道を完全な直線だけにしない
- 木、草、岩、花などに適度な変化を付ける
- 見た目のために通行ルートを狭くしすぎない
- 重要な入口・出口は視認しやすくする
- NPCやイベント地点を過密配置しない
- 画面内に適度な余白を残す
- 迷わせること自体を目的にした巨大迷路を避ける

## 5. 地域設定の方向性
### はじまりのまち
- 街道沿いの交易町
- 冒険開始地点として分かりやすい構成

### ビーエのむら
- 山に囲まれた村
- 薬草・林業の生活感を持たせる

### レインランドのまち
- 水と商業の城下町
- レインランドじょうと関係が深い

### レインランドじょう
- 王家・政治の中心
- ミレイの物語と関係する

### ザボンのむら
- タロサに関わる地域
- 狩猟文化を感じさせる

## 6. ダンジョン
- 一本道だけにしないが、無意味に広くしない
- 分岐、宝箱、近道、ギミックを適量入れる
- 地域の生態・文化・物語と関係する構造にする
- ボスまでの距離を必要以上に長くしない

## 7. Vertical Slice
最初に完成させるマップ：
- はじまりのまち
- 周辺フィールド
- 小ダンジョン
- ボスエリア

この4種が完成し、移動・会話・戦闘・セーブまで通ることを優先する。
