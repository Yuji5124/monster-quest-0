# モンスタークエスト0 特殊ゲームプレイ仕様

最終更新: 2026-09-24 JST

通常のコマンドRPGと異なる区間だけを集約する。数値、操作詳細、報酬、実装方式は、明記したもの以外TBDとし、既存ローカル実装を壊して合わせない。

## 1. No.07 まじんのどうくつ

- 主人公一人で挑む全10層のターン制Dungeon RPG。
- 4〜9Fのどこか一つだけでモンスターハウスを発生させる。
- 10Fでまじんと対峙する。まじんは通常攻撃を繰り返すだけでは勝ちにくく、特定の魔法またはアイテムを使う攻略型で、戦闘中に巨大化する。
- ヒートを有効手段にする案が最有力だが、ローカル正本で未確定のため、弱点・発動条件・数値・巨大化の詳細は**TBD**。
- 撃破後はレインランドじょうへ歩いて戻り、王へ再報告する。
- 現在の`map_08_majin_cave`／`MajinCaveScene`は旧番号由来の互換実装であり、正式表示No.07へ合わせるためだけに改名しない。

## 2. No.09 いわやまのどうくつ

- 一人では攻略不可。
- タロサが一時参加し、主人公との共闘を経て正式同行に至る。
- 縦シューティング要素を含む。「崩落から逃げるために岩を撃ち壊して進む」区間として実装した。2026-09-24に一度横スクロールで実装したが、同日ユーザー指示「横だとキャラクターが浮いて違和感。縦シューティングで戦場の狼のようなスタイルに」により、**見下ろし型の縦スクロール**へ変更した。No.20との内容差は引き続きTBD。
- タロサ正式加入の正確なイベントはTBD。

### 2.1 崩落シューティング（実装済み、`IwayamaShootingScene`）

- 見た目: 見下ろし型。洞窟の床が上から下へ流れ、タロサは上へ進みながら真上へ矢を撃つ。通路の左右は岩壁。人物・岩・敵はすべて地面に影を落とし、床の上に立って見える（横スクロール版で「浮いて見えた」点の解消）。
- 開始: 1F北東の階段手前の赤い丸（`assets/maps/iwayama_cave_1/objects.json`の`type: "shooting"`）を調べる。小さな揺れ・天井からの小石 → 「……？」「タロサ「なんだ？」」 → 強い揺れ・落石 → 暗転 → 崩落直後の約1.7秒は操作不可（後ろ＝画面の下が塞がる） → スクロール開始。
- 操作: タロサ（弓）を操作し、主人公は後ろをついて走る（見た目だけ）。PC=矢印で8方向に移動、Z/Enter長押しで真上へ矢を連射（150ms間隔）、X/Esc長押しでダッシュ。タッチ端末=左下の仮想スティック、右側の長押しで矢、「ダッシュ」ボタン。
- 区間: A小岩 / B小岩+中岩 / C敵+岩 / D爆発岩 / E爆発岩の連鎖 / F崩落激化（落石・揺れ・小石） / G巨大岩壁。各区間の頭がチェックポイント。全体で約2分。
- 岩: 小岩HP1、中岩HP3（被弾で揺れる）、大岩HP6。左右の壁から壁まで横一列に並んだ岩の壁は、撃って穴を開けないと通れない。
- 爆発岩: 暗く、赤〜橙の亀裂が光る。矢1本で爆発し、半径150px内の岩・敵へ10ダメージ（地面に焦げ跡）。範囲内の爆発岩へ150ms遅れで着火して連鎖する。
- 敵: こあくま・エリマキヘビ・ダイジャ（既存の戦闘用画像）。直進・左右に揺れる・突進・岩陰から飛び出す、の単純な動きのみ。小さく跳ねながら進む。HP2。
- 落石（Section F）: 地面に影が広がる予兆 → 天井から落ちてくる → 着地で砕ける。着地の瞬間に影の上にいるとダメージ。空中の落石は矢では壊せない。
- 巨大岩壁: 画面の上を横切って道を塞ぐ。HPバーなし。48発で崩れ、ヒビ→大きな亀裂（奥の光が漏れる）→中心部崩壊→崩落の段階で見せる。崩落は大爆発ではなく岩片が左右へ崩れ落ち、向こうに明るい空間が見える。主人公たちが崩れた穴を上へ抜けて暗転。
- 失敗: 岩・敵・落石に触れると耐久（♥5、イベント専用、通常HPに影響しない）が減る。0で約0.3秒暗転し、その区間の頭から即再挑戦。
- 終了: `event.iwayama_cave_shooting_cleared`を保存し、赤い丸のあった場所（spawn `afterShooting`）へ戻る。シューティングの説明はせず「…………」だけを表示。クリア後は赤い丸が消え、再プレイしない（初回のみの強制イベント）。
- 数値は`src/config/iwayamaShooting.ts`（TEMP_TEST_VALUE）。見た目はCanvasで描いた仮素材（`src/systems/IwayamaShootingTextures.ts`）。SE・BGMは音声未実装のためTBD。
- DEV: `?mapTest=iwayama-shooting`、区間指定`&shootingSection=rocks|medium|enemies|explosion|chain|collapse|wall`（またはa〜g）。

## 6. 「もういちど」

- 裏ボス1回目は通常Game Overにしない。UI、BGM、文字、背景、攻撃処理の制御された異常から、フーフー、タイトル、「もういちど」へ進む。
- 「もういちど」はNew Gameではない。実セーブとジャンカード取得状態を保持して同じNo.01へ戻る。
- 主人公・タロサ・ミレイは記憶を保持し、わたべが通常の4人目ではない特殊参加として加わる。
- わたべの「とくだいヒット」が再戦の突破口。倍率・演出・勝敗条件はTBD。

## 7. 実装上の禁止

- 特殊区間を通常戦闘や通常Game Overで代替して物語導線を失わせない。
- 内部互換IDを番号変更だけで一括改名しない。
- TBDの攻略手段・数値・報酬・真相を推測で固定しない。
