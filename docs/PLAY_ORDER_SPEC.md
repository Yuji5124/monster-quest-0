# モンスタークエスト0 物語上のプレイ順仕様

最終更新: 2026-09-21 JST

このファイルは、Monster Quest 0の**物語上のプレイ順**を整理する正本である。

重要:
- 既存のNo.01〜No.20は、コード・旧資料・アセット参照のための**互換番号**であり、物語上の順番を意味しない。
- 新しい森・村・特殊区間が追加されているため、最終的なマップ番号はまだ決めない。
- 当面は「どの順番で遊ぶか」だけを一本化する。
- プレイ順と互換番号が食い違う場合は、**本書のプレイ順を物語進行の正**とする。
- 各地点で何が起きるか、誰が加入するか、何を入手するか等は、ユーザー確定がない限りTBDとする。

## 2. 基本進行ループ

本編の主な進み方は次を基本形とする。

**拠点（まち／むら）**
→ **NPC会話・事件・ストーリーイベント**
→ **ワールドマップ上に森・フィールド探索地・ダンジョン等が開放**
→ **探索／戦闘／特殊ゲームプレイ**
→ **目的達成・ボス撃破・事件解決**
→ **次の拠点が開く**
→ 次のイベントへ

重要:
- 広大なワールドマップを徒歩で横断する方式ではない。
- 地域間移動はポイント選択式ワールドマップを基本とする。
- 「町で話を聞く → 目的地が開く → 現地へ行く」をプレイヤーが理解しやすい基本リズムにする。
- 毎回まったく同じ手順にはせず、重要場面・特殊区間では崩してよい。
- 解放条件の具体的なNPC、会話、フラグ、アイテムはストーリー確定時に決める。

## 3. 前半〜中盤終了までの骨格

### P01 はじまりのばしょ
- 冒頭専用。
- 主人公1人。
- 焚き火、環境音、短いナレーションから操作開始。
- ここで大きなストーリー説明はしない。

### P02 はじまりのまち
- 最初の通常拠点。
- 町のイベントを通じ、次の探索先へ向かう理由を作る。
- **はじまりのもり**が次のプレイ地点。

### P03 はじまりのもり
- 初期の探索・通常戦闘を覚える地域。
- 一本道寄りの構成を基本とする。
- クリア後は**ビーエのむら**へ進む。

### P04 ビーエのむら
- 村イベントを行う。
- 通常景観とバグ景観が混在する最初期の異常地域。
- 事件の具体的内容・クリア条件はTBD。
- 次は**レインランドのもり**。

### P05 レインランドのもり
- レインランド方面へ向かう屋外探索。
- モンスター戦と地域の雰囲気を見せる。
- 具体的なイベント内容はTBD。
- 次は**レインランドじょうかまち**。

### P06 レインランドじょうかまち
- 前半の主要拠点。
- 町内イベントを経て、フィールド側の次の重要ダンジョンを開放する流れを基本とする。
- 王家・ミレイ・城との関係をどこまでここで扱うかはTBD。
- **レインランドじょう**をこの区間で訪れるか、別プレイ地点として分離するかはTBD。
- 次の確定地点は**まじんのどうくつ**。

### P07 まじんのどうくつ
- **中盤終了地点。**
- 主人公は**1人で挑む**。
- 同行者がいる場合でも、このダンジョンへ入る時点では主人公単独パーティにする。
- なぜ1人で挑むのか、その物語上の理由はTBD。
- ダンジョンはターン制ダンジョンRPG方式。
- 最奥でまじん戦。
- まじん撃破後を「前半〜中盤前半の一区切り」とし、次の展開へ移る。

## 8. AI・実装時のルール

- **旧No.順をストーリー順として使用しない。**
- ストーリー進行を実装する際は、まず本書のP順を参照する。
- 互換No.は既存ファイルやコードを特定するためだけに使用する。
- 未確定区間をAIが勝手につないでストーリーを作らない。
- P01〜P09の順番を変更する場合は、ユーザーの新しい明示指示を必要とする。
- 新マップ追加時は、まずP順上の位置を決め、その後に最終mapId／番号を整理する。
