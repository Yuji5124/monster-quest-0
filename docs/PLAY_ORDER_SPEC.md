## 1. 目的と優先順位

この文書は、2026-09-22時点の**正式な物語順・表示名・No.**を一枚で管理する正本。`STORY_FLOW.md`、`MAP_FLOW_SPEC.md`、`GAME_SPEC.md`の旧順序と衝突する記述は、この文書を優先し `SUPERSEDED` と扱う。

デスクトップ上で既に動作している`mapId`、Scene名、保存フラグ、アセットパスは互換IDであり、番号・表示名の更新だけを理由に改名しない。

## 3. 進行上の固定事項

- No.02で「最近モンスターが増えている」「レインランド王が情報を集めている」を知り、主人公は自分の意思でレインランドへ報告に向かう。
- No.03〜05の異変をNo.06の王へ報告し、No.07を調査する。No.07後にも王へ再報告する。
- タロサはNo.09で一時参加して共闘後に正式同行。ミレイはNo.10で出会い、No.11で正式同行する。
- No.20の裏ボス1回目は通常Game Overでなく、「もういちど」→No.01再訪→わたべ特殊参加→再戦へつながる。
- No.18は「自分たちは何者か」、No.20のオロチまおう直前は「これからどう生きるか」を扱い、同じ記憶・正体会話を繰り返さない。後者で焚き火・最後の野営は使用しない。
- 真の決着後、NPCと仲間の言葉を経て`ここに のこる`／`もとの せかいへ かえる`を選ぶ。レイはどちらの未来にも生まれる。詳細は`STORY_FLOW.md` §10を正とする。
- ジャンカードは全45枚・1回20円・固定順・ダブりなしの独立サブゲーム。本編序盤から秘密、頭文字、たびのあいことばを示唆しない。

## 4. 明示的に旧仕様へ降格する名称・順序

- 「はじまりのもり」は表示名として**ビーエのもり**へ変更する。既存`starting_forest`などの内部IDは残す。
- 「レインランドのむら」は現行メインストーリー順から外す。資料・互換データに残る場合は`legacy / out-of-main-flow`と明記する。
- 「いしのむら」は表示名として**いしのまち**へ変更し、正式No.18とする。内部IDの改名はしない。
- 旧「No.03ビーエのむら」「No.04レインランドのまち」「No.05レインランドじょう」「No.08まじんのどうくつ」等の番号対応は、既存実装・履歴を読むための互換情報であり、今後の物語順に使わない。
