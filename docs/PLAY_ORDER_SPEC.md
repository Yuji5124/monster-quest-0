# モンスタークエスト0 物語上のプレイ順仕様

最終更新: 2026-09-22 JST

このファイルは、Monster Quest 0の**物語上のプレイ順と、各地点へ向かう物語上の理由**を整理する正本である。

重要:
- 既存のNo.01〜No.20は、コード・旧資料・アセット参照のための**互換番号**であり、物語上の順番を意味しない。
- 新しい森・村・特殊区間が追加されているため、最終的なマップ番号はまだ決めない。
- 当面は「どの順番で遊ぶか」と「なぜ次の場所へ行くのか」を一本化する。
- プレイ順と互換番号が食い違う場合は、**本書のプレイ順を物語進行の正**とする。

## 1. 序盤の大目的

主人公は序盤から「世界を救う使命」を与えられるわけではない。

最初の目的は、
1. 自分がいる世界・土地について知る。
2. 道中で目にしたモンスター増加や異変について情報を集める。
3. **レインランドへ向かい、王へ自分の旅の内容と道中で見た異変を報告する。**
4. 王都で各地のモンスター情報を集め、次に何を調べるべきか判断する。

レインランド王は、最近各地で増えているモンスターについて、兵士だけでなく旅人・商人・村人からも情報を集めている。
主人公は「選ばれた勇者だから呼ばれる」のではなく、実際に危険な道を歩いてきた旅人として報告する。

このため序盤の各地域で起きる事件や戦闘は、すべて後の王への報告内容になる。

## 3. 序盤の移動理由

### P01 はじまりのばしょ → P02 はじまりのまち
主人公は知らない場所で目覚める。
自分がどこにいるのか分からないため、焚き火跡から道をたどり、最初に見える人里である「はじまりのまち」を目指す。

この時点の目的は非常に単純でよい。

**「ここがどこなのか知りたい。」**

### P02 はじまりのまち → P03 はじまりのもり
町で、
- この地方がレインランドの勢力圏にあること
- 最近モンスターが増えていること
- レインランド王が各地からモンスター情報を集めていること
を知る。

主人公自身も旅の途中でモンスターや不可解な状況を目にしているため、レインランドへ向かうことを決める。

ただし王都へ直接行けるわけではない。
最初の街道は「はじまりのもり」を抜け、ビーエのむらへ続いている。

**目的: レインランドへ向かうため、まずビーエまでの森を越える。**

### P03 はじまりのもり → P04 ビーエのむら
森では序盤の通常戦闘を経験する。
以前よりモンスターが増えていることを、説明ではなく実際の戦闘で見せる。

森を抜けた先の中継地がビーエのむら。

主人公は、
- 休息
- 王都までの道を聞く
- 周辺のモンスター情報を集める
ためにビーエへ入る。

### P04 ビーエのむら → P05 レインランドのもり
ビーエでは山の暮らしとともに、木こり事件など地域の問題へ巻き込まれる。

事件を解決する中で、
- 山や森のモンスターまで人里へ近づいている
- 以前は見なかった種類が出ている
- 景色そのものに小さな違和感がある
等を主人公が目撃する。

村人から、王都へ続く道は「レインランドのもり」を通ると教わる。

主人公は、
**ビーエで見たことも王へ報告しよう**
と考え、旅を続ける。

### P05 レインランドのもり → P06 レインランドじょうかまち
王都直前の森。

ここでは「はじまりのもり」より明らかに危険度を上げる。
主人公がレインランドへ近づくほど、モンスターの異常が局地的なものではないと分かっていく。

森を抜けると、レインランドじょうかまちと城が見える。

**序盤の最初の目標達成地点。**

### P06 レインランドじょうかまち → レインランドじょう
城下町ではまず自由に情報収集する。

旅人、商人、兵士などから、
- 他の地域でもモンスターが増えている
- 街道が危険になっている
- 城も情報を集めている
ことを確認する。

その後、レインランドじょうへ入る。

主人公は王に、
- はじまりのばしょで目覚めてからの旅
- はじまりのもりのモンスター
- ビーエの事件
- レインランドのもりで見た異変
を報告する。

王側も各地から同様の報告が上がっていることを伝える。

ここで初めて、
**主人公個人の旅が、レインランド全体の異変調査につながる。**

### レインランドじょう → P07 まじんのどうくつ
集まった情報の中で、とくに危険な地点として「まじんのどうくつ」が挙がる。

洞窟付近では、
- モンスターの活動が急増している
- 入った者がまともに奥まで進めない
- 内部の構造がおかしいという報告がある

王は主人公に「世界を救え」と命令するのではなく、
**実際に異常な道を越えて王都まで来た旅人として、洞窟を調べてほしい**
と依頼する。

主人公は情報を得るために始めた旅から、
初めて自分の意志で危険な調査を引き受ける。

ここが「ただの旅人」から「勇者と呼ばれる人物」へ変わり始める最初の節目。

## 4. P07 まじんのどうくつ

- 中盤終了地点。
- 全10層のターン制ダンジョンRPG。
- 主人公は1人で挑む。
- 同行者がいる場合も、洞窟の異常によって主人公だけが内部へ取り込まれる構成を使用できる。
- 最奥でまじん戦。
- まじんは戦闘中に段階的に巨大化する。
- 特定の魔法／アイテムを利用しない力押しでは実質勝ちにくい設計とする。
- まじん撃破後、同じ階層状態を保ったまま1Fまで帰還する。
- 洞窟を出た時点で前半〜中盤の一区切りとする。

## 5. 中盤後

### まじんのどうくつ → レインランドじょう再報告 → P08 レインランドのむら
まじん撃破後、主人公は一度レインランドじょうへ戻り、王に洞窟内部の異常とまじんについて報告する。

その時、王側にも新しい報告が届いている。
城下町ではなく地方の「レインランドのむら」周辺で、
- モンスターが人里近くまで出る
- 見慣れない獣の足跡が続く
- 村からの連絡が減っている
等の異変が起きている。

主人公は、まじんだけを倒して終わりではないことを知り、次の調査地としてレインランドのむらへ向かう。

### P08 レインランドのむら → P09 ザボンのむら
村で事件を解決しながら情報を集める。

ここで、
**「ザボンの狩人が、この辺りでは見ないモンスターの足跡を追っていた」**
という証言を得る。

その狩人たちはザボン方面へ戻った、あるいはその先を調べていると分かる。

主人公は、
**モンスターがどこから来ているのかを追うため**
ザボンのむらへ向かう。

### P09 ザボンのむら → P10 いしのむら
ザボンは狩りの村。
ここでタロサの過去・強さへの考え方を見せる。

村の狩人たちは最近、
**本来ザボン周辺にいないモンスターが岩山側から流れてくる**
ことに気づいている。

足跡、傷ついた獣、逃げてきたモンスターなどから、
「何かに追われて山から下りてきている」
と分かる。

次の調査先は、岩山に近い**いしのむら**。

### P10 いしのむら → P11 いわやまのどうくつ
いしのむらでは、
- 地鳴り
- 落石
- 岩山から下りてくるモンスター
- 採掘路／山道の閉鎖
などが起きている。

村人から、
異変が強くなったのは**いわやまのどうくつ**の奥で何かが起きてからだと聞く。

主人公たちは原因調査のため洞窟へ。

### P11 いわやまのどうくつ → P12 かくれざと
洞窟の奥で、単なる自然災害ではない痕跡を見つける。

さらに古い道標・記録などから、
この地域の古い異変やデーマスについて知る者が、
人目を避けて暮らす**かくれざと**にいる可能性が出る。

主人公たちは答えを求めて、かくれざとを探す。

### P12 かくれざと → P13 みずうみの古城
かくれざとの住民は外部の人間を簡単には信用しない。

しかし主人公たちが、
まじん、岩山の異変、各地のモンスター増加について具体的に話すことで、ようやく情報を得る。

ここで初めて、
**デーマスの塔へ入るには「ゆうしゃのけん／ゆうしゃのかんむり／ゆうしゃのたて」が必要**
という古い伝承を知る。

最初の手掛かりが、**みずうみの古城**。

### P13 みずうみの古城 → P14 港町ダコハ
古城で勇者装備の一つと、残りの装備が各地へ持ち出された記録を得る。

記録の最後に残るのが交易地**港町ダコハ**。

主人公たちは、
**残る勇者装備の行方を知る人・記録を探すため**
ダコハへ向かう。

### P14 港町ダコハ → P15 コタンカイムの洞窟
ダコハは人と物と噂が集まる情報拠点。

古い商人記録や旅人の話から、
勇者装備を運んでいた一行が**コタンカイムの洞窟**付近で消息を絶ったと分かる。

主人公たちは装備の行方と異変を確かめるため洞窟へ。

### P15 コタンカイムの洞窟 → P16 ポサロ城
洞窟では勇者装備に関する次の手掛かりを得る。

さらに、最後の装備またはその保管記録が**ポサロ城**へ渡ったことが判明する。

ここから物語は、
「各地の異変調査」から
**「デーマスへたどり着くための準備」**
へ明確に切り替わる。

### P16 ポサロ城 → P17 ふっかつのほこら
ポサロ城で勇者装備がそろう。

ここには**バクラー**を中〜終盤ボスとして配置できる。
バクラーの具体的な役割・攻略ギミックは別SPECを正とする。

装備をそろえただけではデーマスへ勝てない。

城に残る記録等から、
古い戦いで「強大な魔法を返した力」が**ふっかつのほこら**に関係していたことが分かる。

主人公たちは、デーマス戦への最後の備えとしてほこらへ向かう。

### P17 ふっかつのほこら → P18 デーマスの塔
ほこらでは、
- 復活
- いのちのかがみ
- ミラー／反射
に関係する手掛かりを扱う。

ただし、
**「デーマスにはミラーを使え」**
とは直接教えない。

勇者装備がそろい、反射に関する知識／力を得たことで、
ようやく**デーマスの塔**へ進める。

### P18 デーマスの塔 → P19 ぬまちのどうくつ
デーマス戦では、ダイダインをミラーで返す攻略を核にする。

デーマス撃破後、塔の記録・地図・敵側の連絡などから、
モンスターの流れがさらに奥の勢力へつながっていることが判明する。

そのルートが**ぬまちのどうくつ**。

主人公たちは、
「デーマスを倒せば終わり」ではなかったことを知る。

### P19 ぬまちのどうくつ → P20 バトラスのとりで
ぬまちのどうくつは多数の小型敵を倒して進むアクション区間。

洞窟を抜けると、
終盤の進路を塞ぐ**バトラスのとりで**へ出る。

ここで、
**オロチ側へ進む道をバトラスが押さえている**
ことが分かる。

### P20 バトラスのとりで → P21 オロチのしろ
バトラスは正面から削るだけでは厳しい。

**毒が攻略の鍵。**

タロサの弓／武器アクションによる毒付与を大きな見せ場にする。

バトラス撃破によって、
閉ざされていた道・情報・鍵等が開き、
**オロチのしろ**への進路が確定する。

ここからは寄り道より「最後へ向かう」緊張感を優先する。

### P21 オロチのしろ → P22 最終地点
オロチのしろは王道RPGとしての総決算。

特定の一つの正解ではなく、
装備、魔法、回復、タロサの武器、ミレイの魔法、主人公の判断を全部使って
**オロチまおう**を倒す。

その後、
通常の魔王撃破では説明できない異常が残り、
裏ボス領域である**最終地点（内部名: オロチゾンビのま）**へつながる。

ここから先は、
オロチゾンビ1回目
→ 異常／フーフー
→ 「もういちど」
→ No.01再訪
→ わたべ特殊参加
→ 再戦
の終盤固定骨格へ接続する。

## 6. 基本進行ループ

**拠点**
→ NPC・事件・次の目的
→ ワールドマップに探索地が開く
→ 探索・戦闘
→ 得た情報や事件解決が次の移動理由になる
→ 次の拠点

「町に着いたから次の町へ行く」のではなく、必ず
**情報・事件・人物・依頼のどれかが次の移動理由になる**
ようにする。

## 7. P10以降の正式プレイ順
今回のストーリー接続により、以下を物語上の基本順として採用する。

P10 いしのむら
→ P11 いわやまのどうくつ
→ P12 かくれざと
→ P13 みずうみの古城
→ P14 港町ダコハ
→ P15 コタンカイムの洞窟
→ P16 ポサロ城
→ P17 ふっかつのほこら
→ P18 デーマスの塔
→ P19 ぬまちのどうくつ
→ P20 バトラスのとりで
→ P21 オロチのしろ
→ P22 最終地点

補足:
- レインランドじょうはP06で初訪問し、まじん撃破後など必要に応じて報告拠点として再訪する。
- ブロック／ボクセル城、横アクション、縦アクション、シューティング等の特殊方式をどの地点へ追加するかは別途確定する。
- マップの互換No.とP番号を混同しない。

## 8. AI・実装時のルール
- 旧No.順を物語順として使用しない。
- P01〜P22の物語順は本書を優先する。
- レインランドへ向かう序盤の目的を「王への旅の報告＋モンスター情報収集」とする。
- 主人公を序盤から「世界を救う使命を持つ選ばれた勇者」にしない。
- 各地域間に移動理由を置き、前地域で得た情報・事件・依頼が次の目的地につながるようにする。
- ジャンカードの秘密をこの本編導線へ組み込まない。
