# モンスタークエスト0 未確定事項レジストリ

最終更新: 2026-09-10 23:46 JST

## 1. 目的
AIが未確定事項を勝手に決める事故を防ぐ。

## 2. ルール
- この一覧にある項目は、仕様上必要でもAIが独断で確定しない
- 実装を進めるため仮値が必要な場合は `TBD` / `null` / placeholder と明示する
- 確定したら該当SPECと `PROJECT_STATUS.md` を更新し、この一覧から削除または確定済みへ移す

## 3. 現在TBDとして扱うもの
### バランス数値
- 多くの通常敵の最終HP / MP / 攻撃 / 防御 / 素早さ / EXP / G
- 各魔法の最終MP消費 / 威力 / 成功率
- 各アイテムの最終価格 / 効果量
- レベルアップ曲線の最終値

原作・カード資料で確認済みの数値がある場合はそちらを優先し、AI案で上書きしない。

### マップ実装値
- 各マップの最終タイル数
- 実装時の正式タイルサイズ
- 各NPC / 宝箱 / 出入口の最終座標

正式素材と実画面を確認後に決める。

### 演出
- 各戦闘背景の最終採用案
- 各BGMのA案 / B案の最終採用
- 魔法エフェクトの最終尺
- 終盤異常演出の細かな秒数

### コンテンツ
- 25体モンスターの未確定枠の最終並び
- 45枚ジャンカードの未確定番号 / 表示内容
- NPC会話の未作成地域の本文

## 4. AIが確定してよいもの
既存SPEC・PROJECT_STATUS・ユーザー指示で明確に確定済みのものだけ。
例:
- 約5時間
- 主要パーティ3人
- モンスター25体
- ジャンカード45枚
- 1回20円 / 固定順 / ダブりなし
- Phaser 3 / Phaser Game Agent中心
- ASRS不使用
- 「たびのあいことば」名称

## 5. 仮値の書き方
悪い例:
`hp: 120` ← 根拠なく確定値のように置く

良い例:
`hp: null // TBD: balance pass`

テストのため一時値を使う場合:
`hp: 120 // TEMP_TEST_VALUE - not final`

## 6. 判断
迷ったら、勝手に決めるより未確定として残す。
ただし、未確定項目と無関係な実装は止めずに進める。
