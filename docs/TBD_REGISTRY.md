# モンスタークエスト0 未確定事項レジストリ

最終更新: 2026-09-11 JST

## 1. 目的
AIが未確定事項を勝手に決める事故を防ぐ。

## 2. ルール
- この一覧にある項目は、仕様上必要でもAIが独断で確定しない
- 実装を進めるため仮値が必要な場合は `TBD` / `null` / placeholder と明示する
- 確定したら該当SPECと `PROJECT_STATUS.md` を更新し、この一覧から削除または確定済みへ移す
- 原作 / カード資料の確認値と、Monster Quest 0の最終ゲーム値を混同しない

## 3. 現在TBDとして扱うもの
### ストーリー / 進行
- オープニングの詳細台詞・開始位置・演出尺
- 中盤の各地域をつなぐ正確な一本道順
- ポサロ城の本線上の正確な位置
- コタンカイムの洞窟の本線上の正確な位置
- タロサ加入の正確なタイミング / 条件 / 台詞
- ミレイ加入の正確なタイミング / 条件 / 台詞
- ふっかつのほこらの詳細役割 / 条件
- 最終解決の具体的入力内容 / 公開しない秘密情報

### NPC / 町サイズ
- はじまりのまちの最終NPC人数

- レインランドのまちの最終NPC人数

- 各町・村の最終マップ規模

最新方針は「旧案より全体的に約半分程度へ圧縮」。旧12人 / 15人 / 20人は最終実装人数ではない。

### バランス数値
- 多くの通常敵の最終HP / MP / 攻撃 / 防御 / 素早さ / EXP / G

- 行動順 / 命中 / 回避 / ダメージ計算の最終式

原作・カード資料で確認済みの数値がある場合は `sourceReference` として保持できるが、MQ0最終値へ自動採用しない。

### キャラクター成長
- 主人公・タロサ・ミレイの最終成長率
- 各キャラクターの加入レベル
- エレキテル以外の魔法の正式な習得キャラクター
- 各魔法の正式習得レベル
- 各キャラクターの最終装備可能範囲

デーマス区間Lv15程度、最終地点Lv20前後は目安であり最終固定値ではない。

### モンスター
- 25体の未確定枠の最終名称 / 並び
- 各通常敵の最終出現地域 / 出現率
- ドロップ品
- 未確定敵AI

### マップ実装値
- 各マップの最終タイル数
- 実装時の正式タイルサイズ
- 各NPC / 宝箱 / 出入口の最終座標
- 各マップの推奨レベル帯の最終値
- 細かなマップ接続

正式素材と実画面を確認後に決める。

### UI / 入力
- 最終内部解像度
- 縦持ち / 横持ちの正式対応方針
- iPhone用仮想十字キー / ボタンの最終配置
- メニューの最終階層

### 演出 / 音
- 各戦闘背景の最終採用案

- 終盤異常演出の細かな秒数
- 後半で偽セーブ消失表現を再利用するかどうか

重要: 序盤 / 起動直後に偽セーブ消失を置かないことは確定済みでありTBDではない。

### ジャンカード
- 45枚の未確定番号 / 表示内容
- 公開用のネタバレ表示方法の最終調整

固定事項は、全45枚 / 1回20円 / No.01→45固定順 / ランダムではない / ダブりなし / 本編必須ではない。

## 4. AIが確定してよいもの
既存SPEC・PROJECT_STATUS・ユーザー指示で明確に確定済みのものだけ。
例:
- 約5時間
- 主要パーティ3人
- モンスター25体
- ジャンカード45枚
- 1回20円 / 固定順 / ダブりなし
- Phaser 3 / Phaser Game Agent中心
- Claude Codeメイン実装 / Codexレビュー・QA
- ASRS不使用
- 「たびのあいことば」名称
- 町 / NPCを旧案より約半分程度へ圧縮する方針
- 序盤にリセット / 偽セーブ消失を使わない方針
- 「だいヒット」「とくだいヒット」名称
- デスタロッサをMQ0へ登場させない方針

## 5. 仮値の書き方
悪い例:
`hp: 120` ← 根拠なく確定値のように置く

良い例:
`hp: null // TBD: balance pass`

テストのため一時値を使う場合:
`hp: 120 // TEMP_TEST_VALUE - not final`

原作資料の参考値:
`sourceReference: { "hp": 1000 } // source material only; not MQ0 balance`

## 6. 判断
迷ったら、勝手に決めるより未確定として残す。
ただし、未確定項目と無関係な実装は止めずに進める。
