# Monster Quest 0 未確定事項レジストリ

更新日: 2026-09-09

このファイルは「AIが勝手に決めてはいけない未確定事項」を明示するための一覧。
確定した項目は専門仕様書と `DECISIONS.md` へ反映し、この一覧から外す。

## 1. ルール
- `TBD` は自由裁量ではない
- 実装上の仮値が必要な場合は `TEMP` と明示する
- TEMP値を正式仕様としてドキュメントへ昇格させない
- ユーザー決定・原作確認・正式資料確認後にCONFIRMEDへ移す

## 2. 戦闘数値
以下は完全表が確定するまで推測禁止：
- 25体すべてのHP / MP / 攻撃 / 防御 / 素早さ
- 全モンスターのEXP / Gold
- 全魔法の消費MP / 威力
- 全アイテムの回復量 / 価格 / 売値
- 全装備の性能
- 完全なレベルアップ曲線

原作・カード資料で確認済みの値がある場合はその値を優先し、確認済み箇所だけ専門仕様へ反映する。

## 3. 魔法習得
- 各キャラクターが何レベルで各魔法を覚えるかの完全表
- 一部魔法の最終的な対象範囲 / 消費MP / 威力

## 4. マップ
- 全マップの最終サイズ
- 全ダンジョンの完全一覧
- 全マップの接続座標
- 全宝箱位置
- 全NPC座標
- 各地域の最終エンカウント率

存在が確認済みの地域名と、詳細設計の確定を混同しない。

## 5. ストーリー
公開リポジトリでは、未確定かどうかに関係なく重大な終盤秘密を記載しない。

公開仕様で詳細未記載の終盤イベントについて、AIが勝手に真相・理由・台詞を作らない。

## 6. ジャンカード
- 全45枚の完全公開用一覧がGitHubへ反映済みかは要確認
- 各カードの最終ゲーム内説明文
- 公開時に伏せるカードの内部情報

総数45枚、1回20円、固定順、重複なしは確定。

## 7. 音声
- 8曲の最終採用版（A案 / B案の選択が残る場合）
- 各マップへの最終BGM割当
- 全SEの最終ファイル

実ファイルを確認してから採用状態を更新する。

## 8. 画像
制作済み5基本セットの実ファイル名 / GitHub上の最終配置パスは、リポジトリへ配置された時点で確定する。

戦闘背景・地域固有素材は必要箇所から追加する。

## 9. 技術
Phaser Game Agentが生成する初期構造を確認する前に、
- package構成
- TypeScript / JavaScriptの最終選択
- bundler構成
- asset loaderの具体方式
をドキュメントだけで無理に固定しない。

ただし責務分離は `PHASER_ARCHITECTURE.md` に従う。

## 10. 更新方法
確定したら：
1. 該当専門仕様書を更新
2. 必要なら `DECISIONS.md` へ追記
3. `CONTENT_MATRIX.md` の状態更新
4. このファイルから該当TBDを削除または確定済みと明記

## 11. AIへの最重要ルール
この一覧にある空白を「それっぽいRPGの常識」で埋めない。
Monster Quest 0の確定情報と、AIが考えた案を混ぜない。
