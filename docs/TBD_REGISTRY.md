## 1. 目的

## 2. ルール
- この一覧にある項目はAIが独断で確定しない。
- 仮値が必要な場合は `TBD` / `null` / placeholder と明示する。
- 確定したら該当SPECと `PROJECT_STATUS.md` を同期する。
- 原作 / カード資料の確認値とMQ0最終ゲーム値を混同しない。

### 真のエンディング
確定済み:
- 真の最終解決後、主人公の未来は選択式。
- 選択肢は「ここに のこる」／「もとの せかいへ かえる」。
- 「ここに のこる」: MQ0世界に残り、ミレイとレインランドへ戻る。後に娘レイが生まれ、ミレイは出産時に亡くなる。主人公がレイを育てる。
- 「もとの せかいへ かえる」: わたべと帰還し、本来のNPCへ戻る。冒険の記憶は残り、操作不能になることで元NPCだったことを示す。
- タロサはMQ0本編中にはデスタロッサにならないが、MQ0後に「限界をなくす力」への誘いを経て、やがてデスタロッサへ至る未来を持つ。
- ミレイはレインランドの姫／魔法使い。旅への願いから本来の役割を外れ、未来の断片を感じる。残留ルートではレイの母となる。
- わたべは「もういちど」後の特殊参加キャラクターで、真の解決後は現実世界側へ帰還する。
