# モンスタークエスト0 未確定事項レジストリ

最終更新: 2026-09-18 JST

## 1. 目的
AIが未確定事項を勝手に決める事故を防ぐ。

## 2. ルール
- この一覧にある項目はAIが独断で確定しない。
- 仮値が必要な場合は `TBD` / `null` / placeholder と明示する。
- 確定したら該当SPECと `PROJECT_STATUS.md` を同期する。
- 原作 / カード資料の確認値とMQ0最終ゲーム値を混同しない。

## 4. AIが確定してよいもの
既存SPEC・PROJECT_STATUS・ユーザー指示で明確に確定済みのものだけ。
例:
- 初見約4時間30分 / 寄り道込み約5時間30分
- 全体ワールドマップ・主要地域配置を維持
- 正式マップ番号No.01〜No.20
- 主人公は男性 / 元NPC / 別世界由来
- 暗闇→No.01夜の焚き火→ナレーション→操作解放
- 主要パーティ3人
- モンスター25体
- オロチゾンビは裏ボス
- 「もういちど」→わたべ→再戦は裏ワザ
- ジャンカード45枚 / 1回ジャンコイン1枚 / 固定順 / ダブりなし
- Phaser 3 / Phaser Game Agent中心
- ASRS不使用
- 「たびのあいことば」名称
- 「だいヒット」「とくだいヒット」名称
- デスタロッサをMQ0へ登場させない

## 5. 仮値の書き方
悪い例:
`hp: 120`

良い例:
`hp: null // TBD: balance pass`

テスト値:
`hp: 120 // TEMP_TEST_VALUE - not final`

原作資料参考値:
`sourceReference: { "hp": 1000 } // source material only; not MQ0 balance`
