# Monster Quest 0 決定事項

更新日: 2026-09-09

このファイルは、過去仕様と現在仕様が食い違った場合の最優先資料とする。

## プロジェクト
- 正式タイトル：Monster Quest 0 ～幻の冒険の書～
- 「誰も知らないゲーム、やってみる？」は広告・紹介用コピーであり、サブタイトルではない
- 想定プレイ時間：約5時間

## 開発
- ゲームエンジン：Phaser
- Phaser Game Agentを基本制作基盤として使用する
- Claude Codeをメイン実装担当とする
- Codexはレビュー・デバッグ・難所対応を担当する
- ChatGPTは仕様整理・画像制作・プロンプト設計・ドキュメント更新を担当する
- Astraは基本システム完成後の量産フェーズで必要に応じて使用する
- ASRSは使用しない
- 独自RPGエンジンを作らない
- 独自マップエディタを作らない
- AI 80% / 人間による視覚調整20%を基本制作比率とする

## パーティ
- 主要パーティは主人公・タロサ・ミレイ
- タロサとミレイは途中加入
- ミレイはレインランドの姫であることを隠して旅に加わる

## キャラクターデザイン
- 主人公：金髪、青いヘッドバンド、額の赤い宝石、赤いマント / スカーフ、剣、金色系装備を基準とする
- タロサ：青い逆立った髪、尖った耳、弓、緑の腰布を基準とする
- 主要キャラクターは正式デザインを勝手に変更しない

## モンスター
- モンスター総数：25体
- 公開時にネタバレとなる終盤モンスターは「？？？」等で伏せる
- 原作・カード資料で確認済みのデザインや数値は、未確認のAI案より優先する

## ジャンカード
- 全45枚
- 本編攻略必須ではない独立したサブゲーム
- 公開時にネタバレとなるカード名は「？？？」表記を使用する

## 魔法・アイテム
- こどつら本編由来の魔法に加え、ジャンカードで確認できる魔法も正式候補として取り入れる
- 確認済み候補にはヒート、アイスーン、ダイダインがある
- リライフはMonster Quest 0では復活魔法として採用する。ただし原作確定情報とは分けて扱う
- 確認済みアイテム / 装備には、かいふくやく、どくけし、きこりのオノ、まもりのナイフ、かいがらのぼうし、ふしぎなかぎ、ゆうしゃのけん、ゆうしゃのかんむり、ゆうしゃのたて等がある

## マップ・世界
- マップは必要以上に巨大化させない
- 約5時間で完走できる密度を優先する
- NPCには生活感・地域情報が出る会話を持たせる
- 村人・町人は基本2パターン程度の台詞を用意する方針
- 基本タイルセットを共通利用し、地域固有素材のみ追加する

## 画像
- FC後期〜初期SFC風の完全オリジナルピクセルアート
- 既存ゲームの背景・構図・タイル・配色を直接模倣しない
- 正式素材を仮素材へ置き換えない
- 戦闘背景は地域ごとに高品質な完成画像を使用する

## 制作順
- 最初にVertical Sliceを完成させる
- タイトル → はじまりのまち → フィールド → ザコ戦 → レベルアップ → 小ダンジョン → ボス → セーブ / ロード → iPhone Safari確認
- Vertical Slice完成前に全地域を大量制作しない

## 公開リポジトリのネタバレ規則
- 終盤ボスの真名・姿
- 終盤の正体
- 真相
- 謎の答え
- 最終入力内容
