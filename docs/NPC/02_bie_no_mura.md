最終更新: 2026-09-11 JST

## 1. 地域の役割
- 山に囲まれた小規模な村。
- 薬草・林業など山の暮らしを感じさせる。
- 行方不明の木こり救出事件を地域の中心事件として扱う。
- 事件解決後、レインランド方面へ自然に誘導する。

## 2. 規模
- 旧会話案: NPC 15人規模。
- 最新方針: 小さな村としてNPC人数・マップ規模を旧案より約半分程度へ圧縮。
- 最終人数はTBD。
- 似た役割・同じ説明を持つ人物は統合する。

## 3. 会話バランス
少人数の中で以下を混ぜる。
- 山の生活
- 薬草 / 林業
- 家族や仕事
- 木こりが戻らない不安
- 山道 / 洞窟の危険
- レインランドへの道や噂
- 攻略に関係ない普通の生活会話

全員が木こり事件だけを話す構成にはしない。
事件に直接関係がなく、普段の生活をしている住民も入れる。

## 4. 進行段階
### 事件前
- 木こりが戻らないことを一部NPCが気にしている。
- 村全員が同じ台詞で騒がない。

### 救出後
- 関係者の反応を変える。
- 全員の会話を無理に変える必要はない。
- レインランド方面への導線を自然に強める。

## 5. 与える情報
- 山の暮らし
- 周辺の危険
- 木こり救出に必要な最低限の手掛かり
- 次の地域へ進む理由

## 6. 与えすぎない情報
- 木こり救出の答えそのもの
- 後半ボス攻略
- ミレイの正体
- 世界の真相
- 終盤バグ / たびのあいことばの答え
