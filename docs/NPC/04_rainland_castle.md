## 1. 地域の役割
- レインランド王家・政治の中心。
- 主人公はNo.03ビーエのもり、No.04ビーエのむら、No.05レインランドのもりで見た異変を王へ報告する。王は選ばれた勇者だからではなく、実際に異常な地域を越えた旅人として主人公を信頼し、No.07まじんのどうくつの調査を依頼する。
- ミレイに関する情報が物語上重要になる地域。
- 城下町より重要人物との接触密度を上げてよいが、NPC総数は増やしすぎない。
- 主要人物の人生が交差する場面に近づくため、通常地域より丁寧に作る候補。

## 2. 規模
- 旧大規模RPGの城のように多数の兵士・侍女を並べない。
- 必要な役割を持つ人物だけを置く。
- 最新の配置目安は7人。正式会話本文は `NPC_DIALOGUE_MASTER.md` 未提供のためTBD。
- マップサイズも初見約4時間30分 / 寄り道込み約5時間30分の方針に合わせてコンパクトにする。

## 3. 必要な役割候補
実装前にストーリー進行を確認し、必要なものだけ採用する。
- 城の入口 / 警備
- 王家の現状を示す人物
- 城で働く生活NPC
- ミレイに関する断片情報を持つ人物
- 次の進行につながる人物
- 攻略と無関係な短い生活会話

役割数＝NPC人数ではない。1人が自然に複数の役割を持ってよい。

## 4. ミレイ情報管理
- ミレイはレインランドの姫。
- 身分を隠して旅に加わる設定を守る。
- 正体判明の正確なタイミングは `STORY_FLOW.md` / `TBD_REGISTRY.md` を確認する。
- 正体判明前に城NPCが直接答えを言わない。
- プレイヤーが後から「あの台詞はそういう意味だったのか」と理解できる伏線を優先する。

## 5. 会話バランス
- 王家・政治だけで埋め尽くさない。
- 城で働く人の普通の生活や仕事も入れる。
- 全員がミレイを話題にしない。
- 同じ王家説明を兵士が何度も繰り返さない。
- 攻略ヒントとストーリー説明を一人に集中させない。

## 6. 与えすぎない情報
- ミレイの正体を適切な時点より前に直接明かすこと
- タロサの全過去
- 終盤ボスの名前・姿
- 世界の真相
- わたべの最終役割
- たびのあいことばの答え

## 7. 制作手順
1. `STORY_FLOW.md` で城到達時点の主人公・ミレイ・王家の状態を確認。
2. 城で起こるイベントの目的を1〜2個に絞る。
3. 必要NPC役割を決める。
4. 最小人数で配置する。
5. 各NPCは基本2パターン程度の短い会話にする。
6. ミレイ情報のネタバレ段階を確認する。
7. 確定後 `DIALOGUE_READY` に変更する。

AIは、王・王妃・大臣・兵士等の未確定人物設定を「城にいそうだから」という理由だけで勝手に正式追加しない。
