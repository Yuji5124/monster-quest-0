## 1. 地域の役割
- 最初に自由操作する町。
- 街道に面した交易・出発地点。
- 世界説明より「外へ出てみたい」と思わせることを優先する。
- 基本操作・外の危険・生活感を短い会話へ分散する。

## 2. 規模
- 旧会話案: NPC 12人規模。
- 最新の配置目安: 7人。町サイズ・NPC人数は旧案を機械的に半減せず、話題の重複を除いて選抜する。
- 正式会話本文は `NPC_DIALOGUE_MASTER.md` 未提供のためTBD。
- 旧12人の台詞を全部捨てず、役割が重複する人物は統合する。

## 3. 会話バランス
最低限、少人数の中で以下を混ぜる。
- 生活 / 商売
- 街道 / 周辺地域
- 外へ出る不安と期待
- 基本操作に自然につながる情報
- 攻略に関係ない印象的な一言

主要人物の噂を中心テーマにしない。
特にタロサ等、この時点で直接関係の薄い人物の話題へ偏らせない。

## 4. 進行変化
- 初回滞在時
- 一度町の外へ出た後

旧案には外出後の会話変化があるため、再編集時に使える台詞を残す。

## 5. 与えすぎない情報
- ミレイの正体
- タロサの過去
- 世界が失敗作である真相
- 終盤のバグ / リセット解決
- わたべの最終役割
- たびのあいことばの答え
