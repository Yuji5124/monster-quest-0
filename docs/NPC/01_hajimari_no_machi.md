- 街道に面した交易・出発地点。
- 世界説明より「外へ出てみたい」と思わせることを優先する。
- 基本操作・外の危険・生活感を短い会話へ分散する。

- 旧会話案: NPC 12人規模。

- 旧12人の台詞を全部捨てず、役割が重複する人物は統合する。

## 3. 会話バランス
最低限、少人数の中で以下を混ぜる。
- 生活 / 商売
- 街道 / 周辺地域
- 外へ出る不安と期待
- 基本操作に自然につながる情報
- 攻略に関係ない印象的な一言

主要人物の噂を中心テーマにしない。
特にタロサ等、この時点で直接関係の薄い人物の話題へ偏らせない。

## 4. 進行変化
