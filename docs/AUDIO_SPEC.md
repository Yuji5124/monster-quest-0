# モンスタークエスト0 音楽・SE仕様

最終更新: 2026-09-20 JST

このファイルはBGM / SEの用途、管理、採用判断の正本。

## 1. 音楽方針
- ファミコン〜初期SFCを感じるレトロRPGサウンドを基本にする。
- 完全なFC音源エミュレーションだけに限定せず、現代環境でも聴きやすい高品質レトロサウンドにする。
- 矩形波、三角波、ノイズ、パルス波等のゲーム音色を活かす。
- 8曲全体を1本のゲームのサウンドトラックとして統一する。
- A案 / B案がある曲は最終採用まで両方を候補として扱う。

## 5. 終盤異常演出
- BGM停止や一瞬の欠けは `GLITCH_SPEC.md` に従って制御する。
- 本当の音声再生エラーと演出演算を混同しない。
- 演出後は必ず既知の正常状態へ復帰する。
- 序盤から異常SEを多用しない。

## 5.1 No.01冒頭の環境音
- 「はじめから」直後は**BGMなし**。タイトルで決定した直後のユーザー操作でAudioContextを開始する。
- 0:00は完全無音。約0.7秒後から焚き火の低い燃焼音と遠い風を小さく入れる。
- 0:02〜0:07の明転、ナレーション、操作解放後もBGMを足さない。操作解放後だけ水辺の環境音を小さく重ねる。
- 正式な火・風・水のSE素材は未登録のため、現実装は`OpeningCampfireAudio.ts`のWeb Audioノイズ音を**TEMP_PROCEDURAL_AMBIENCE**として使う。既存BGM候補を環境音として流用しない。
- 正式SEが採用されたときは、音量・開始順・BGMなしの原則を保ったまま差し替える。

## 6. iPhone / Web
- ブラウザのユーザー操作後にAudioContextを開始する前提で設計する。
- iPhone SafariでBGM / SEが多重再生・無音化しないか確認する。
- タブ移動、バックグラウンド復帰時のBGM状態をQA対象にする。
- 音量設定を保存可能にする。

## 7. アセット管理
推奨パス:
- `assets/audio/bgm/`
- `assets/audio/se/`

正式配置後は `ASSET_INDEX.md` または音声専用manifestへ同期する。

## 8. 禁止
- A/B案をAIが勝手に最終採用する。
- 既存ゲーム曲のメロディを直接模倣する。
- 終盤バグ用音声を序盤から常用する。
- 端末依存の自動再生を前提にする。
