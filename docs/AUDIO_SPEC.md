# Monster Quest 0 音楽・SE仕様

更新日: 2026-09-09

## 1. 基本方針
- FC〜初期SFCを感じるレトロRPGサウンド
- 完全なFC音源再現に限定せず、現代環境で聴いても気持ちよい高品質レトロサウンドを目指す
- 矩形波、三角波、ノイズ、パルス系の質感を活かす
- 全曲を1本のゲームのサウンドトラックとして統一する

## 2. BGM
- 全8曲構成を基本とする
- 01：タイトル / オープニング
- 02：フィールド / ワールドマップ
- 03：むら・まち
- 04〜08：ゲーム進行に合わせた地域・戦闘・終盤用途
- 各曲はA案 / B案等の候補素材がある場合、ゲーム全体の統一感を見て採用する

## 3. 実装方針
- BGM IDをSceneやMap IDから参照できるようにする
- マップごとに音声ファイル名をコードへ直書きしすぎない
- マップ遷移時の不自然な二重再生を防ぐ
- 戦闘開始 / 終了時のBGM復帰位置はプレイ感を見て決める
- iOS Safariの音声再生制限を考慮する

## 4. 最低限必要なSE
- カーソル移動
- 決定
- キャンセル
- メニュー開閉
- 通常攻撃
- ダメージ
- 敵撃破
- 魔法発動
- 回復
- 宝箱
- アイテム取得
- レベルアップ
- 扉
- 階段 / マップ遷移
- エンカウント
- セーブ
- エラー / 使用不可

## 5. 音量
最低限カテゴリを分ける。
- BGM
- SE

設定値はセーブ可能にする。

## 6. 終盤演出
- 制御されたBGM停止、瞬断、違和感演出を使用可能
- 実際のAudioエラーや永久停止を起こさない
- 異常演出後は必ず正常状態へ復帰できるようにする

## 7. 禁止事項
- 出典不明の既存ゲーム音源を使用しない
- 既存ゲームのメロディを直接模倣しない
- 仮BGMを正式素材がある場所へ無断で上書きしない
