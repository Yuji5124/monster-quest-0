# Monster Quest 0 アイテム・装備仕様

更新日: 2026-09-09

## 1. 基本方針
- 原作・動画・カード等で確認できた名称を優先する
- 効果未確定の装備へAIが勝手に特殊能力を追加しない
- アイテム数を必要以上に増やさず、約5時間のゲームで役割が分かる構成にする

## 3. アイテムカテゴリ
- 回復
- 状態異常回復
- 武器
- 防具
- 重要アイテム
- その他イベント用

## 4. 実装方針
- コード内へ個別アイテム処理を大量に直書きしない
- IDベースで管理する
- 重要アイテムは売却・破棄で進行不能にならないようにする
- 入手済み重要アイテムはセーブ対象とする

推奨データ：
- id
- name
- type
- description
- value
- effectId
- equipSlot
- stats
- keyItem
- sellable

## 5. UI
- アイテム名をレトロRPGらしく短く読みやすく表示する
- アイコンは必須ではない。テキストだけでもゲームが成立する構造を維持する
- アイコンを使用する場合は共通サイズで統一する

## 6. 禁止事項
- 進行に必要な重要アイテムを消費・売却可能にしない
- AIが似た名前の新アイテムを勝手に大量追加しない
- 装備数値をストーリー上の強さと矛盾させない
