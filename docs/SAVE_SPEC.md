# Monster Quest 0 セーブ / ロード仕様

更新日: 2026-09-09

## 1. 基本方針
- Webブラウザ向けのローカル保存を基本とする
- iPhone Safariでの利用を前提に確認する
- セーブ破損を演出として使わない
- 終盤の異常演出があっても実データは安全に保つ

## 2. 最低限保存するもの
- 現在マップID
- プレイヤー位置 / 向き
- パーティメンバー
- 各キャラクターのレベル / EXP / HP / MP
- 所持金
- 所持アイテム
- 装備
- 重要アイテム
- ストーリー進行フラグ
- ボス撃破フラグ
- 宝箱取得状態
- NPC / イベント進行フラグ
- ジャンカード取得状態
- 次回ジャンカード排出番号
- 必要に応じて設定値（音量等）

## 3. 保存形式
- セーブデータにはversionを持たせる
- 仕様変更時に古いセーブを読み込めるよう、必要ならmigrationを用意する
- 一時的なSceneオブジェクトやPhaser内部参照は保存しない
- JSON化できるゲーム状態のみ保存する

## 4. オートセーブ
候補タイミング：
- マップ移動後
- 重要イベント終了後
- ボス撃破後

ただし頻繁すぎる保存は避ける。
正式なオートセーブ仕様はVertical Sliceで操作感を確認して確定する。

## 5. 手動セーブ
- メニューまたはゲーム内の明確な保存手段を用意する
- 保存成功が分かるフィードバックを出す
- 保存中に操作不能時間を長くしない

## 6. 安全ルール
- 不完全なデータで既存セーブを上書きしない
- 読み込み失敗時に無限ループしない
- セーブデータがなくても新規ゲームを開始できる
- 終盤の演出で本当にセーブデータを消去・破損しない

## 7. QA
以下を必ず試す。
- 新規ゲーム → セーブ → 再読み込み
- ボス前後
- 仲間加入前後
- 重要アイテム入手前後
- ジャンカード取得前後
- Safariタブ終了 / 再起動後
- バージョン変更後の読み込み
