# モンスタークエスト0 仕様変更ルール

最終更新: 2026-09-10 23:46 JST

## 1. 目的
会話・画像・コード・AI出力の間で仕様がズレるのを防ぐ。

## 2. 重要変更時
以下のいずれかが変わった場合は、コードや画像だけでなく関連Markdownも更新する。
- タイトル / 名称
- プレイ時間
- キャラクター設定
- モンスター数 / カード数
- マップ名 / 進行順
- 魔法 / アイテム
- ボス攻略構造
- セーブ項目
- 開発方式
- アート方向

## 3. 最優先更新先
全体へ影響する変更はまず `PROJECT_STATUS.md` を更新する。
その後、対象SPEC、README、CONTENT_MATRIXを必要に応じて同期する。

## 4. 古い仕様
削除だけで意味が分からなくなる場合は「旧仕様」として残してよい。
ただし現行仕様と誤認しないよう明記する。

## 5. 未確定
確定していない項目は `TBD_REGISTRY.md` へ置く。
AIが空欄を勝手に埋めて確定扱いしない。

## 6. アセット変更
正式画像を差し替えた場合:
- `ASSET_INDEX.md`
- `assets/asset_catalog.json`
- 参照コード
を同期する。

## 7. 実装変更
データ形式、Scene責務、イベント形式を変更した場合:
- `PHASER_ARCHITECTURE.md`
- `DATA_CONTRACTS.md`
- `EVENT_SYSTEM_SPEC.md`
を同期する。

## 8. 進捗変更
会話設計・アセット配置・Phaser実装・Playtestが進んだ場合は `CONTENT_MATRIX.md` と必要に応じて `PROJECT_STATUS.md` を更新する。

## 9. AIルール
AIはユーザーの新しい確定指示を既存仕様より優先する。ただし、勝手な推測を「新しい仕様」として書き込まない。

## 10. 日付
大きな仕様同期では各基幹文書の最終更新日時をJSTで更新する。
