# モンスタークエスト0 マップ進行仕様

最終更新: 2026-09-11 JST

このファイルは各地域・ダンジョンの役割、接続、進行条件を整理する正本。最終座標・タイル数は実装確認後に確定する。

## 1. 基本方針
- 全域の基本移動は徒歩。
- 船・飛行によるワールド移動は基本システムにしない。
- 橋は過密にせず旧案より減らす。
- 町・村の規模は従来案よりコンパクトにし、NPC数も約半分を目安に再調整する。
- 各地域は生活・文化・事件・周辺ダンジョンとの理由づけを持つ。

## 4. 基本進行の大枠
はじまりのまち
→ ビーエ方面
→ レインランド方面
→ 中盤各地域（ザボン、いしのむら、洞窟、かくれざと等）
→ 勇者装備関連
→ デーマスの塔
→ 終盤地域
→ バトラスのとりで
→ オロチのしろ
→ 最終地点

中盤の正確な接続順は未確定部分を含むため、AIが一本道を勝手に固定しない。

## 5. マップごとに実装時に持たせる情報
- `mapId`
- 表示名 / 内部名
- map type
- 推奨レベル帯
- 接続先
- 出入口
- BGM
- encounter table
- NPC / 宝箱 /イベント
- 必要フラグ
- 必要アイテム / 装備
- ボス
- 初回クリア後の変化
- 再訪価値

未確定値は `null` / `TBD` とする。

## 6. ダンジョン設計
- 一本道だけにしないが、約5時間の作品として迷路を巨大化しない。
- 小さな分岐、宝箱、近道、イベントで密度を出す。
- その土地に存在する理由・歴史・生態を会話や景観へ反映する。
- ボス攻略のヒントは町・村・ダンジョン内に分散する。

## 7. 町・村設計
- 最新方針として従来の町サイズ・NPC人数から約半分程度へ圧縮する。
- 建物を増やすだけの空間は作らない。
- 1画面または少ない画面数でも、その地域の個性が分かる構成を優先する。
- NPC会話は `NPC_SPEC.md` と地域別会話データを参照する。

## 8. 実装禁止
- 船や飛行を勝手に追加する。
- 未確定の地域順を確定扱いする。
- 巨大マップ化してプレイ時間を水増しする。
- ネタバレ内部名を公開画面へそのまま出す。
