# モンスタークエスト0 マップ進行仕様

最終更新: 2026-09-11 JST

このファイルは各地域・ダンジョンの役割、接続、進行条件を整理する正本。最終座標・タイル数・地域サイズ・ダンジョン階層は実装確認後に確定する。

## 1. 基本方針
- 全域の基本移動は徒歩。
- 船・飛行によるワールド移動は基本システムにしない。
- 橋は過密にせず旧案より減らす。
- 各地域は生活・文化・事件・周辺ダンジョンとの理由づけを持つ。
- **町・村・城・ダンジョンの具体的な規模は再検討中。**
- 旧「全体を約半分へ圧縮」案は検討履歴として残すが、現時点では固定ルールとして扱わない。
- 最終規模は、目標プレイ時間 **初見約4時間30分 / 寄り道込み約5時間30分** と、地域ごとの役割・探索密度・移動テンポから決める。

## 6. ダンジョン設計
- 一本道だけにしないが、プレイ時間を水増しする巨大迷路にはしない。
- **ダンジョンの広さ・フロア数・分岐数は再検討中。旧「約半分」案を自動採用しない。**
- 小さな分岐、宝箱、近道、イベント、敵配置などで密度を出す。
- その土地に存在する理由・歴史・生態を会話や景観へ反映する。
- ボス攻略のヒントは町・村・ダンジョン内に分散する。
- 通常ダンジョンと重要ダンジョンを同じ規模にそろえない。
- デーマスの塔、終盤拠点など重要地点は物語上必要なら十分な尺を取る。

## 7. 町・村設計
- **町・村のサイズ、建物数、NPC人数は再検討中。**
- 旧大規模案と旧半減案はいずれも参考資料として扱い、確定値にしない。
- 建物を増やすだけの空間は作らない。
- 小さくても、その地域の個性・生活・進行上の役割が分かる構成を優先する。
- 大きくする場合も、意味のない移動時間を増やさない。
- NPC会話は `NPC_SPEC.md` と地域別会話データを参照する。

## 8. プレイ時間基準
全体の目標:
- **初見クリア: 約4時間30分**
- **NPC会話・探索など寄り道込み: 約5時間30分**

この時間はマップを機械的に縮小して達成するのではなく、以下の合計で調整する。
- 町・村での移動と会話
- フィールド移動
- 通常戦闘とレベル上げ
- ダンジョン探索
- ボス戦
- 仲間加入・主要イベント
- 終盤演出
- 任意の寄り道

## 9. 実装禁止
- 船や飛行を勝手に追加する。
- 未確定の地域順を確定扱いする。
- 未確定の町サイズ・NPC数・ダンジョン階層を旧案から自動確定する。
- 巨大マップ化してプレイ時間を水増しする。
- 逆に、重要イベントや地域性が消えるほど機械的に縮小する。
- ネタバレ内部名を公開画面へそのまま出す。
