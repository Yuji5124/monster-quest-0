# モンスタークエスト0 マップ進行仕様

最終更新: 2026-09-11 JST

このファイルは各地域・ダンジョンの役割、接続、進行条件を整理する正本。最終座標・タイル数・地域内部サイズ・ダンジョン階層は実装確認後に確定する。

## 1. 基本方針
- **全体マップ、主要地域の配置、世界全体の大枠は変更しない。**
- 全域の基本移動は徒歩。
- 船・飛行によるワールド移動は基本システムにしない。
- 橋は過密にせず旧案より減らす。
- 各地域は生活・文化・事件・周辺ダンジョンとの理由づけを持つ。
- **見直す対象は、町・村・城の内部マップサイズと、ダンジョンの広さ・階層・分岐量。**
- 町・村・城は旧案よりコンパクトにする方向で再設計する。
- ダンジョンも旧案よりコンパクトにする方向で再設計する。
- 「一律50%」などの固定比率ではなく、目標プレイ時間と地域の役割に合わせて個別に縮小する。
- 最終規模は、目標プレイ時間 **初見約4時間30分 / 寄り道込み約5時間30分** と、地域ごとの役割・探索密度・移動テンポから決める。
- **物語の始まりだけは通常地域より密度を高くし、時間を引き延ばすのではなく演出・風景・音・短い操作で印象を強くする。**

## 3. はじまりのばしょ
- 「はじまりのまち」とは別マップ。
- イベント専用の小規模マップ。
- **夜版／昼版の同一ロケーション2種類を用意する。**
- 物語開始時は夜版。
- 主人公は焚き火付近で目覚める。
- 夜版は不安・静けさ・主人公の違和感を見せる。
- 昼版は世界へ歩き出す感覚、時間経過、現実感を見せる。
- 広大な探索や大量NPCは置かない。
- 正確なタイル数・昼への切替条件はTBD。

### 1回目: オープニング
- 主人公は基本的に一人。
- 世界や自分の出自を説明しないまま、ここからMQ0の通常冒険へ入る。
- はじまりのまちへつなぐ。

### 2回目: 「もういちど」後
- オロチゾンビ1回目→異常→偽リセット→「もういちど」の後、**同じNo.18へ戻る**。
- 今回は主人公だけでなくタロサ・ミレイら仲間が存在する。
- 主人公・タロサ・ミレイは前の出来事を覚えている。
- 初回と同じ地形／焚き火を見せ、差分によって「世界は戻ったように見えるが、冒険は続いている」と伝える。
- 2回目の時間帯、仲間の正確な立ち位置、台詞、通常ルートと異なる出口／追加導線の有無はTBD。

詳細: `OPENING_SPEC.md` / `STORY_FLOW.md` / `GLITCH_SPEC.md`

## 7. ダンジョン設計
- **ダンジョンは旧案より小さくする方向で再設計する。**
- 一本道だけにはしないが、長い迷路や意味の薄い往復は減らす。
- フロア数、1フロアの広さ、分岐数を抑え、短時間でも印象に残る構成を優先する。
- 小さな分岐、宝箱、近道、イベント、敵配置などで密度を出す。
- その土地に存在する理由・歴史・生態を会話や景観へ反映する。
- ボス攻略のヒントは町・村・ダンジョン内に分散する。
- 通常ダンジョンと重要ダンジョンを同じ規模にそろえない。
- デーマスの塔、終盤拠点など重要地点は、縮小しつつも物語上必要な演出・攻略要素は残す。
- 「約半分」は設計上の目安として参考にできるが、一律の固定値にはしない。

## 8. 町・村・城設計
- **町・村・城の内部マップは旧案より小さくする方向で再設計する。**
- 全体マップ上の位置・地域構成は変更しない。
- 建物数、内部移動距離、無意味な空きスペースを減らす。
- 小さくても、その地域の個性・生活・進行上の役割が分かる構成を優先する。
- NPC人数はマップサイズと役割に合わせて改めて調整する。
- 旧大人数NPC案は会話素材として保持する。
- NPC会話は `NPC_SPEC.md` と地域別会話データを参照する。

## 9. 始まりの密度設計
始まりを「濃くする」ためにマップを巨大化しない。

優先する:
- 夜→昼の時間変化
- 焚き火、風、足音、無音／BGM
- 主人公の短い反応
- はじまりのまちへ入ったときの開放感
- 最初のNPCとの会話
- 最初のフィールド移動
- 初戦闘までの流れ

始まりの数マップは通常地域より演出密度を上げるが、移動距離・NPC数・説明文で水増ししない。

同じNo.18を「もういちど」後にも使うため、最初の構図・焚き火・ランドマークは終盤で見ても認識できるよう印象を持たせる。

## 10. プレイ時間基準
全体の目標:
- **初見クリア: 約4時間30分**
- **NPC会話・探索など寄り道込み: 約5時間30分**

主な時間短縮は、世界そのものを削るのではなく以下で行う。
- 町・村・城内部の移動距離を短縮
- ダンジョンの広さ・階層・分岐を圧縮
- 意味の薄い往復を削減
- NPC・イベント導線を整理

主要地域、主要人物、主要ボス、重要イベント、「もういちど」以降、終盤演出は維持する。

## 11. 実装禁止
- 全体ワールドマップや主要地域構成を、内部マップ縮小のために勝手に変更する。
- 「はじまりのばしょ」を「はじまりのまち」と同一マップ扱いする。
- No.18を物語順に合わせるため勝手にNo.01へ振り直す。
- 「もういちど」後を単純なNew Game／2周目として別進行にする。
- 船や飛行を勝手に追加する。
- 未確定の地域順を確定扱いする。
- 巨大マップ化してプレイ時間を水増しする。
- 逆に、重要イベントや地域性が消えるほど機械的に縮小する。
- ネタバレ内部名を公開画面へそのまま出す。
