# Monster Quest 0 モンスター仕様

更新日: 2026-09-09

## 1. 基本方針
- ゲーム内モンスター総数：25体
- 原作・ジャンカード・共有資料で確認できる設定をAI案より優先する
- 既存デザインを勝手に別モンスターへ描き直さない
- 戦闘用画像は背景透明PNGへ統一する
- ネタバレ対象は公開時に「？？？」等で伏せる

## 2. 強さの考え方
- 序盤：レベル上げ相手として分かりやすい
- 中盤：状態変化、耐性、攻撃パターンなどで差を出す
- 強敵：通常敵より明確に危険だが、準備で攻略可能にする
- ボス：レベルだけでなくヒントと対策で攻略する

## 3. 確認済み例
以下は共有資料で数値が確認されている例。実装時は最新の個別仕様を優先する。

| 名前 | HP | MP | 攻撃 | 備考 |
|---|---:|---:|---:|---|
| ダイジャ | 40 | 0 | 20 | 序盤候補 |
| デーマス | 1000 | 500 | 300 | ボス |
| まじん | 800 | 0 | 500 | 強敵 |

## 4. 現在の確定分類
- No.15：まじん / 強敵
- No.16：バクラー / ボス
- 公開用一覧でネタバレとなる終盤モンスターは「？？？」表記にする

## 5. 実装ルール
各モンスターは可能な限りデータ駆動にする。

最低限の項目例：
- id
- name
- hp
- mp
- attack
- defense
- speed
- exp
- gold
- sprite
- actions
- resistances
- encounterAreas
- spoilerLevel

## 6. 量産ルール
- モンスター追加のたびに戦闘システム本体へ専用コードを書かない
- 特殊行動だけデータまたは共通アクションとして拡張する
- 戦闘テンポを損ねる複雑な行動を通常敵へ増やしすぎない
