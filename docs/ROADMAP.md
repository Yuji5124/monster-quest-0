# Monster Quest 0 開発ロードマップ

更新日: 2026-09-09

## 0. 原則
- 完成を最優先する
- 約5時間の本編を目標とする
- AI 80% / 人間の視覚調整20%
- Phaser Game Agent中心
- Vertical Slice完成前に全地域を作らない

## Phase 1: リポジトリ・仕様基盤
目標：AIが同じ方針を読める状態にする。

- Markdown仕様整備
- 素材フォルダ整理
- Phaserプロジェクト初期化
- Phaser Game Agent接続
- Claude Code / Codex用ルール確認

完了条件：
- `docs/INDEX.md` から主要仕様へ到達できる
- `DECISIONS.md` が最新版になっている
- プロジェクトがブラウザで起動する

## Phase 2: Vertical Slice v0.1
目標：正式素材で最初から最後まで短時間遊べる。

実装順：
1. タイトル
2. はじまりのまち
3. 主人公歩行
4. NPC会話
5. フィールド
6. ランダムエンカウント
7. 戦闘
8. 経験値 / レベルアップ
9. 小ダンジョン
10. ボス
11. セーブ / ロード
12. iPhone Safari確認

完了条件：
- 新規ゲームからボス撃破まで進行不能なし
- 正式タイル・正式主人公・正式UIを使用
- iPhoneで主要操作可能

## Phase 3: 基本システム固定
Vertical Sliceで判明した問題を直す。

- 戦闘テンポ

- マップ遷移

- セーブversion

- ビーエのむら

- マップ
