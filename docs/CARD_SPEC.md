# Monster Quest 0 ジャンカード仕様

更新日: 2026-09-09

## 1. 概要
- ゲーム内に「ジャンカードガチャ」を実装する
- カードは全45枚
- ジャンカードは本編攻略必須ではない独立したサブゲームとして扱う
- コレクションとして楽しめる構成にする
- カード内容にはキャラクター、モンスター、アイテム、魔法などを含む

## 2. ガチャ基本方針
- 1回ごとにカードを1枚入手する
- 重複なしを基本とする
- 排出順・価格・演出の細部は実装時に `DECISIONS.md` で確定する
- 全45枚コンプリート後は、取得済みカードをいつでも閲覧できる

## 3. ガチャ画面
表示項目の基本案：
- 現在の所持金
- カード所持枚数 / 45
- カード一覧
- 未取得カードは「？」またはシルエット
- 「カードをひく」
- 「コレクション」
- 「もどる」

## 4. カード取得演出
- 短い演出でテンポを落としすぎない
- 「ジャンカードを てにいれた！」等の取得メッセージを表示
- カード番号、カード名、カード画像、カード記載情報を確認できる

## 5. コレクション
- メニューから確認可能
- 入手済みカードは拡大表示できる
- 未入手カードは内容を隠す
- ネタバレ対象カードは公開画面・紹介資料では名称や姿を伏せる

## 6. ゲーム上の役割
- 本編とは独立した収集・ガチャ要素
- 45枚集めなくても本編クリア可能
- 本編のテンポを阻害しない
- コンプリートはやり込み要素として成立させる

## 7. セーブ項目
最低限、以下を保存する。
- 取得済みカードID
- カード所持枚数
- ガチャに必要な進行情報

## 8. データ構造案
各カードに以下を持たせる。
- id
- number
- name
- image
- category
- description
- spoilerLevel

## 9. 公開時のネタバレ制御
- 終盤ボスや正体に関わるカードは公開用一覧では「？？？」表記を使用する
- GitHubは公開リポジトリのため、真名や終盤の答えそのものを公開仕様書へ記載しない
