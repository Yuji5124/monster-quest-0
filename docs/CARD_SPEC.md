# モンスタークエスト0 ジャンカード仕様

最終更新: 2026-09-27 JST

## 1. 概要
- ゲーム内に「ジャンカードガチャ」を実装する。
- カードは全45枚。
- 1回につき**ジャンコイン1枚**（`cards.jumpCoinCount`。戦闘報酬のG=`player.money`とは別枠の専用通貨）。
- 1回につき1枚排出。
- No.01からNo.45まで順番に排出する固定順方式。
- 重複なし。
- 全45枚を集める場合の必要枚数はジャンコイン45枚。
- ジャンコインは、モンスターを倒した際に一定の確率で入手する（確率・対象敵・実装は`TBD_REGISTRY.md`のとおり未確定/未実装、2026-09-27時点）。加えて、No.03ビーエのもりの宝箱から1枚を確定で入手できる（2026-10-01ユーザー指定）。
- ジャンカードは本編攻略必須にはせず、独立したサブゲーム／収集要素として楽しめる構成にする。

## 2. ガチャ画面
表示項目:
- 現在のジャンコイン所持枚数
- 1回ジャンコイン1枚
- 現在のカード所持枚数 / 45
- No.01〜No.45の一覧
- 未取得カードは「？」または黒いシルエット
- 「カードをひく」
- 「コレクション」
- 「もどる」

## 3. 排出ルール
- 1回目: No.01
- 2回目: No.02
- …
- 45回目: No.45
- 46回目以降は回せない。
- ジャンコインが1枚未満では回せない。

## 4. カード取得演出
- 所持ジャンコインから1枚を減算する。
- 指定素材`assets/title/reference/H.png`（コイン投入）→`assets/title/reference/I.png`（ハンドルを回す）の順で、カード出現前に約6秒のレア演出を再生する（コイン投入→「チャリン！」→ハンドル3段「ガチャ…ガチャ…ガチャリ！」→虹色の枠と後光→白フラッシュ→カード）。秒数は`src/config/jumpCardGachaPresentation.ts`に集約。演出中は入力を受け付けない。
- 「ジャンカードを てにいれた！」と表示。
- カード番号、カード名、カード画像、カード記載情報を表示。

## 5. コレクション
- メニューからいつでも確認可能。
- 入手済みカードは拡大表示できる。
- 未入手カードは内容を隠す。
- 45枚コンプリートはやり込み要素として扱い、本編クリア条件にはしない。

## 6. 本編との距離
- ジャンカード自体を独立した遊びとして成立させる。
- **本編中は最後まで攻略必須にしない。**
- **序盤〜中盤のNPCや本編イベントで、頭文字・並び順・たびのあいことば・カードの秘密を早期に示唆しない。**
- 「カードを集めれば世界の秘密が分かる」等の露骨な誘導を序盤から置かない。
- プレイヤーは普通の収集／ガチャ要素として楽しめる。
- 終盤の仕掛けと関係する場合も、そこへ至るまでは秘密として保つ。

## 7. ゲーム上の役割
- カード同士を見比べたり、元作品由来の情報を楽しめる収集要素。
- 本編のテンポを止める収集ノルマにしない。
- カセット裏面などの仕掛けと連動する場合も、公開仕様では終盤の具体的な答えを記載しない。

### 7.1 ジャンカードバトル（2026-10-01 ユーザー指定）
- No.06レインランドじょうかまちに、ジャンカードバトルをするNPCを配置する。
- 初回の相手は、プレイヤーがNo.01「プリン」を所持している時だけ勝負でき、相手も同じプリンカードを出す。
- この対戦は**1回勝負**。カードを消費せず、所持金・ジャンコイン・RPG戦闘のHP/EXP/進行フラグも変えない。
- 専用画面ではプレイヤーのカードを左、相手のカードを右に表示する。グー／チョキ／パーを選んでから「じゃんけん、しょっ！」で同時に出し、相手の手はランダムに決まる。あいこは選び直し、勝った側が先に攻撃してすぐ勝負を終える。
- 対戦相手は`src/config/jumpCardBattles.ts`、共通の画面とじゃんけん判定は`src/scenes/JumpCardBattleScene.ts`／`src/systems/JumpCardBattle.ts`で管理する。将来の対戦NPCはこの設定を追加して接続する。

## 8. ネタバレ管理
- 公開用カード一覧では、終盤ネタバレ対象のカード名を `？？？` と表記できる。
- スカルまおう等の重大ネタバレ対象は公開時 `？？？` を使用する。
- 内部データでは正式名・正式IDを維持する。
- 公開用ビジュアルでは終盤ボスの姿・名前を露出しない。

## 9. セーブ項目
- ジャンカード購入に使うジャンコイン（`cards.jumpCoinCount`）
- 取得カード枚数
- 取得済みカード番号
- 次回排出カード番号

例:
- `cardsCollected = 18`
- `nextCard = 19`

「もういちど」等の終盤演出でも取得情報を削除しない。

> 実装互換メモ（2026-09-27更新）: 2026-09-24時点の本書は所持金20円方式を正本としていたが、**ユーザー確定によりSUPERSEDED**。現行コードの`cards.jumpCoinCount`（ガチャ専用通貨）を正本とする。ジャンコインの入手方法は「モンスター討伐時の低確率ドロップ」と方針確定したが、確率・対象敵・実装は着手しておらず`TBD_REGISTRY.md`のTBDのまま（DEVビルドの起動時45枚付与のみ）。ガチャ画面の所持枚数表示は現行コード（`JumpCardGachaScene`）で既に対応済み。

## 10. データ案
各カードに以下を持たせる:
- `id`
- `name`
- `publicName`
- `image`
- `description`
- `secretData`

`secretData` の具体内容は公開仕様書では扱わない。

## 11. 画像管理
- 完成カード: `assets/cards/full/card_001_<name>.png` ～ `card_045_<name>.png`
- 中央絵透過素材: `assets/cards/art/card_art_001_<name>.png` ～ `card_art_045_<name>.png`
- 正式な画像名と状態は `docs/ASSET_INDEX.md` を正とする。
