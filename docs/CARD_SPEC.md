# モンスタークエスト0 ジャンカード仕様

最終更新: 2026-09-19 JST

## 1. 概要
- ゲーム内に「ジャンカードガチャ」を実装する。
- カードは全45枚。
- 1回につき**ジャンコイン1枚**。
- 1回につき1枚排出。
- No.01からNo.45まで順番に排出する固定順方式。
- 重複なし。
- 全45枚を集める場合の必要ジャンコインは45枚。
- ジャンカードは本編攻略必須にはせず、独立したサブゲーム／収集要素として楽しめる構成にする。

## 2. ガチャ画面
表示項目:
- 現在のジャンコイン残数
- 1回ジャンコイン1枚
- 現在のカード所持枚数 / 45
- No.01〜No.45の一覧
- 未取得カードは「？」または黒いシルエット
- 「カードをひく」
- 「コレクション」
- 「もどる」

## 3. 排出ルール
- 1回目: No.01
- 2回目: No.02
- …
- 45回目: No.45
- 46回目以降は回せない。
- ジャンコインが1枚未満では回せない。

## 4. カード取得演出
- ジャンコインから1枚減算。戦闘報酬のG（通常の所持金）は減らさない。
- 指定素材`assets/title/reference/I.png`（コインで回す案内）→`assets/title/reference/H.png`（コイン投入）の順で、カード出現前に約5秒の演出を再生する。演出中は入力を受け付けない。
- 「ジャンカードを てにいれた！」と表示。
- カード番号、カード名、カード画像、カード記載情報を表示。

## 5. コレクション
- メニューからいつでも確認可能。
- 入手済みカードは拡大表示できる。
- 未入手カードは内容を隠す。
- 45枚コンプリートはやり込み要素として扱い、本編クリア条件にはしない。

## 6. 本編との距離
- ジャンカード自体を独立した遊びとして成立させる。
- **本編中は最後まで攻略必須にしない。**
- **序盤〜中盤のNPCや本編イベントで、頭文字・並び順・たびのあいことば・カードの秘密を早期に示唆しない。**
- 「カードを集めれば世界の秘密が分かる」等の露骨な誘導を序盤から置かない。
- プレイヤーは普通の収集／ガチャ要素として楽しめる。
- 終盤の仕掛けと関係する場合も、そこへ至るまでは秘密として保つ。

## 7. ゲーム上の役割
- カード同士を見比べたり、元作品由来の情報を楽しめる収集要素。
- 本編のテンポを止める収集ノルマにしない。
- カセット裏面などの仕掛けと連動する場合も、公開仕様では終盤の具体的な答えを記載しない。

## 8. ネタバレ管理
- 公開用カード一覧では、終盤ネタバレ対象のカード名を `？？？` と表記できる。
- スカルまおう等の重大ネタバレ対象は公開時 `？？？` を使用する。
- 内部データでは正式名・正式IDを維持する。
- 公開用ビジュアルでは終盤ボスの姿・名前を露出しない。

## 9. セーブ項目
- ジャンコイン残数
- 取得カード枚数
- 取得済みカード番号
- 次回排出カード番号

例:
- `cardsCollected = 18`
- `nextCard = 19`

「もういちど」等の終盤演出でも取得情報を削除しない。

## 10. データ案
各カードに以下を持たせる:
- `id`
- `name`
- `publicName`
- `image`
- `description`
- `secretData`

`secretData` の具体内容は公開仕様書では扱わない。

## 11. 画像管理
- 完成カード: `assets/cards/full/card_001_<name>.png` ～ `card_045_<name>.png`
- 中央絵透過素材: `assets/cards/art/card_art_001_<name>.png` ～ `card_art_045_<name>.png`
- 正式な画像名と状態は `docs/ASSET_INDEX.md` を正とする。
