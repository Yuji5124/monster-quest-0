# モンスタークエスト0 ジャンカード仕様

## 1. 概要
- ゲーム内に「ジャンカードガチャ」を実装する
- カードは全20枚
- 1回20円
- 1回につき1枚排出
- カードはランダムではなく、No.01からNo.20まで固定順で排出する
- 重複なし
- 全20枚を集めるには合計400円必要

## 2. ガチャ画面
表示項目：
- 現在の所持金
- 1回20円
- 現在のカード所持枚数 / 20
- No.01〜No.20の一覧
- 未取得カードは「？」または黒いシルエット
- 「カードをひく」
- 「コレクション」
- 「もどる」

## 3. 排出ルール
- 1回目：No.01
- 2回目：No.02
- …
- 20回目：No.20
- 21回目以降は回せない
- 20円未満では回せない

## 4. カード取得演出
- 所持金から20円減算
- 2〜4秒程度の短い演出
- 「ジャンカードを てにいれた！」と表示
- カード番号、カード名、カード画像、カード記載情報を表示

## 5. コレクション
- メニューからいつでも確認可能
- 入手済みカードは拡大表示できる
- 未入手カードは内容を隠す

## 6. ゲーム上の役割
- ジャンカードは単なる収集要素ではなく、終盤の重要な謎につながる
- 20枚集めても答えを自動表示しない
- プレイヤーがカード同士を見比べ、内容を考える構成とする
- 大人と子どもが相談しながら考える遊びを重視する
- 具体的な終盤の答えは公開仕様には記載しない

## 7. セーブ項目
- 所持金
- 取得カード枚数
- 取得済みカード番号
- 次回排出カード番号

例：
- cardsCollected = 6
- nextCard = 7

## 8. データ案
各カードに以下を持たせる：
- id
- name
- image
- description
- secretData

secretDataの具体内容は公開仕様書では扱わない
