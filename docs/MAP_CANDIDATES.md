# モンスタークエスト0 マップ候補一覧

最終更新: 2026-09-22 JST

このファイルは、最新の物語順1〜20を変更せずに追加できる**マップ候補・サブエリア候補**を管理する。
物語上の正式順は `PLAY_ORDER_SPEC.md` を最優先とする。

## 1. 管理ルール
- 最新1〜20の本編順はこのファイルから変更しない。
- 候補マップには正式No.をまだ付けない。
- 候補は「独立マップ」「既存地域内のサブマップ」「短い特殊区間」のいずれかとして後から採否を決める。
- 敵出現地域を増やす目的だけで無理にマップを増やさない。
- 採用時は、前後の町・イベントから開放される理由を作る。
- 初見約4時間30分 / 寄り道込み約5時間30分を超過させない。
- 不採用になっても本編1〜20が成立する構造にする。

## 3. 追加マップ候補

### C01 ザボンの狩り場
状態: **候補 / 未採用**

想定位置:
08「ザボンのむら」のイベント内、または08→09の間。

役割候補:
- ザボンが「狩人・魔物討伐に強い地域」であることを実際のプレイで見せる。
- タロサ登場後、弓／武器アクションのチュートリアル・実戦確認に使える。
- 09「いわやまのどうくつ」へ向かう前の短い戦闘区間。
- やきプリン、カマイタチ、プリンキング等の中盤敵候補を配置する余地を作る。

採用条件:
- タロサ関連イベントを強化したい場合のみ採用。
- 10〜15分以上の独立ダンジョンにはしない。
- ザボンのむら内部イベントだけで十分なら不採用。

### C02 ダコハ海岸
状態: **候補 / 未採用**

想定位置:
12「港町ダコハ」のイベント内、または12→13の間。

役割候補:
- 港町なのに町だけで終わる単調さを避ける。
- 海・浜辺系モンスターの出現場所を作る。
- さわぎとりうお等、水辺に合う敵の正式配置候補。
- 交易船、漂着物、洞窟への手掛かり等を短いイベントにできる。

採用条件:
- 港町イベントとコタンカイムの洞窟の接続理由として必要な場合に採用。
- 本編テンポを落とす場合は町内イベントへ統合する。

### C03 バトラスのとりで周辺
状態: **候補 / 未採用**

想定位置:
18「いしのまち」→19「バトラスのとりで」の間。

役割候補:
- 終盤に通常敵の強さが一段上がったことを見せる短い危険地帯。
- ダラボッチ、通常敵化したまじん、プリンキング等の終盤敵候補を配置できる。
- いしのまちで装備を整えた成果をすぐ試せる。
- バトラスの砦へ近づく緊張感を作る。

採用条件:
- 終盤レベル帯の通常戦闘量が不足した場合に採用。
- バトラスのとりで内部で十分な通常戦闘を確保できる場合は不採用。

## 6. 候補採用の判断基準
候補マップは以下のうち2つ以上を満たす場合に採用価値が高い。

1. 町イベントから次のダンジョンへの移動理由を自然につなぐ。
2. 既存25体の敵に適切な出現地域を与えられる。
3. 仲間の能力を実戦で見せられる。
4. 世界の地域差を表現できる。
5. 特殊ゲームプレイを短く効果的に入れられる。
6. 既存マップへ詰め込むよりテンポが良くなる。

逆に、単にプレイ時間を増やすだけなら追加しない。
