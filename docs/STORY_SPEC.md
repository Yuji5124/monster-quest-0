# Monster Quest 0 ストーリー仕様（公開版）

更新日: 2026-09-09

## 1. 基本方針
- 王道のレトロRPGとして序盤からしっかり遊べることを優先する
- 事件、探索、仲間との掛け合い、ボス攻略を前半から充実させる
- 終盤の違和感・異常演出は、それまでの普通の冒険との落差を活かす
- プレイヤーが少ないヒントから攻略法を考えるボス戦を取り入れる
- ジャンカードは本編クリア必須にせず、独立したサブゲームとして楽しめるようにする

## 2. 主要パーティ
- 主人公
- タロサ
- ミレイ

タロサとミレイは物語の途中で仲間になる。
ミレイはレインランドの姫であることを隠して旅に加わる。

## 3. 世界・地域
公開仕様で確認済みの主要地域：
- はじまりのまち：街道沿いの交易町
- ビーエのむら：山に囲まれた薬草・林業の村
- レインランドのまち：水と商業の城下町
- レインランドじょう：王家・政治の中心
- ザボンのむら：狩猟文化があり、タロサに関係する地域
- ポサロ城
- ふっかつのほこら

地域には生活・文化・他地域との関係を持たせ、単なる通過地点にしない。

## 4. 進行の考え方
- 町で事件や目的を知る
- フィールドを探索する
- ザコ戦や装備更新で成長する
- ダンジョンで仕掛け・探索を行う
- ボス戦では単純なレベルだけでなく攻略の気づきを用意する
- 仲間との会話や地域情報を通して世界を理解する

## 5. 終盤
- 終盤まで通常のレトロRPGとして成立させる
- 異常演出は終盤に限定し、段階的に強める
- 真相、最終入力内容、終盤ボスの詳細はこの公開リポジトリには記載しない

## 6. プレイ時間
- 目標：約5時間
- マップや会話を必要以上に膨らませない
- ジャンカード45枚の収集は本編プレイ時間を大きく引き伸ばす前提にしない

## 7. 実装時の禁止事項
- 未確定の設定をAIが勝手に確定しない
- 終盤ネタバレを公開画面・README・紹介素材に出さない
- ストーリー都合で主要キャラクターの確定設定を変更しない
