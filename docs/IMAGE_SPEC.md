# Monster Quest 0 ～幻の冒険の書～ 画像制作仕様

更新日: 2026-09-09

## 1. 全体方針
- 完全オリジナルの2Dピクセルアート
- FC後期〜初期SFCを思わせる、明るく丁寧なレトロファンタジー
- 既存ゲームの背景・構図・タイル・配色を直接模倣しない
- 高品質とは描き込み量を増やすことではなく、少ない色数・明確な形・統一感で見せること
- 通常プレイ中は王道RPGとして自然に見えることを優先する
- ネタバレ要素は通常画像・公開素材に含めない

## 2. 制作比率
- AIによる生成・実装：80%
- 人間による視覚調整：20%
- AIで大枠を作り、配置、色、輪郭、数ピクセル単位の違和感を人間が仕上げる

## 3. 正式キャラクター素材
以下は正式デザインを優先し、仮素材へ置き換えない。
- 主人公
- タロサ
- ミレイ

歩行スプライト基本仕様：
- 正面：3コマ
- 横：3コマ
- 後ろ：3コマ
- 左右は必要に応じて反転利用
- 3キャラクターで同一規格を使用する

## 4. NPC
- 基本NPC約10体をベースにする
- 髪色、服色、小物などの差分で量産可能にする
- 町ごとに完全新規キャラクターを大量制作しない

## 5. モンスター
- ゲーム内モンスター総数：25体
- 原作・ジャンカード等でデザインが確認できるものは、そのデザインを正として扱う
- 勝手な描き直し・装備追加・体型変更を避ける
- ゲーム用素材は背景透明PNGへ統一する
- 公開時のネタバレ対象は名称・姿を伏せる

## 6. マップ用タイル
基本タイルセットは制作済みとして扱う。

共通レイヤーの考え方：
- Ground
- GroundDetail
- Road
- Building
- Object
- Collision
- Event
- AbovePlayer

不足タイルは全エリア分を先に作らず、実装中に必要になった分だけ追加する。

## 7. マップ品質
- 草、道、木、岩、花、建物などに適度なバリエーションを持たせる
- 道や自然物を機械的な直線配置にしすぎない
- 木の葉や屋根などは `AbovePlayer` 相当の前景レイヤーで主人公の前に表示できるようにする
- 画面を過密にせず、移動しやすい余白を残す

## 8. 戦闘背景
戦闘背景は高品質な完成画像として制作し、必要に応じて追加する。

基本候補：
- 草原
- 森
- 洞窟
- 城 / 城下町周辺
- 雪原
- その他、物語進行で必要になる地域

戦闘背景は16bit的な過剰描写ではなく、FC後期の制約感を残した綺麗なピクセルアートを目指す。

## 9. UI
共通UI素材は制作済みとして扱う。
- ウィンドウ
- 選択カーソル
- 戦闘コマンド
- メニュー
- HP / MP表示

以降は既存UIを基準に拡張し、画面ごとに別デザインへ変えない。

## 10. ジャンカード
- 全45枚
- カード中央のメインビジュアルをゲーム用透明PNGへ変換して利用できる
- 元カードに存在しない手足、武器、模様、エフェクトを追加しない
- ネタバレ対象カードは公開時に伏せる

## 11. AI担当
- ChatGPT：画像仕様、画像生成、正式デザイン整理、素材変換指示
- Claude Code + Phaser Game Agent：読み込み、アニメーション、配置、ゲーム内表示
- Codex：表示崩れ、サイズ、パフォーマンス、モバイル表示の検証
- 人間：最終的な配置・ドット・色・見た目の20%調整

## 12. 最重要ルール
素材を先に無制限に増やさない。

ゲームを実装し、必要になった素材だけを追加する。
