# モンスタークエスト0 イベントシステム仕様

最終更新: 2026-09-10 23:46 JST

## 1. 目的
NPC会話、宝箱、ワープ、ボス、仲間加入、ストーリー演出を共通方式で扱い、マップごとの専用コード増殖と二重発火を防ぐ。

## 2. 基本イベントコマンド
- `message`
- `choice`
- `addItem`
- `removeItem`
- `addGold`
- `setFlag`
- `setSwitch`
- `transfer`
- `startBattle`
- `joinParty`
- `leaveParty`
- `playBgm`
- `playSe`
- `wait`
- `screenEffect`

必要なコマンドだけ段階的に実装する。

## 3. 共通イベント形式
```json
{
  "id": "event_start_chest_01",
  "trigger": "interact",
  "conditions": [],
  "once": true,
  "commands": [
    {"type": "message", "text": "たからばこを あけた！"},
    {"type": "addItem", "itemId": "item_kaifukuyaku", "count": 1},
    {"type": "setFlag", "flag": "chest.start_01", "value": true}
  ]
}
```

## 4. Trigger
最低限:
- `interact`: 話す / 調べる
- `touch`: 接触
- `enter`: エリア進入
- `auto`: 条件成立時
- `step`: 特定タイル

## 5. Condition
例:
- フラグON/OFF
- アイテム所持
- パーティ加入状態
- ボス撃破
- レベル条件
- マップ到達

条件はコードへ散在させずイベント側で読める形に寄せる。

## 6. 二重発火防止
- 実行中イベントは同一IDを再起動しない
- `once: true` は保存フラグを持つ
- Scene切替直前・戦闘開始直前に入力ロックする
- タッチ入力とキーボード入力の同時発火を防ぐ

## 7. NPC会話
- 会話本文はデータへ置く
- 基本2パターン程度
- 進行フラグで変化可能
- 生活感 / 地域情報 / 事件 / 噂 / 攻略ヒントを分散
- 未確定設定をAIが会話内で確定しない

## 8. 宝箱
- 開封状態を保存する
- 通常宝箱と特殊イベント宝箱を分ける
- 終盤の特殊宝箱は通常共通処理を破壊せず、イベントコマンドで表現する

## 9. ボス
- ボス専用AIや演出はBattleSystemへ最小限の拡張点を用意する
- ボス名による巨大な `if` 連鎖は禁止
- ボス撃破フラグを必ず保存する

## 10. 仲間加入
- 加入は `joinParty` + 進行フラグで管理
- タロサ / ミレイ加入イベントをScene固有コードへ閉じ込めない
- 再入場時に二重加入しない

## 11. マップ移動
- transfer中は入力ロック
- 移動先mapIdとspawnIdで指定する
- 座標を各イベントへ重複直書きしない

## 12. 終盤異常演出
- 実害のあるバグを起こさない
- セーブ破損・本当のフリーズ・無限ループ禁止
- GLITCH_SPEC.mdに従い、表示・音・画面効果の制御された演出として実装する

## 13. 完了条件
イベント追加時は最低限:
- 1回だけ動くべきものが1回だけ動く
- セーブ→ロード後も状態維持
- マップ再入場で破綻しない
- iPhoneタッチで二重発火しない
- 進行不能にならない
