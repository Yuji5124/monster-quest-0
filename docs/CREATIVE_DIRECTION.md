# モンスタークエスト0 クリエイティブ方針

最終更新: 2026-09-11 JST

## 1. 作品の狙い
『モンスタークエスト0 ～幻の冒険の書～』は、FC後期〜初期SFCのRPGを思わせる懐かしさを入口にしながら、現代の子どもにも新鮮に感じられる作品を目指す。

既存RPGの表面だけをなぞるのではなく、元設定・ストーリー・登場人物の人生がつながる感覚を大切にする。

## 2. 全編を同じ密度で作り込まない
制作時間を増やしすぎないため、すべての町・NPC・演出を同じ密度で豪華にしない。

### 特に丁寧に描く場所
1. **物語の始まり**
2. 主人公・タロサ・ミレイ・わたべ等、主要人物の人生が交差する場面
3. **「もういちど」で始まりの場所へ戻る場面**
4. エンディングと終盤の感情的な山場

それ以外は、短くても印象に残る表現を優先する。

## 3. 「始まりを濃くする」方針
始まりは作品内でも最も丁寧に作る区間の一つ。

ただし、濃くする = 長くする、ではない。

優先する表現:
- 約5秒の短い異常
- 夜の「はじまりのばしょ」
- 焚き火
- 風・足音・環境音
- 無音とBGMの切り替え
- 夜→昼の変化
- 少ない台詞
- 主人公の立ち止まり・視線・反応
- はじまりのまちに入ったときの安心感／開放感
- 最初のNPCとの自然な会話
- 最初のフィールド移動
- 初戦闘までの小さな緊張

長文説明、ムービー尺、NPC人数、移動距離で密度を作らない。

冒頭約5秒は、裏設定上は主人公の元世界からMQ0へ迷い込む瞬間の断片。初見では意味を説明せず、最後に元世界を正常表示して回収する。

## 4. 主人公
- 主人公は男性。
- 本来は別のモンスタークエスト作品／別バージョン世界にいた、特別ではないNPCだった人物。
- 世界間の異常でMonster Quest 0へ迷い込む。
- 最初から真相を知る人物にはしない。
- 「選ばれし勇者」の物語ではなく、何者でもなかった人物が中心になっていく流れを大切にする。
- 最後まで特別な血筋や生まれつきの勇者設定にはしない。
- 真の最終解決後は元世界へ戻り、本来のNPCとしての立場へ帰る。

この出自は序盤で直接説明せず、最後に操作そのものを使って意味がつながるようにする。

## 5. 二重構造
### 子どもが見る表層
- 知らない場所で目覚める
- 町へ行く
- 仲間に出会う
- モンスターと戦う
- 世界の異変へ立ち向かう
- 一度失敗しても、仲間と覚えたまま「もういちど」挑む
- 最後は元いた場所へ帰る

普通のRPGとして理解できる。

### 大人が考察できる裏層
- 主人公は別世界の元NPC
- Monster Quest 0には異なるバージョンの断片が混ざっている
- 異なる世界由来の敵・ボスが混在する
- 最初の短い異常は元世界から迷い込む瞬間
- 終盤の偽リセットと記憶継承
- 同じ焚き火へ戻る構造
- 最後に操作できなくなりNPCへ戻る主人公

どちらか一方を理解しないと物語が成立しない構成にはしない。

## 6. メタ表現
プレイヤーへ直接語りかけるメタ会話は基本的に使わない。

避ける:
- 「プレイヤー」
- 「ゲーム」
- 「バージョン」
- 「セーブデータ」
- 「プログラム」
などを登場人物が真相説明として直接話すこと。

代わりに、世界観の中では説明しきれない違和感・記憶・伝承・敵の混在・**操作できる／できないというゲーム体験そのもの**から考察できる形にする。

終盤の偽セーブ消失も登場人物が「セーブデータ」と説明せず、プレイヤー側の画面体験として見せる。

## 7. 元設定への敬意
- 『こどもだってつらいよ』由来の設定・名称・キャラクター・カード資料を雑に消費しない
- 原資料で確認できる情報はAIの創作より優先する
- 原作未確定事項を「原作設定」として断定しない
- Monster Quest 0独自採用は、原作確定情報と区別する
- デスタロッサ等、別作品側の設定を安易にそのまま登場させない
- 別作品／別バージョン由来の要素が存在する場合は、MQ0世界の混線という裏構造と整合させる
- 作者ケイトアローとの関係は未確定部分を残し、AIが全能の神等へ勝手に設定しない

## 8. レトロ表現
懐かしさは少し大げさに表現してよい。
- 短いNPC台詞
- シンプルなコマンドUI
- ドット歩行
- レベルアップの喜び
- 少ないヒントから攻略法を見つける
- 子どもが「昔のゲームってこうだったの？」と感じる演出

ただし既存作品のマップ・UI・構図・モンスターを直接コピーしない。

## 9. ビジュアルの二層構造
### レトロを維持
- フィールド
- 歩行スプライト
- UI
- コマンド戦闘の基本表示

### 現代的に綺麗にする
- 戦闘背景
- 探索 / イベント背景
- 重要シーンの一枚絵的表現

この差を作品の個性として使う。

## 10. NPC
NPCは攻略装置ではなく、その土地で生活している人として扱う。
- 生活
- 仕事
- 家族
- 地域文化
- 噂
- 他地域との関係
を短い会話へ混ぜる。

重要人物の説明を町人全員に繰り返させない。
主要人物に興味がない、ほとんど知らない、日常の方が大事という住民も自然に置く。

**主人公自身が元世界ではNPCだったという事実は、NPCを「背景の人」ではなく人生を持つ人物として扱う本作の裏テーマにもつなげる。**

NPC人数はマップ規模・地域の役割・滞在時間を決めてから必要人数を決める。

## 11. マップ / ダンジョン
町・村・城・ダンジョンは、広さそのものを価値にしない。
一方で、単純に半分へ縮小することも目的にしない。

- 地域の個性が伝わること
- 無意味な移動時間を増やさないこと
- 探索する楽しさが残ること
- 重要イベントに必要な間を取れること
- 通常地域と重要地域に強弱があること

を基準に規模を再設計する。

「はじまりのばしょ」は小規模でよいが、通常地域より演出密度を高くする。冒頭と「もういちど」後で同じ場所を使うため、焚き火や地形の構図を記憶に残るようにする。

## 12. 攻略
主要ボスは、レベルを上げるだけでなく少ないヒントから攻略法へ気づく余地を作る。
答えをNPCがそのまま読み上げる構成は避ける。

オロチゾンビ1回目→「もういちど」→わたべ参加→再戦は、通常のレベル上げだけでは到達できない裏ワザ的な最終攻略として扱う。

## 13. 終盤
異常演出は単なるネタや驚かせ要素ではなく、作品世界とストーリーに意味があるものとして扱う。
本当のデータ破損・フリーズ・進行不能は絶対に起こさない。

導入の約5秒の異常は、本格崩壊を先取りするのではなく、主人公が別世界から迷い込んだ痕跡として扱う。

終盤は:
- オロチゾンビ1回目
- バグ／フーフー
- データが消えた／初めからになったように見える偽リセット
- 「もういちど」
- 同じ焚き火へ、仲間と記憶を持ったまま戻る
- わたべ参加
- 再戦／真の最終解決

という流れを核にする。

## 14. エンディングの感情
真の最終解決後、主人公はわたべと元世界へ帰らなくてはならない。
ミレイは主人公に恋心を抱いており、二人は別れる。

ここを長い恋愛説明にせず、短い言葉・間・表情／動きで伝える。

最後に主人公は元世界でNPCへ戻る。別の勇者に話しかけられ、短いNPC台詞を返すことで真相を見せる。

目指す余韻は、**「誰も知らないNPCだった男が、一度だけ主人公になった冒険」**。
MQ0で起きた旅や仲間との記憶は、元に戻ったから無意味だった、とは描かない。

## 15. プレイ時間
作品全体の目標は以下とする。
- **初見クリア: 約4時間30分**
- **NPC会話・探索など寄り道込み: 約5時間30分**

プレイ時間はマップを機械的に縮小して合わせるのではなく、戦闘、探索、会話、イベント、移動のテンポ全体で調整する。

始まりと終盤は通常区間より丁寧にするが、全体時間を圧迫する長い説明区間にはしない。

## 16. 制作判断
新しい演出・マップ・設定を追加するときは、次を確認する。
- 物語に必要か
- プレイヤー体験を良くするか
- 初見約4時間30分 / 寄り道込み約5時間30分の完成を遠ざけないか
- 既存の確定設定を壊さないか

「作れるから追加する」ではなく「作品に必要だから追加する」。

## 17. AIへの最重要指示
AIは作品を勝手に豪華化・長編化・設定追加しない。
旧女性主人公設定を復活させない。
開始直後の短いバグを削除して「完全に普通の開始」へ戻さない。
開始直後へ偽セーブ消失を戻さない。
終盤の「もういちど」を単純なNew Game／周回プレイへ変更しない。
プレイヤーへ直接メタ説明を追加しない。
主人公を実は王子／伝説の勇者／特別な血筋等へ変更しない。
旧マップ規模、旧NPC人数、旧「半分」案を確定仕様として勝手に復活させない。
重要場面には丁寧さを使い、その他は簡潔にまとめ、モンスタークエスト0を最後まで完成させることを優先する。
