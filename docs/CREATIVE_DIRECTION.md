# モンスタークエスト0 クリエイティブ方針

最終更新: 2026-09-12 JST

## 1. 作品の狙い
『モンスタークエスト0 ～幻の冒険の書～』は、FC後期〜初期SFCのRPGを思わせる懐かしさを入口にしながら、現代の子どもにも新鮮に感じられる作品を目指す。

既存RPGの表面だけをなぞるのではなく、元設定・ストーリー・登場人物の人生がつながる感覚を大切にする。

## 2. 全編を同じ密度で作り込まない
すべての町・NPC・演出を同じ密度で豪華にしない。

### 特に丁寧に描く場所
1. **物語の始まり**
2. 主人公・タロサ・ミレイ・わたべ等、主要人物の人生が交差する場面
3. **「もういちど」でNo.01の焚き火へ戻る場面**
4. 真の終盤とエンディング

それ以外は、短くても印象に残る表現を優先する。

## 3. 「始まりを濃くする」方針
濃くする = 長くする、ではない。

優先する表現:
- 約5秒の短い異常
- No.01「はじまりのばしょ」夜版
- 焚き火
- 風・足音・環境音
- 無音とBGMの切り替え
- 夜→昼の変化
- 少ない台詞
- 主人公の立ち止まり・視線・反応
- No.02「はじまりのまち」へ入ったときの安心感／開放感
- 最初のフィールド移動と初戦闘

長文説明、ムービー尺、NPC人数、移動距離で密度を作らない。

冒頭約5秒は、裏設定上は主人公が元世界からMQ0へ迷い込む瞬間の断片。初見では意味を説明せず、最後に元世界を正常表示して回収する。

## 4. 主人公
- 主人公は男性。
- 本来は別のモンスタークエスト作品／別バージョン世界にいた、特別ではないNPCだった人物。
- 世界間の異常でMonster Quest 0へ迷い込む。
- 最初から真相を知る人物にはしない。
- 特別な血筋や生まれつきの勇者にはしない。
- 本来NPCだった人物が、この一度の冒険では主人公になったこと自体を核にする。
- 真の最終解決後は元世界へ戻り、本来のNPCとしての立場へ帰る。

## 5. 二重構造
### 子どもが見る表層
- 知らない場所で目覚める
- 町へ行く
- 仲間に出会う
- モンスターと戦う
- 世界の異変へ立ち向かう
- 一度失敗しても、仲間と覚えたまま「もういちど」挑む
- 最後は元いた場所へ帰る

普通のRPGとして理解できる。

### 大人が考察できる裏層
- 主人公は別世界の元NPC
- MQ0には異なるバージョン／世界の断片が混ざっている
- 異なる世界由来の敵・ボスが混在する
- 冒頭約5秒は元世界から迷い込む瞬間
- 終盤の偽リセットと記憶継承
- 同じNo.01焚き火へ戻る構造
- 最後に操作できなくなりNPCへ戻る主人公

どちらか一方を理解しないと物語が成立しない構成にはしない。

## 6. メタ表現
登場人物がプレイヤーへ直接語りかけるメタ会話は基本的に使わない。

避ける言葉:
- 「プレイヤー」
- 「ゲーム」
- 「バージョン」
- 「セーブデータ」
- 「プログラム」

代わりに、違和感・記憶・伝承・敵の混在・**操作できる／できないというゲーム体験そのもの**から考察できる形にする。

終盤の偽データ消失も、登場人物が「セーブデータ」と説明せず、プレイヤー側の画面体験として見せる。

## 7. 元設定への敬意
- 『こどもだってつらいよ』由来の設定・名称・キャラクター・カード資料を雑に消費しない
- 原資料で確認できる情報はAI創作より優先する
- 原作未確定事項を「原作設定」として断定しない
- MQ0独自採用は原作確定情報と区別する
- デスタロッサ等、別作品側の設定を安易にそのまま登場させない
- 別世界由来の要素はMQ0世界の混線という裏構造と整合させる

## 8. ジャンカードとの距離
- ジャンカードは全45枚の独立サブゲーム。
- 本編攻略必須にしない。
- **序盤〜中盤のNPCや本編イベントで、カードの頭文字・並び・たびのあいことば・秘密を早期に前面化しない。**
- 普通のガチャ／収集要素として楽しめる表層を最後まで守る。

## 9. レトロ表現
- 短いNPC台詞
- シンプルなコマンドUI
- ドット歩行
- レベルアップの喜び
- 少ないヒントから攻略法を見つける

既存作品のマップ・UI・構図・モンスターを直接コピーしない。

## 10. ビジュアルの二層構造
### レトロを維持
- フィールド
- 歩行スプライト
- UI
- コマンド戦闘の基本表示

### 現代的に綺麗にする
- 戦闘背景
- 探索 / イベント背景
- 重要シーン

## 11. NPC
NPCは攻略装置ではなく、その土地で生活している人として扱う。
生活、仕事、家族、地域文化、噂、他地域との関係を短い会話へ混ぜる。

重要人物の説明を町人全員に繰り返させない。
NPC人数はマップ規模・地域の役割・滞在時間を決めてから必要人数を決める。

## 12. マップ / ダンジョン
- 正式番号はNo.01〜No.20。
- 全体ワールドマップ・主要地域配置は維持。
- 内部マップはコンパクト化。
- 広さそのものを価値にしない。
- 重要地域と通常地域に強弱をつける。
- No.01は小規模だが、初回と「もういちど」後の2回で意味が変わる重要舞台。

## 13. 攻略
主要ボスはレベル上げだけでなく、少ないヒントから攻略法へ気づく余地を作る。
答えをNPCがそのまま読み上げない。

オロチゾンビは裏ボス。「もういちど」→わたべ→再戦は裏ワザとして扱う。

## 14. 終盤
- 異常演出は単なるネタではなく、世界混線と主人公の出自へつなげる。
- 実データ破損・本当のフリーズ・進行不能は禁止。
- 「もういちど」はNew Gameではなく同一冒険の最終章。
- No.01へ戻ったとき、同じ場所・違う状況で感情を作る。
- 真の終盤後、主人公とわたべは元世界へ帰る。
- ミレイとの別れは長い告白ではなく短い台詞・間で伝える。
- 最後は主人公を操作不能にし、別の勇者から話しかけられるNPCとして見せる。

## 15. プレイ時間
- 初見クリア: **約4時間30分**
- 寄り道込み: **約5時間30分**

戦闘、探索、会話、イベント、移動のテンポ全体で調整する。

## 16. AIへの最重要指示
AIは作品を勝手に豪華化・長編化・設定追加しない。
旧女性主人公、旧マップ番号、旧カード総数、序盤の偽セーブ消失、カード秘密の早期示唆を復活させない。
「もういちど」をNew Gameにしない。
オロチゾンビを通常ラスボス扱いへ戻さない。
重要場面には丁寧さを使い、それ以外は簡潔にまとめ、最後まで完成させることを優先する。
