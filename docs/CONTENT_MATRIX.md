## 1. ステータス定義
- `CONFIRMED`：仕様として確定
- `PRODUCED`：素材制作済みとユーザー確認済み
- `IN_REPO`：GitHub内に実ファイル存在を確認済み
- `IMPLEMENTED`：ゲームへ組み込み済み
- `TESTED`：実際に操作確認済み
- `POLISHED`：人間の視覚調整済み

AIは `PRODUCED` を `IN_REPO` や `IMPLEMENTED` と読み替えない。
