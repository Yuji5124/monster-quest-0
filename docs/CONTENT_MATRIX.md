# モンスタークエスト0 コンテンツ進捗表

最終更新: 2026-09-11 JST

この表は「設定済み」「会話原案あり」「素材制作済み」「GitHub配置済み」「Phaser実装済み」を混同しないための進捗管理表。

## ステータス定義
- `CONFIRMED`: 設定確定
- `DIALOGUE_DRAFT`: 会話原案あり。実装人数・台詞は再編集対象を含む
- `DIALOGUE_READY`: 実装用会話として再編集済み
- `ASSET_READY`: ChatGPT等で素材制作済み
- `IN_GITHUB`: 正式パスへ配置済み
- `IMPLEMENTED`: Phaser実装済み
- `PLAYTESTED`: 実機 / ブラウザで確認済み
- `TBD`: 未確定

## 最新スコープ方針
- 目標プレイ時間: 約5時間
- 町・村のサイズは従来案より全体的に約半分程度へ圧縮
- NPC人数も従来案より全体的に約半分程度へ圧縮
- 旧12人 / 15人 / 20人等の会話案は素材として活かすが、その人数をそのまま実装しない
- 序盤にリセット / 偽セーブ消失演出を置かない
