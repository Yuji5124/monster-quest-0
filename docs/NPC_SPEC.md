# モンスタークエスト0 NPC・会話仕様

最終更新: 2026-09-24 JST

このファイルはNPC会話の設計ルールを定義する正本。
**実際の台詞本文・地域別NPC一覧は `NPC_DIALOGUE_MASTER.md` を正とする。**

## 1. 現行方針

町・村・城内部の縮小後サイズに合わせ、NPC会話を2026-09-24に全面再構成した。

旧大人数版・旧「半分」版・過去チャットの個別会話案は参考素材へ降格する。
実装時は以下の順で優先する。

1. `PLAY_ORDER_SPEC.md`
2. `STORY_FLOW.md`
3. `NPC_DIALOGUE_MASTER.md`
4. 本ファイル
5. 旧会話案

目標プレイ時間:
- 初見 約4時間30分
- 寄り道込み 約5時間30分

## 2. 最重要ルール

- **同じ重要情報を複数NPCが繰り返さない。**
- 1人につき主題は原則1つ。
- 全員を攻略ヒント役にしない。
- 全員を主要人物の説明役にしない。
- 主人公たちへ特に興味がない住民も置く。
- タロサについて詳しく話すNPCはザボンでも少数に限定する。
- ミレイの正体は確定開示前にNPCが断定しない。
- ジャンカードは通常本編では独立サブゲームとして扱い、秘密・暗号・終盤用途をNPCが早出ししない。
- 序盤の世界異常会話は少数。終盤へ近づくほど認識者を増やす。
- 店主は店の話だけでもよい。
- 重要NPCのみイベント前後の差分を持つ。
- 固有名詞・アイテム・魔法は正式採用済みのみ使用する。
- 未確定事項をNPCが事実として説明しない。

## 5. 主要人物会話の扱い

### 主人公
- 序盤は無名の旅人。
- 町中から勇者扱いされない。
- 王も「選ばれた者」ではなく「自分の目で異変を見てきた旅人」として依頼する。
- 実際の行動の積み重ねで勇者らしくなっていく。

### タロサ
- 08で登場。
- 09で一時参加。
- 09攻略後に正式同行。
- 村人全員がタロサの話をする構成は禁止。
- 19バトラス前は毒の矢を本人の努力の成果として見せる。

### ミレイ
- 10で初登場。
- 11から同行。
- 姫であることは本人が明かすまで一般NPCに断定させない。
- 14以降、NPCの説明ではなく景色・記録・本人の記憶で過去を戻していく。
- 18で世界の矛盾と記憶がつながる。

### わたべ
- 通常の町NPCが序盤〜中盤から重要人物として語らない。
- 「もういちど」以降の特殊参加まで伏せる。

## 6. 会話文体

- 1ページ1〜3行を基本。
- 1行を長くしすぎない。
- ひらがな中心でも読みやすさを優先する。
- 説明文ではなく会話として自然にする。
- 同じNPCが長文設定説明をしない。
- 子どもNPCは子どもの関心を話す。
- 職人NPCは仕事の話をする。
- 重要情報は生活の中へ混ぜる。

## 7. 再訪

- はじまりのまち

## 8. 実装

NPC会話をSceneコードへ散在させず、データ + EventSystemで管理する。

参照:
- `NPC_DIALOGUE_MASTER.md`
- `DATA_CONTRACTS.md`
- `EVENT_SYSTEM_SPEC.md`
- `NAMING_CONVENTIONS.md`
- `PLAY_ORDER_SPEC.md`

基本event:
- `message`
- `setFlag`
- `addItem`
- `transfer`
- `startBattle`

進行フラグで会話variantを切り替える。

## 9. NPC画像

基本NPCは `assets/characters/npc/` へ配置する。
2026-09-24時点でNPC用歩行スプライト候補を追加制作中。

主人公の正式歩行スプライトと同様、
- 4方向
- 各方向3フレーム
- ドット密度を統一
- 背景透明
を基本実装形式とする。

同じNPCグラフィックを複数地域で色替え・小物替えして使うことは可能。
ただし重要人物は固有グラフィックを優先する。

## 10. AI制作手順

1. `PROJECT_STATUS.md`
2. `PLAY_ORDER_SPEC.md`
3. `STORY_FLOW.md`
4. `NPC_DIALOGUE_MASTER.md`
5. 対象マップ仕様
6. NPC素材一覧

の順で確認する。

新しい会話を追加する場合、
**「その情報をすでに誰かが話していないか」**
を最初に確認する。

AIが独自に新しい重要設定、重要アイテム、王家設定、ボス設定を確定してはいけない。
