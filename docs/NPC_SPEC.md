# Monster Quest 0 NPC仕様

更新日: 2026-09-09

## 1. 基本方針
- NPCは単なるヒント表示装置にしない
- 村・町ごとの生活、仕事、文化、人間関係、他地域とのつながりを感じさせる
- 同じ地域のNPC同士で話題が完全にバラバラにならないようにする
- 一人あたり基本2パターン程度の台詞を用意する

## 2. 会話の種類
NPC会話は以下を混ぜる。
- 生活会話
- 地域情報
- 事件に関する話
- 噂
- 攻略ヒント
- 仲間キャラクターに関する反応
- 進行後の差分会話

全員が攻略ヒントを話す状態にはしない。

## 3. 基本NPC素材
汎用NPC基本10体をベースにする。
- 男性
- 女性
- 老人
- 老婆
- 子ども
- 商人
- 兵士など

必要に応じて服色、髪色、小物、帽子などを変更して地域差を出す。
主要キャラクターは汎用NPCから作らず、専用素材を使用する。

## 4. 地域性
### はじまりのまち
- 街道と交易の話題
- 旅人、商人、周辺地域の情報

### ビーエのむら
- 薬草
- 林業
- 山の暮らし

### レインランド
- 水
- 商業
- 城下町
- 王家や城に関する話題

### ザボンのむら
- 狩猟
- 周辺の自然
- タロサに関係する地域性

## 5. 実装方針
- 会話本文をコードへ直書きしすぎない
- NPC IDと会話IDを分離できる構成を優先する
- ストーリー進行フラグによる会話差分を許容する
- 重要会話はイベント二重発火を防止する

## 6. 禁止事項
- すべてのNPCを長文にしない
- 現代的なネット用語を無目的に使わない
- 地域設定と矛盾する会話を入れない
- 未公開の終盤ネタバレを通常NPCへ話させない
