# モンスタークエスト0 キャラクター成長仕様

最終更新: 2026-09-11 JST

このファイルは主人公・タロサ・ミレイ・特殊参加キャラクターの成長と習得方針を整理する正本。最終数値は未確定部分が多いため、AIが推測で固定しない。

## 1. 基本方針
- 主要パーティは主人公・タロサ・ミレイの3人。
- 約5時間のゲームとして、レベルアップの間隔を長くしすぎない。
- レベル上げだけで全ボスを押し切る設計にはしない。
- キャラクターごとの差は、装備・魔法・役割で分かりやすく出す。
- 最終HP / MP / 攻撃 / 防御 / 素早さ / EXP曲線はTBD。

## 2. 主人公
確定事項:
- 女性勇者風。
- 剣を使用。
- 固有魔法「エレキテル」を覚える。
- 勇者装備に関係する中心人物。

ゲーム上の役割:
- 物理と魔法の中間型を基本にする。
- 初見プレイヤーでも扱いやすい基準キャラクター。

最終成長率・習得レベルはTBD。

## 3. タロサ
確定事項:
- 物語途中で加入。
- 弓を使用。
- 強さを求める人物。
- ザボンのむらに関係する。

ゲーム上の役割:
- 主人公と完全に同じ性能にしない。
- 攻撃・速度・補助等のどこに特色を置くかは最終バランス調整で確定する。

加入レベル・最終習得表はTBD。

## 4. ミレイ
確定事項:
- 物語途中で加入。
- レインランドの姫。
- 身分を隠して旅に加わる。

ゲーム上の役割:
- 主人公・タロサとは異なる魔法／支援面の役割を持たせる方向。
- 正式な魔法配分・装備制限はTBD。

## 5. わたべ
- 主要3人パーティとは別管理。
- イベント／特殊参加キャラクター。
- 固有攻撃「とくだいヒット」を使用できる。
- 通常加入キャラクターと同じレベル成長テーブルを必須としない。

## 6. 採用済み魔法プール
- ライフ
- リライフ
- ヒート
- ビーター
- ビーテスト
- ムーブ
- ミスト
- パニック
- エレキテル
- アイスーン
- ダイダイン

主人公のエレキテル以外の正式なキャラクター別配分・習得レベルは、ユーザー確定後にこの表へ追加する。

## 7. レベル帯
- デーマス戦はLv15程度を目安とする。
- 最終地点はLv20前後を一つの目安として扱えるが、最終調整値ではない。
- 目標プレイ時間約5時間との整合を優先する。

## 8. データ項目
各キャラクターに最低限以下を持たせる。
- `id`
- `name`
- `level`
- `exp`
- `hp` / `maxHp`
- `mp` / `maxMp`
- `attack`
- `defense`
- `speed`
- `equipment`
- `learnedMagic`
- `learnTable`

未確定値はnull / TBD。

## 9. バランス確認
- 新規加入者が弱すぎて即レベル上げ必須にならない。
- 3人の役割が重複しすぎない。
- 回復役が倒れた瞬間に詰む設計にしない。
- 魔法を覚えても使う意味がないMP設計にしない。
- 通常敵との戦闘が長期化しすぎない。

## 10. 禁止
- 未確定習得レベルをAIが勝手に正式化する。
- 原作側の未確認設定をMQ0の確定設定として記載する。
- 主人公・タロサ・ミレイを4人以上の常設パーティへ変更する。
