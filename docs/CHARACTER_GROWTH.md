# モンスタークエスト0 キャラクター成長仕様

最終更新: 2026-09-24 JST

このファイルは主人公・タロサ・ミレイ・特殊参加キャラクターの成長と習得方針を整理する正本。最終数値は未確定部分が多いため、AIが推測で固定しない。

## 1. 基本方針
- 主要パーティは主人公・タロサ・ミレイの3人。
- 目標プレイ時間は初見約4時間30分 / 寄り道込み約5時間30分。
- レベルアップの間隔を長くしすぎない。
- レベル上げだけで全ボスを押し切る設計にはしない。
- キャラクターごとの差は、装備・魔法・役割で分かりやすく出す。
- 主人公・タロサ・ミレイは、加入時を含め**全員Lv1・EXP0から開始**する。
- 最終HP / MP / 攻撃 / 防御 / 素早さ / EXP曲線はTBD。

## 2. 主人公
### 最新確定事項
- **男性**。
- 本来は別のモンスタークエスト作品／別バージョン世界にいた**ただのNPCだった人物**。
- 最初から選ばれた勇者ではない。
- 世界間の異常によってMonster Quest 0へ迷い込む。
- 「はじまりのばしょ」で焚き火のそばに倒れている／眠っている状態から物語が始まる。
- 自分がなぜこの世界にいるのか完全には理解していない。
- 物語を通して、何者でもなかった人物が中心人物になっていく構造を重視する。
- 固有魔法「エレキテル」は採用済み能力として維持する。
- 原則ほとんど喋らず、まとまった会話への参加はNo.18いしのまちとオロチゾンビ初回戦を基準に絞る。いしのまちでは「ここまで歩いてきたことは本当だ」と自分の足で生きた時間を語り、オロチゾンビ初回戦では仲間を守る行動で意思を示す。

### ゲーム上の役割
- 初見プレイヤーが扱いやすい基準キャラクター。
- 物理と魔法の中間型を基本方向とする。
- ただし「勇者だから万能」という説明にはしない。
- 勇者装備との最終的な関係・装備可能範囲はTBDとして、物語上の整合を確認して決定する。

### アート
- 旧女性勇者風デザインは現行主人公設定と不整合。
- 旧 `hero_walk.png` はそのまま正式実装しない。
- 最新男性主人公の正式歩行スプライトは2026-09-19にCURRENT化済み(`assets/characters/playable/protagonist_walk.png`、詳細は`ASSET_INDEX.md` §2)。

最終成長率・習得レベルはTBD。

## 3. タロサ
確定事項:
- No.08ザボンのむらに関係する狩人で、魔物討伐経験者が多い地域の出身。
- 青い逆立った髪、尖った耳、弓を使用。
- 努力すれば強くなれ、強くなれば守れると信じる。
- No.09いわやまのどうくつで一時参加し、主人公との共闘後に正式同行する。
- No.19バトラス戦では毒の矢が正規攻略の鍵となる。主人公・ミレイではなくタロサだから倒せる見せ場にする。
- 普段は短く率直に話す。重要場面だけ、溜め込んだ言葉を通常会話の2〜3倍程度まで話せるが、長演説にはしない。
- オロチまおう直前には、世界の異常が努力を飛び越える力を与えることへ憤る。ただしバトラスで自分の矢が届いた事実を認め、「だから、もっと先まで行ける」と前向きに決める。帰る場所であるザボンを持ちながら、今はさらに先へ進む人物とする。

ゲーム上の役割:
- 主人公と完全に同じ性能にしない。
- 攻撃・速度・補助等のどこに特色を置くかは最終バランス調整で確定する。

加入時Lv1は確定。最終習得表はTBD。

### アート
正式歩行スプライトは2026-09-19にCURRENT化済み(`assets/characters/playable/tarosa_walk.png`、青い髪・エルフ耳・弓と矢筒・緑のスカーフ。詳細は`ASSET_INDEX.md` §2)。弓使用という確定事項と一致する。

## 4. ミレイ
確定事項:
- No.10かくれざとで主人公・タロサと出会う。ここでは魔法を覚えたばかりで、親しくなりつつも身分を隠す。
- No.11みずうみの古城の古代文字／知識を読める唯一の人物として同行を受け入れ、ここから3人パーティーになる。
- レインランドの姫。
- 身分を隠して旅に加わる。
- No.14ポサロ城以降、自分の過去と現在の世界に一致しない記憶を少しずつ思い出す。
- No.18には過去だけでなく未来らしい断片も約25%見え始め、魔法を覚えたのでなく思い出している感覚を持つ。オロチまおう直前には、自分の意志でレインランド城へ帰ると決める。「戻される」のではなく、自分で帰ることを重視する。

ゲーム上の役割:
- 主人公・タロサとは異なる魔法／支援面の役割を持たせる方向。
- 正式な魔法配分・装備制限はTBD。

### アート
正式歩行スプライトは2026-09-19にCURRENT化済み(`assets/characters/playable/mirei_walk.png`、紫髪・紫目・白と金のフード付きローブ。詳細は`ASSET_INDEX.md` §2)。「レインランドの姫」設定と矛盾しない。

## 5. わたべ
- 主要3人パーティとは別管理。
- イベント／特殊参加キャラクター。
- 固有攻撃「とくだいヒット」を使用できる。
- 通常加入キャラクターと同じレベル成長テーブルを必須としない。
- 終盤の解決に関わる重要人物。

## 5.1 終盤後の人物関係

- 真の決着後、主人公は`ここに のこる`か`もとの せかいへ かえる`かを選ぶ。どちらのルートも、主人公・ミレイ・タロサの旅と記憶をなかったことにしない。
- レイはどちらの未来にも生まれる。隠しボス討伐時点でミレイは妊娠していない。タロサをレイの父親にせず、父親となる人物は本編に登場させない。
- 残留ルートの主人公は、世界が修復される過程で混線由来の存在として徐々に消えていく。帰還ルートの主人公は本来のNPCへ戻ったように見えてから、MQ0の記憶を持って自分の意思で歩き出す。
- 選択条件・演出・台詞・レイ誕生までの時系列・各キャラクターの終盤後能力はTBD。旧「ミレイは出産時に亡くなり、主人公がレイを育てる」案は**SUPERSEDED**。

## 5.2 タロサの本編外の将来

- MQ0本編にデスタロッサ本人を登場させない。
- 本編後、タロサが強さを求め続け、悪魔から「限界をなくす力」を示されることで後のデスタロッサへつながる。本編に置くのは、仲間を裏切る悪堕ちの予告ではなく、さらに先を目指す前向きな伏線だけである。詳細な時期・表現はTBD。

### 11.9 実戦闘への接続
`BattleScene`は`enemy.devPlayer`（デーマス等の単独確認用ダミー）が無い場合、
実際の加入パーティ(`partySystem`)＋現在のレベル(`characterProgression`)＋自動装備
＋習得済み魔法から`BattleSystem`の戦闘者を組み立てる(`buildPartyCombatant`)。
2〜3人パーティでは、生存中の全メンバーが1人ずつコマンドを入力してから敵が行動する
(`BattleSystem`の複数アクター対応)。どうぐコマンドは実際の所持品(`Inventory`)を消費する。
