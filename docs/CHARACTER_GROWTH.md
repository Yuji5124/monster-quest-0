# モンスタークエスト0 キャラクター成長仕様

最終更新: 2026-09-22 JST

このファイルは主人公・タロサ・ミレイ・特殊参加キャラクターの成長と習得方針を整理する正本。最終数値は未確定部分が多いため、AIが推測で固定しない。

## 1. 基本方針
- 主要パーティは主人公・タロサ・ミレイの3人。
- 目標プレイ時間は初見約4時間30分 / 寄り道込み約5時間30分。
- レベルアップの間隔を長くしすぎない。
- レベル上げだけで全ボスを押し切る設計にはしない。
- キャラクターごとの差は、装備・魔法・役割で分かりやすく出す。
- 主人公・タロサ・ミレイは、加入時を含め**全員Lv1・EXP0から開始**する。
- 最終HP / MP / 攻撃 / 防御 / 素早さ / EXP曲線はTBD。

## 2. 主人公
### 最新確定事項
- **男性**。
- 本来は別のモンスタークエスト作品／別バージョン世界にいた**ただのNPCだった人物**。
- 元世界では、物語の中心でも選ばれた勇者でもなく、決められた場所と役割の中で生きていた。
- 心の奥では「勇者になりたい」「自分で行き先を決めたい」という自由への憧れを持っていた。
- 世界間の異常によってMonster Quest 0へ迷い込み、NPCとしての限界が外れ、この世界で一度だけ主人公になる。
- 序盤では自分の出自や世界の仕組みを理解していない。
- 最後まで特別な血筋や生まれつきの勇者にはしない。
- 固有魔法「エレキテル」は採用済み能力として維持する。

### ゲーム上の役割
- 初見プレイヤーが扱いやすい基準キャラクター。
- 物理と魔法の中間型。
- 「勇者だから万能」ではなく、冒険の中で勇者と呼ばれるようになる人物として描く。

### 真の最終解決後
- 最終選択は主人公本人の未来選択として扱う。
- 「ここに のこる」: MQ0世界に残り、ミレイとレインランドへ戻る。後に娘「レイ」が生まれ、ミレイは出産時に亡くなる。主人公がミレイの名を残すため娘を「レイ」と名付け、育てる。
- 「もとの せかいへ かえる」: わたべと元世界へ帰り、本来のNPCへ戻る。MQ0での冒険の記憶は残り、最後はプレイヤーから操作できなくなることで元NPCだったことを示す。
- 出産・死・命名理由は本編中に長文説明せず、未来描写や余韻で示す。

### アート
- 旧女性勇者風デザインは現行主人公設定と不整合。
- 旧 hero_walk.png は正式実装しない。
- 最新男性主人公の正式歩行スプライトは assets/characters/playable/protagonist_walk.png。

最終成長率等の数値は別途TBD。

## 3. タロサ
### 最新確定事項
- 物語途中で加入。青い髪・尖った耳・弓を使う。
- ザボンのむらに関係する。
- 元来は努力と鍛錬を信じる、純粋な「村のヒーロー」側の人物。
- 「強くなれば守れる」と本気で信じている。
- 魔法は主軸にせず、弓・武器更新・武器アクションを優遇する専用枠。

### 物語上の結論
- 主人公、ミレイ、わたべ等の「努力だけでは説明できない力」を目の当たりにし、努力で越えられない差が存在することを知る。
- 嫉妬や裏切りではなく、「努力すれば人を守れる」と信じていた純粋さが壊れていく悲しみとして描く。
- バトラス戦ではタロサの弓／毒が攻略の鍵となり、本人の努力が報われる大きな見せ場を作る。
- 最終局面で「限界」という現実を知り、MQ0後に悪魔の「限界をなくす力」という誘いへ向かう。
- **MQ0本編中にデスタロッサ本人は登場させない。**
- MQ0後の未来として、タロサがやがてデスタロッサへ至る伏線を残し、後の作品へつなげる。
- 旧「MQ0本編でタロサがデスタロッサ化する」案は不採用。

加入時Lv1・EXP0は維持。最終成長値は別途TBD。

### アート
- 正式歩行スプライトは assets/characters/playable/tarosa_walk.png。

## 4. ミレイ
### 最新確定事項
- レインランドの姫。
- 身分を隠して旅へ加わる。
- 本来は城で「姫」という役割の中に留まり、出会いを待つ側の人生だった。
- しかし本人は城の外へ出て、自分の目で世界を見たいと願っていた。
- 世界の混線によって本来の役割から外れ、その願いとともに魔法へ目覚める。
- ゲーム上は魔法使い。攻撃魔法、回復、復活、補助を担う。
- 主人公への感情は、旅を通した信頼から恋心へ変わる。

### 記憶と未来
- 旅の中で、本来のレインランド、自分が姫として生きるはずだったルート、まだ起きていない未来の断片を少しずつ感じ取る。
- 未来には、自分が再び姫を産む断片が含まれる。
- その娘が「レイ」。
- 主人公がMQ0世界に残る未来では、主人公とミレイはレインランドへ戻り、後にレイが生まれる。
- ミレイはレイ出産時に亡くなる。
- この事実は本編中に直接説明せず、終盤・エンディング後の描写で匂わせる。

### アート
- 正式歩行スプライトは assets/characters/playable/mirei_walk.png。

最終魔法配分・成長値は別途TBD。

## 5. わたべ
- 主要3人パーティとは別管理。
- 現実世界側／ゲーム世界の外側に近いところから入り込む異物的な存在。
- 本編中は通常の常設4人目にしない。
- 「もういちど」以降の裏ワザ領域で加入／特殊参加する。
- 現実側で集められるジャンカード等の力とも意味的につながる。
- 通常のゲーム内成長では説明しきれない非常に大きな力を持つ。
- 固有攻撃「とくだいヒット」を使用できる。
- オロチゾンビ再戦の最終解決に必要。
- 真の最終解決後は現実世界側へ帰還する。
- 主人公が「もとの せかいへ かえる」を選んだ場合は、その帰還に同行する。

通常加入キャラクターと同じレベル成長テーブルを必須としない。

## 9. バランス確認
- 新規加入者が弱すぎて即レベル上げ必須にならない。
- 3人の役割が重複しすぎない。
- 回復役が倒れた瞬間に詰む設計にしない。
- 魔法を覚えても使う意味がないMP設計にしない。
- 通常敵との戦闘が長期化しすぎない。

## 10. 禁止
- 主人公を旧女性勇者風設定へ戻す。
- 主人公を最初から世界の真相を知る人物にする。
- 主人公がプレイヤーへ直接メタ発言する。
- 未確定習得レベルをAIが勝手に正式化する。
- 原作側の未確認設定をMQ0の確定設定として記載する。
- 主人公・タロサ・ミレイを4人以上の常設パーティへ変更する。
