# モンスタークエスト0 UI・入力仕様

最終更新: 2026-09-11 JST

このファイルはタイトル、フィールド、メニュー、戦闘、タッチ操作の共通UI / Input契約を定める。

## 1. 基本方針
- UIはファミコン風のシンプルで読みやすい見せ方を維持する。
- 戦闘背景やイベント背景を高品質化しても、文字・コマンド・ステータスの視認性を最優先する。
- WebブラウザとiPhone Safariを同じゲームとして遊べるようにする。
- キーボード用処理とタッチ用処理でゲームロジックを二重実装しない。`InputSystem` で共通actionへ変換する。

## 2. 共通アクション
最低限:
- `moveUp`
- `moveDown`
- `moveLeft`
- `moveRight`
- `confirm`
- `cancel`
- `menu`

必要に応じてdebug actionを追加する場合、本番操作と衝突させない。

## 3. タイトル画面
正式メニュー:
- はじめから
- つづきから
- ジャンカードガチャ
- ジャンカード図鑑
- たびのあいことば
- 設定

- 選択中項目を明確にする。
- セーブがない場合の「つづきから」は安全に無効表示する。
- 「ふっかつのじゅもん」という旧名称を表示しない。

## 4. フィールド
- 十字移動を基本とする。
- NPC / 宝箱 / オブジェクトは `confirm` で調べる。
- メニューは専用actionで開く。
- タッチ操作時も会話中に移動が暴発しないようinput lockを持つ。

## 5. 会話UI
- 短い文章を優先する。
- 文字サイズはiPhone実機で読めることを基準にする。
- 長文を一画面へ詰め込まない。
- 会話送り中の二重入力を防ぐ。
- 重要な固有名詞は画面幅で不自然に切れないよう確認する。

## 6. メニュー
最低限:
- ステータス
- どうぐ
- まほう
- そうび
- ジャンカード閲覧
- 設定

常に全項目を同時表示する必要はない。小画面で読みやすい階層を優先する。

## 7. 戦闘UI
基本コマンド:
- たたかう
- まほう
- どうぐ
- にげる

- 敵・背景よりコマンドと戦闘メッセージが読みやすいことを優先する。
- 「クリティカル」ではなく「だいヒット」を表示する。
- わたべ固有は「とくだいヒット」。
- タッチでは選択領域を文字サイズより十分大きくする。

## 8. ジャンカードUI
- 所持金
- 1回20円
- 所持枚数 / 45
- カードをひく
- コレクション
- もどる

未取得カードは内容を伏せる。公開ネタバレ対象は取得条件に応じても表示名を慎重に扱う。

## 9. iPhoneタッチ操作
- 画面端へ仮想十字キー / actionボタンを置く方式を基本候補とする。
- Safe Areaを考慮する。
- ブラウザUIと重なりにくい配置にする。
- 縦持ち / 横持ちの正式対応方向は実機確認後に確定する。
- 連打、長押し、指を滑らせた際の誤入力をQAする。
- タッチUIがゲーム画面の重要部分を大きく隠さない。

## 10. 画面サイズ
最終内部解像度・拡大方式は正式アセット確認後に確定する。

守ること:
- pixel-art素材は不要なぼかしを避ける。
- 高品質背景は画面比率に合わせて破綻しないcrop / fitを選ぶ。
- UIの基準座標を端末ごとに手作業で複製しない。

## 11. Input lock
以下ではプレイヤー移動を止める:
- 会話
- メニュー
- 戦闘遷移
- 宝箱演出
- 仲間加入等のイベント
- 終盤の制御演出

lock解除漏れによる進行不能をQA対象にする。

## 12. アクセシビリティ / 快適性
- 小さすぎる文字を避ける。
- 点滅・バグ演出を長時間連続させない。
- 音量設定を用意する。
- 本物のエラーに見える演出から必ず復帰する。

## 13. 禁止
- iPhoneだけ別ロジックにする。
- 画面上の小さな文字そのものをタップ判定領域にする。
- 背景を優先してUIを読みにくくする。
- 端末サイズごとにSceneコードへ座標を大量直書きする。
