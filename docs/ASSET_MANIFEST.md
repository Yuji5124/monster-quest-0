# Monster Quest 0 素材管理

更新日: 2026-09-09

このファイルは「何が制作済みで、何が不足しているか」をAIが判断するための一覧とする。

## 1. 基本方針
- 既に完成した正式素材を優先して使用する
- 仮素材で全ゲームを作って後から総入れ替えしない
- 不足素材は実装中に必要になったものだけ追加する
- 素材制作そのものを目的化しない

## 2. 制作済みの基本5セット
ユーザー確認済み：
- 主人公・タロサ・ミレイ歩行スプライト
- MQ0基本タイルセット
- NPC基本10体
- モンスター25体のゲーム用素材セット
- MQ0共通UI

※ この「制作済み」は作品制作上の状態を示す。GitHubへ実ファイルが配置済みかどうかは別途リポジトリ内を確認すること。

## 3. 進行中 / 追加制作する素材
必要になった時点で追加する。
- 戦闘背景
  - 草原
  - 森
  - 洞窟
  - 城 / 城下町周辺
  - 雪原
  - その他地域固有背景
- 室内固有タイル
- 地域固有建物 / オブジェクト
- 魔法エフェクト
- SE
- イベント専用差分
- 終盤専用演出素材

## 4. 後回しでよいもの
- 全アイテムの個別アイコン
- 全ジャンカードのゲーム内最終演出調整
- 全地域の固有装飾を先行制作すること
- 1回しか使わないイベント素材を早期に大量制作すること

## 6. 命名
- 英数字・ハイフンまたはスネークケースのどちらかに統一する
- 同一カテゴリで命名方式を混在させない
- `final2_new_latest.png` のような履歴名を正式ファイル名にしない
- 画像差分は用途を名前で分かるようにする

例：
- `hero_walk.png`
- `tarosa_walk.png`
- `battle_bg_forest.png`
- `monster_daija.png`
- `ui_window.png`

## 7. AIルール
- 正式素材が存在するかを確認してから新規生成する
- 正式キャラクターの外見を勝手に再デザインしない
- 元資料由来のモンスターは形・色・装備・模様・表情を勝手に変更しない
- 透明PNGが必要な素材は不要な背景・カード枠・UIを含めない

## 8. 実装フェーズの判断
Vertical Sliceで不足した素材だけをTODO化する。
「素材が全部そろうまで実装を開始しない」という進め方は禁止する。
