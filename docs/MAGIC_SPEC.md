# モンスタークエスト0 魔法仕様

最終更新: 2026-09-11 JST

このファイルはMonster Quest 0で扱う魔法の名称、役割、原作資料との区別、データ管理方針の正本。

## 1. 基本方針
- 採用済み名称だけを正式魔法として扱う。
- 原作 / ジャンカードで確認した情報と、Monster Quest 0独自採用を区別する。
- 消費MP、威力、成功率、習得レベル等の未確定数値をAIが勝手に最終値として決めない。
- 魔法データはSceneへ直書きせずJSON等の固定データとして管理する。

## 3. リライフ
- Monster Quest 0内では**復活魔法**として採用する。
- 戦闘不能の仲間を蘇生する。
- 原作側で本当に復活魔法だったかは未確定。
- ドキュメントでは `MQ0 adopted behavior` と `source confirmed behavior` を混同しない。

## 4. エレキテル
- 主人公が覚える固有魔法。
- 主人公の個性を示す重要魔法として扱う。
- 習得レベル、消費MP、威力、属性、演出はTBD。
- 他キャラクターへ自動的に配布しない。

## 5. ダイダイン / ミラー関連
- デーマスの強力な「ダイダイン」は攻略ギミックの中心。
- 反射を利用して逆転する構造を採用する。
- 「ミラー」はデーマス戦に関係する重要要素として扱う。
- ミラーをプレイヤー魔法、敵専用効果、アイテム効果のどれとして最終実装するかはTBD。
- AIが一般的な反射魔法の仕様を勝手にコピーしない。

## 6. キャラクター別習得
確定済み:
- 主人公: エレキテル

未確定:
- 主人公 / タロサ / ミレイへのその他魔法の最終配分
- 各習得レベル
- 初期習得魔法
- 加入時に習得済みの魔法

詳細は `CHARACTER_GROWTH.md` と同期する。

## 7. 魔法データ項目
各魔法は最低限以下を持つ。
- `id`
- `name`
- `mpCost`
- `target`
- `effectType`
- `power`
- `successRate`
- `element`
- `statusEffect`
- `animation`
- `usableInBattle`
- `usableOnField`
- `sourceReference`
- `notes`

未確定値は `null` / `TBD`。

## 8. 効果タイプ
実装上の候補分類:
- heal
- revive
- damage
- buff
- debuff
- status
- utility
- reflect / special

分類名は実装時に統一するが、魔法名や効果そのものを分類都合で変更しない。

## 9. バランス
- 通常攻撃だけで十分になり、魔法が死に要素になる状態を避ける。
- MP不足が厳しすぎて魔法を温存するだけになる状態を避ける。
- 回復魔法を使う意味があるダメージ量にする。
- ボス攻略魔法はNPCヒント等と連動させる。
- 約5時間のゲームとして、覚えた魔法を使う機会がないまま終了しないようにする。

## 10. 演出
- レトロRPGらしい短いテンポを基本にする。
- 高品質背景とエフェクトで文字・敵が読みにくくならないようにする。
- エフェクト尺の最終値はTBD。
- 終盤のバグ演出と通常魔法エフェクトを混同しない。

## 11. 禁止
- 未採用魔法をAIが正式追加する。
- 原作未確定情報を原作確定として記載する。
- リライフのMQ0独自採用を原作事実と書く。
- エレキテルを主人公以外へ勝手に配る。
- 消費MP / 威力 / 成功率を根拠なく最終値へ固定する。
