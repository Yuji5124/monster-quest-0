# Monster Quest 0 魔法仕様

更新日: 2026-09-09

## 1. 基本方針
- こどつら本編由来の魔法と、ジャンカードで確認できる魔法をMonster Quest 0へ取り入れる
- 同名魔法が複数資料にある場合は重複させず統合する
- 原作で効果が未確定のものは「原作確定」と書かない
- AIが未確認の魔法名を勝手に追加しない

## 2. 現時点で確認済み
| 名前 | 区分 | MQ0での扱い | 備考 |
|---|---|---|---|
| ヒート | 攻撃系候補 | 採用候補 | ジャンカード確認済み |
| アイスーン | 攻撃系候補 | 採用候補 | ジャンカード確認済み |
| ダイダイン | 強力な攻撃魔法 | 採用 | デーマス使用技として重要 |
| リライフ | 復活 | 採用 | MQ0では戦闘不能の仲間を蘇生。原作で復活魔法かは未確定 |

## 3. ダイダイン
- デーマスが使用する重要魔法
- デーマス戦では、原作に合わせてダイダインで主人公たち全員が戦闘不能に追い込まれる展開を採用する
- 通常の汎用魔法として扱うか、イベント専用・敵専用とするかは実装時にストーリー仕様と整合させる

## 4. リライフ
- Monster Quest 0では復活魔法として使用する
- 戦闘不能の仲間を蘇生する
- 回復量、消費MP、使用可能タイミングなどの数値はバランス調整で確定する

## 5. エフェクト方針
基本エフェクトを共通化して流用する。
- 炎
- 氷
- 雷
- 回復
- 復活

PhaserのSprite Animation / Particle等を使用し、過剰に重い演出にしない。

## 6. データ化
魔法は可能な限りデータ駆動にする。

推奨項目：
- id
- name
- type
- mpCost
- power
- target
- element
- effectId
- animationId

## 7. 禁止事項
- 既存資料にない魔法をAI判断だけで正式採用しない
- 効果未確定の魔法へ勝手に原作設定を付けない
- デーマス戦の重要演出を通常バランス調整の都合だけで削除しない
