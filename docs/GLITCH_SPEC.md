# モンスタークエスト0 終盤バグ演出仕様

## 1. 基本方針
- バグ演出は序盤・中盤では発生させない
- それまでは「普通の昔ながらのドット絵RPG」として成立させる
- 終盤に入ってから突然、世界が壊れ始める
- 実際のプログラム障害ではなく、すべて制御された演出として実装する

## 2. 発生タイミング
想定プレイ時間60分の場合：
- 0〜45分：通常状態
- 45〜50分：最初の違和感
- 50〜55分：明確なバグ演出
- 55〜60分：強い異常状態

## 3. 演出例
### 初期異常
- NPC文章の一部が一瞬乱れる
- BGMが一瞬止まる
- マップチップが一瞬だけ別画像になる

### 中程度
- 敵名の一部が文字化けする
- 主人公のドット絵が一瞬別画像になる
- NPCが一時的に二重表示される
- メニューに一瞬だけ「？？？」が現れる

### 強い異常
- 画面が一瞬暗転する
- BGMが停止する
- 画面の一部が崩れる
- 意味不明な文字列が表示される
- 最終エリアそのものが不安定に見える

## 4. 発生回数
- 終盤のみ合計3〜5回程度
- 多用せず、段階的に強くする

## 5. 安全ルール
以下は絶対に起こさない：
- セーブデータ破損
- 本当のフリーズ
- 長時間の操作不能
- 進行不能
- 無限ループ
- カード取得情報の消失

## 6. ストーリー上の役割
- 終盤になって初めて「この世界そのものがおかしい」と気づかせる
- バグは単なるギャグではなく、世界が正常ではないことを示す
- 具体的な原因・解決方法は公開仕様には記載しない

## 7. 重要な見せ方
プレイヤーの認識を次のように変化させる：

普通のRPG
→ 何か変だ
→ ゲームが壊れた？
→ これは意図的なのでは？
→ 持っている情報に意味があるのでは？

## 8. 一言で表すと
「約50分間は普通のRPG。最後の10分で世界そのものが壊れ始める。」
