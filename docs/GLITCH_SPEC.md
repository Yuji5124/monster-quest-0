# モンスタークエスト0 終盤バグ・偽異常演出仕様

最終更新: 2026-09-10 13:50 JST

## 1. 基本方針
- 世界の本格的なバグ演出は序盤・中盤では多用しない。
- それまでは「普通の昔ながらのRPG」として十分に成立させる。
- 終盤に入ってから、世界そのものが失敗作であることを感じさせる異常を段階的に強める。
- 実際のプログラム障害ではなく、すべて制御された演出として実装する。
- プレイヤーの実セーブデータやカード取得情報は絶対に破損させない。

## 2. 起動時の偽セーブ消失演出
ゲーム起動時に、昔のRPGを知るプレイヤーが一瞬焦る演出を入れる。

基本案:
1. 「ぼうけんのしょが きえました」風の偽メッセージを表示する。
2. 実データは削除しない。
3. 数秒後に「……まだ おわっていない」と表示する。
4. そのまま通常のゲーム進行へ戻す。

### 安全ルール
- LocalStorage等の実保存データを削除しない。
- セーブ破損を模倣する場合も見た目だけにする。
- 初回プレイヤーが本当にデータ消失したと誤解し続けない長さにする。

## 3. 終盤での段階的異常
想定プレイ時間は約5時間。異常演出は「最後の10分だけ」の固定時間ではなく、**物語上の終盤フラグ以降**で管理する。

### 初期異常
- NPC文章の一部が一瞬乱れる。
- BGMが一瞬止まる／音が欠ける。
- マップチップが一瞬だけ別画像になる。
- 一度見たはずの場所に小さな違和感が出る。

### 中程度
- 敵名の一部が文字化けする。
- 主人公やNPCのドット絵が一瞬乱れる。
- NPCが一時的に二重表示される。
- メニューに一瞬だけ `？？？` が現れる。
- 画面の一部だけ座標がずれる。

### 強い異常
- 画面が一瞬暗転する。
- BGMが停止する。
- 画面の一部が崩れる。
- 意味不明な文字列が混ざる。
- 最終地点がFC時代のバグ画面のように不安定に見える。

## 4. 最終戦の正式ギミック
最終戦では通常のRPGの勝利演出だけで終わらせない。

基本シーケンス:
1. 最終戦中または直後に画面がバグる。
2. 通常操作では進めない異常状態になる。
3. 「フーフー」を連想させる演出／入力を挟む。
4. ゲームがオープニングへ戻ったように見せる。
5. タイトル／OP側で「もういちど」という選択肢が現れる。
6. そこから本当の終盤解決へつながる。

※具体的な答えや最終解決方法は公開用資料には書かない。

## 5. 「たびのあいことば」
- 旧名称「ふっかつのじゅもん」は使用しない。
- 正式名称は **「たびのあいことば」**。
- タイトル画面の機能名も「たびのあいことば」に統一する。
- パッケージ／カセットの謎解き要素と関連づける場合も、公開仕様では答えそのものを記載しない。

## 6. パッケージ・カセットとの連動
- 黒箱／黒カートリッジを基本デザインとする。
- カセット表面の剣・宝石・星・数字などを終盤の入力順を示す謎に利用する。
- 裏面には「たびのあいことば」のヒントを置く。
- ジャンカード総数は45枚の現行仕様に合わせる。
- 普段見ていたパッケージ／カセット自体が終盤で攻略情報になる構造を狙う。

## 7. 発生回数
- 小さな異常は終盤に3〜5回程度を目安とする。
- 最終地点では演出密度を上げてよい。
- 毎マップ・毎戦闘で発生させず、プレイヤーが慣れないようにする。

## 8. 絶対に起こさないこと
- 本当のセーブデータ破損
- 本当のフリーズ
- 長時間の操作不能
- 進行不能
- 意図しない無限ループ
- ジャンカード取得情報の消失
- ブラウザ／iPhone上で本当のエラー画面を出して復帰不能にすること

## 9. ストーリー上の役割
- 世界が単なるレトロRPGではなく「失敗作」であることを終盤で明かしていく。
- バグは単なるギャグではなく、物語の核として使う。
- 最後は通常の強さだけでは解決できない構造へつなげる。
- わたべの役割や最終解決の詳細は内部設定として扱い、公開用資料では伏せる。

## 10. 見せ方の流れ

普通のRPG
→ 少し変だ
→ ゲームが壊れた？
→ 壊れているのではなく演出なのか？
→ ゲーム外で見ていた情報にも意味がある？
→ OP／パッケージ／これまでの情報を見直す
→ 本当の終盤へ

## 11. 実装
- バグ演出のON/OFFは進行フラグで制御する。
- 画面ノイズ、座標ずれ、文字化け、音停止などを個別の演出関数として実装する。
- 実エラーと演出エラーを混在させない。
- Phaser側で異常演出を終了後、必ず既知の正常状態へ復帰できるようにする。
