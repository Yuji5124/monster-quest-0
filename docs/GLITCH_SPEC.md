# Monster Quest 0 終盤異常演出仕様

更新日: 2026-09-09

## 1. 基本方針
- 異常演出は序盤・中盤では発生させない
- それまでは「普通の昔ながらのドット絵RPG」として成立させる
- 終盤に入ってから突然、世界に違和感が現れ始める
- 実際のプログラム障害ではなく、すべて制御された演出として実装する
- 約5時間の本編全体に対して多用しない

## 2. 発生タイミング
- 本編終盤のみ
- 時間固定ではなく、ストーリー進行フラグで制御する
- 最初の違和感 → 明確な異常 → 強い異常、の3段階程度で強める

## 3. 演出例
### 初期異常
- NPC文章の一部が一瞬乱れる
- BGMが一瞬止まる
- マップチップが一瞬だけ別画像になる

### 中程度
- 敵名の一部が文字化けする
- 主人公のドット絵が一瞬別画像になる
- NPCが一時的に二重表示される
- メニューに一瞬だけ「？？？」が現れる

### 強い異常
- 画面が一瞬暗転する
- BGMが停止する
- 画面の一部が崩れる
- 意味不明な文字列が表示される
- 最終エリアそのものが不安定に見える

## 4. 発生回数
- 終盤のみ、必要最小限
- 多用せず、段階的に強くする
- 同じ演出を何度も繰り返さない

## 5. 安全ルール
以下は絶対に起こさない。
- セーブデータ破損
- 本当のフリーズ
- 長時間の操作不能
- 進行不能
- 無限ループ
- カード取得情報の消失
- ブラウザや端末を不安定にする処理

## 6. 実装ルール
- すべて明示的なイベントフラグで発火させる
- ランダムな本物のエラーに依存しない
- セーブ / ロード後も進行状態が再現できる
- iPhone Safariでも安全に再生できる軽量な演出を優先する

## 7. 公開時の注意
- 具体的な原因・終盤ボス・解決方法は公開仕様には記載しない
- 紹介画像や広告では異常演出の核心を見せない
