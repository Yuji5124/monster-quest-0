# Monster Quest 0 モバイル仕様

更新日: 2026-09-09

## 1. 主要ターゲット
- Webブラウザ
- iPhone Safariを主要確認環境の一つとする
- PCブラウザでも遊べること

## 2. 入力
- タッチ操作を後付けにしない
- 移動用方向入力
- 決定
- キャンセル
- メニュー
- 戦闘コマンド選択

PCではキーボード入力も使用可能にする。

## 3. UI
- Safe Areaを考慮する
- 小画面で文字やボタンが画面外へ欠けないようにする
- hover必須操作を作らない
- タップ領域を見た目より極端に小さくしない
- 縦持ち / 横持ちの正式方針は実装初期に固定し、その後むやみに変更しない

## 4. 表示
- ピクセルアートがぼやけない設定を優先する
- CSSやCanvas拡大時も整数倍率・nearest系表示を意識する
- 端末ごとのアスペクト比差でゲーム領域が破綻しないようにする

## 5. 音
- iOSの自動再生制限を考慮し、最初のユーザー操作後にAudioContext / BGMを開始できる構造にする
- アプリ復帰時のBGM二重再生を防ぐ

## 6. セーブ
- ブラウザ保存を基本とする
- Safariの再読み込みやタブ復帰でセーブが壊れないようにする
- ゲーム進行に重要なデータは明示的に保存する

## 7. パフォーマンス
- 大量の高解像度画像を一度に読み込まない
- 戦闘背景やマップ素材は必要単位で管理する
- 常時生成されるParticleを増やしすぎない
- 長時間プレイ後のメモリ増加を確認する

## 8. 実機確認項目
- 起動
- タイトルから開始
- フィールド移動
- NPC会話
- 戦闘
- メニュー
- セーブ / ロード
- BGM / SE
- 画面回転・復帰
- Safari再読み込み後の状態
