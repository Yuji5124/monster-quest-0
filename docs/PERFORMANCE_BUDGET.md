# モンスタークエスト0 パフォーマンス基準

最終更新: 2026-09-10 23:46 JST

## 1. 目的
Web / iPhone Safariで快適に遊べる状態を守り、画像・演出の高品質化で操作感を犠牲にしない。

## 2. 基本方針
- 60fpsを目標とするが、数値より入力遅延・カクつき・進行不能がないことを優先
- 高品質背景は必要解像度へ最適化して使用
- 画面外の不要オブジェクト・エフェクトを増やしすぎない
- 同じアセットの重複ロードを避ける
- Scene遷移時に不要なTimer / Listener / Particleを残さない

## 3. iPhone
最低確認:
- Safariで起動
- タッチ移動
- 決定 / キャンセル
- 会話送り
- 戦闘コマンド
- メニュー
- セーブ / ロード
- Safe Area
- 縦横サイズ変化時にUIが致命的に欠けない

## 4. 画像
- PNGを無意味に超高解像度で保持しない
- 戦闘背景は表示サイズに対し過剰な解像度にしない
- 透明余白が巨大な画像は整理する
- スプライトシートは用途別に適切にまとめる

## 5. 音
- BGM二重再生禁止
- Sceneごとに同一音源を重複生成しない
- iOSの音声開始制約を考慮し、ユーザー操作を起点にAudioを開始できる構造にする

## 6. イベント
- 毎フレーム全NPC・全イベントを総当たりで重く判定しない
- 自動イベントの無限評価・無限再実行を防ぐ
- 二重発火を防ぐ

## 7. 戦闘
- 演出中に大量オブジェクトを残留させない
- 戦闘終了後に戦闘専用リソースを整理する
- 背景・敵・UIの読み込み失敗時に無限待機しない

## 8. QAで見る症状
- タッチが遅れて反応する
- 長時間プレイで徐々に重くなる
- Scene移動のたびにBGMが増える
- 戦闘を繰り返すとFPSが落ちる
- iPhoneで画面が再読み込みされる
- 画像読み込みで一瞬真っ白になる

## 9. 優先順位
高品質背景の細部より、歩く・話す・戦う・セーブする操作の気持ちよさを優先する。

## 10. 完了報告
パフォーマンスに関係する変更では、検証端末 / ブラウザ、確認シナリオ、既知の問題を残す。
