# モンスタークエスト0 Definition of Done

最終更新: 2026-09-12 JST

## 1. 目的
AIが「コードを書いた」「画面が出た」だけで完了扱いしないための共通完成基準。

## 2. 機能のDone
- 仕様書に一致
- ブラウザで実際に動く
- 主要操作で進行不能にならない
- 既存機能を壊していない
- セーブ対象はロード後も状態維持
- iPhone Safari想定のタッチ操作で使える
- TODO / 仮実装が残る場合はPARTIAL

## 3. オープニングのDone
- タイトルから開始できる
- 約5秒の制御異常が実エラーなしで再生
- **No.01「はじまりのばしょ」夜版**へ遷移
- 最新男性主人公が焚き火のそばで目覚める
- 早い段階で操作可能
- 夜→昼 / 次導線が破綻しない
- **No.02「はじまりのまち」**へ自然につながる
- 直接メタ会話なし
- 開始直後の偽セーブ消失なし
- 人間が音・間・視線・テンポを確認済み

## 4. マップのDone
- 正式No.01〜No.20を使用
- 正式タイル / 正式素材
- 出入口 / Collisionが正常
- NPC / 宝箱 / イベント起動
- 閉じ込めなし
- Foreground等が破綻しない
- 人間の視覚調整を1回以上実施

No.01は初回夜 / 昼と、「もういちど」後の再訪状態を混同しない。

## 5. NPCのDone
- 役割が決まっている
- 基本2パターン程度の会話
- 必要な会話変化はフラグ連動
- 未確定設定 / ネタバレを勝手に話さない
- ジャンカード秘密を序盤から示唆しない
- 実機で文字量・テンポ確認

## 6. 戦闘のDone
- たたかう / まほう / どうぐ / にげる
- 敵行動
- 勝利 / 通常全滅
- EXP / レベルアップ
- だいヒット
- 戦闘後フィールドへ安全復帰
- BGM二重再生なし
- ボス再入場 / セーブロード破綻なし

## 7. オロチゾンビ / 裏ワザのDone
- オロチゾンビを裏ボスとして扱う
- 1回目を通常Game Overへ落とさない
- 異常 / フーフー / 偽リセットが制御演出として動く
- 「もういちど」が解放される
- New Game処理を使わない
- No.01へ戻る
- 主人公・タロサ・ミレイの記憶保持がイベント上伝わる
- わたべ加入 / 特殊参加 → 再戦へ進む
- 実セーブとジャンカードが消えない
- 再戦後、真エンディングへ進める

## 8. セーブのDone
- versionあり
- パーティ / レベル / HP / MP / 所持品 / 装備 / 所持金
- 宝箱 / ボス / NPC進行
- ジャンカード状態
- No.01初回 / 再訪
- 「もういちど」解放 / 選択
- わたべ最終参加
- オロチゾンビ再戦 / 真撃破
を保存できる。

偽データ消失演出で実データを削除しない。

## 9. アセットのDone
- GitHub正式パスに存在
- `ASSET_INDEX.md` / `asset_catalog.json` と一致
- 意味のある名前
- 必要な透明背景が正しい
- 正式キャラデザインを維持
- 旧女性主人公 `hero_walk.png` を現行主人公に使用していない

## 10. Vertical SliceのDone
タイトル
→ 約5秒異常
→ No.01夜
→ 焚き火
→ 主人公歩行
→ 夜→昼 / 次導線
→ No.02はじまりのまち
→ No.02内部
→ フィールド
→ ザコ戦
→ レベルアップ
→ 小ダンジョン
→ ボス
→ セーブ / ロード
→ iPhone Safari

を通してプレイできる。

## 11. エリアのDone
- マップ
- NPC
- 会話
- イベント
- 出入口
- 宝箱
- 敵編成
- BGM
- 固有素材
- セーブ状態
が揃い、入口から出口まで通して遊べる。

## 12. リリース候補のDone
- 最初から真エンディングまで通しプレイ可能
- 初見約4時間30分 / 寄り道込み約5時間30分へ調整済み
- 25体モンスター確認
- ジャンカード45枚確認
- iPhone Safari / PCブラウザ確認
- 仮素材 / デバッグ / 不要TODO整理
- 公開素材へ重大ネタバレ混入なし
- 旧主人公 / 旧マップ番号 / 旧カード数が残っていない

## 13. ステータス表記
- `DONE`
- `PARTIAL`
- `BLOCKED`

「実装しました」だけでDONEにしない。
