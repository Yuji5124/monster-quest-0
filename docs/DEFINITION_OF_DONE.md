# Monster Quest 0 Definition of Done

更新日: 2026-09-09

このファイルは、AIが「実装済み」「完成」と報告してよい最低条件を定義する。
コードを書いただけでは完成ではない。

## 1. 共通DoD
機能を完成扱いにするには、最低限：
- 仕様書を読んで実装されている
- ブラウザで起動する
- 実際に操作して確認している
- 主要な正常系が動く
- 明らかな進行不能がない
- コンソールに重大なエラーが出ない
- 正式素材がある場合は正式素材を使用している
- iPhone Safari想定で破綻しない
- 関連仕様変更がある場合、Markdownも更新している

## 2. マップDoD
1マップ完成には：
- 出入口が機能する
- Collisionが機能する
- プレイヤーが壁・障害物を不自然に通過しない
- NPC / オブジェクトへ到達できる
- イベントが起動する
- 進行不能地形がない
- 前景 / 奥行き表現が破綻しない
- 仮素材が残る場合はTODOとして明示されている
- 人間による視覚確認を通す

## 3. NPC DoD
- 正しいマップへ存在する
- 正しいSpriteを参照する
- 会話できる
- 必要なら進行条件で会話が変わる
- イベント二重発火しない
- 生活感 / 地域情報というNPC方針に反していない

## 4. 戦闘DoD
- コマンド入力可能
- 敵ターンが進む
- 勝利可能
- 敗北 / 全滅処理可能
- 経験値 / レベルアップが反映される
- 戦闘終了後にフィールドへ安全に戻れる
- 戦闘を繰り返して状態が壊れない
- タッチUIでも主要操作可能

## 5. 魔法 / アイテムDoD
- データ登録
- UI表示
- 使用条件
- 対象選択
- 効果反映
- 消費処理
- 使用不能時の処理
- セーブ / ロード後も整合

## 6. ボスDoD
- 戦闘前イベント
- 戦闘
- 勝利判定
- 敗北時の安全な復帰
- 勝利後イベント
- 撃破flag保存
- 報酬二重取得防止
- 再訪時の挙動確認

## 7. セーブDoD
- セーブ可能
- ロード可能
- 現在マップ復帰
- パーティ状態復帰
- 所持品復帰
- 主要イベントflag復帰
- ジャンカード状態復帰
- バージョン値を持つ
- 壊れた / 古いデータへの最低限の防御がある

## 8. ジャンカードDoD
- 1回20円
- 固定順
- 重複なし
- 45枚上限
- 所持金不足時に回せない
- コレクションへ反映
- セーブ / ロードで維持
- 本編進行必須にしない

## 9. Vertical Slice DoD
タイトルから開始し、
はじまりのまち
→ フィールド
→ ザコ戦
→ レベルアップ
→ 小ダンジョン
→ ボス
→ セーブ / ロード
まで通しでプレイできる。

加えて：
- 正式主人公素材
- 正式基本タイル
- 正式共通UI
を使用する。

iPhone Safari想定の主要操作確認を行う。

## 10. エリア量産DoD
Phase 4以降の新規地域は、少なくとも：
- マップ
- NPC
- 出入口
- イベント
- 敵編成（必要地域）
- 宝箱（ある場合）
- BGM
- 固有素材（必要な場合）
を揃える。

## 11. Release Candidate DoD
- 最初からエンディングまで通しプレイ可能
- 全主要ボス攻略可能
- 全必須マップ遷移確認
- セーブ / ロード確認
- iPhone Safari確認
- PCブラウザ確認
- 重大な仮素材を除去
- 公開素材へのネタバレ混入確認
- プレイ時間を約5時間へ調整
- 既知の進行不能バグ0件

## 12. 完了報告フォーマット
AIは完了時に最低限、以下を報告する。
- 変更したもの
- 実際に確認した操作
- 未確認事項
- 残っているTODO
- 変更した仕様書

「実装しました」だけで完了報告しない。
