# モンスタークエスト0 Definition of Done

最終更新: 2026-09-11 08:31 JST

## 1. 目的
AIが「コードを書いた」「画面が出た」だけで完了扱いしないための共通完成基準。

## 2. 機能のDone
機能は以下を満たして初めてDone。
- 仕様書に一致する
- ブラウザで実際に動く
- 主要操作で進行不能にならない
- 既存機能を壊していない
- セーブ対象ならセーブ / ロード後も状態が維持される
- iPhone Safari想定のタッチ操作で使える
- 仮実装やTODOが残る場合はDoneではなくPartialと記録する

## 3. オープニングのDone
- タイトルから「はじめから」で開始できる
- 約5秒の制御された異常演出が実エラーなしで再生される
- No.18「はじまりのばしょ」夜版へ遷移する
- 最新男性主人公が焚き火のそばで目覚める
- 主人公を早い段階で操作できる
- 夜→昼または次導線が破綻しない
- はじまりのまちへ自然につながる
- 直接メタ会話がない
- 開始直後の偽セーブ消失を使っていない
- 人間による音・間・視線・テンポの確認を1回以上実施

## 4. マップのDone
- 正式タイル / 正式素材を使用
- 出入口が正しく接続
- Collisionが破綻しない
- NPC / 宝箱 / イベントが起動
- 進行不能になる閉じ込めがない
- 前景 / 奥行き表示が破綻しない
- 人間による視覚調整を1回以上実施
- 道・木・建物・装飾の不自然さを確認

No.18については夜版 / 昼版の状態切替も確認する。

## 5. NPCのDone
- 役割が決まっている
- 基本2パターン程度の会話がある
- 進行変化が必要なNPCはフラグ連動する
- 未確定設定やネタバレを勝手に話さない
- 実機で文字量・テンポを確認

## 6. 戦闘のDone
- 攻撃
- 魔法
- アイテム
- にげる
- 敵行動
- 勝利
- 全滅
- 経験値
- レベルアップ
が一連で動く。

さらに:
- 戦闘終了後にフィールドへ安全に戻る
- BGMが二重再生しない
- HP / MP / 状態が正しく引き継がれる
- ボス戦は再入場・セーブロードで重複しない

## 7. セーブのDone
- versionを持つ
- 主要進行フラグを保存
- パーティ / レベル / HP / MP / 所持品 / 装備 / 所持金を保存
- 宝箱 / ボス / NPC進行を保存
- ジャンカード取得状態を保存
- 壊れたデータでゲーム全体がクラッシュしない
- 偽データ消失演出を後半で使う場合も実データを削除しない

## 8. アセットのDone
- GitHubの正式パスに存在
- `ASSET_INDEX.md` / `asset_catalog.json` と一致
- 用途が分かる名前
- `final_new2` 等の履歴名を正式名にしない
- 透明PNGが必要な素材は背景が残っていない
- 正式キャラのデザインが保たれている
- **旧女性主人公 `hero_walk.png` を現行主人公として使用していない**

## 9. Vertical SliceのDone
タイトル
→ 約5秒の異常
→ No.18 はじまりのばしょ夜
→ 焚き火で目覚める
→ 主人公歩行
→ 夜→昼または次導線
→ はじまりのまち
→ フィールド
→ ザコ戦
→ レベルアップ
→ 小ダンジョン
→ ボス
→ セーブ / ロード
→ iPhone Safari確認

を新規ゲームから通してプレイできる。

## 10. エリアのDone
そのエリアについて:
- マップ
- NPC
- 会話
- イベント
- 出入口
- 宝箱
- 敵編成（必要な場合）
- BGM
- 固有素材
- セーブ状態
が揃い、入口から出口まで通して遊べる。

## 11. リリース候補のDone
- 最初から最後まで通しプレイ可能
- **初見約4時間30分 / 寄り道込み約5時間30分**へ調整済み
- 25体のモンスター実装確認
- ジャンカード45枚確認
- iPhone SafariとPCブラウザで主要進行確認
- 仮素材・デバッグ表示・不要TODOを整理
- 公開素材へ重大なネタバレが混入していない
- 主人公・オープニングが最新仕様と一致

## 12. ステータス表記
AIは作業結果を以下で報告する。
- `DONE`: 上記基準を満たす
- `PARTIAL`: 一部動くが未検証 / 仮素材 / TODOあり
- `BLOCKED`: 不足素材・未確定仕様・技術問題で止まっている

「実装しました」だけで完了報告しない。
