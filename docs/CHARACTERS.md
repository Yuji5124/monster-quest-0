# Monster Quest 0 キャラクター仕様

更新日: 2026-09-09

## 主人公
- 主要パーティメンバー
- 金髪
- 青いヘッドバンド
- 額の赤い宝石
- 赤いマント / スカーフ
- 剣
- 金色系装備
- 正式ビジュアルを基準とし、AIが別デザインへ変更しない

## タロサ
- 物語途中で仲間になる
- 青い逆立った髪
- 尖った耳
- 弓を持つ
- 緑の腰布
- 強さを求める展開を持つ
- 正式ビジュアルを基準とする

## ミレイ
- 物語途中で仲間になる
- レインランドの姫
- 自分の正体を隠して旅に加わる
- 正式ビジュアルを基準とする

## 歩行スプライト共通規格
- 正面：3コマ
- 横：3コマ
- 後ろ：3コマ
- 左右反転利用可
- 主要3人でサイズ・基準位置・アニメ速度を統一する

## NPC
- 基本NPC約10体をベースにする
- 村・町ごとに色や小物差分を作る
- 一般NPCは必要以上に完全新規デザインを増やさない
- 村人・町人には基本2パターン程度の台詞を持たせる
- 地域の生活、文化、仕事、他地域との関係が会話から感じられるようにする

## 公開時の注意
- 終盤の正体やネタバレに関わる人物情報は公開ドキュメントへ記載しない
