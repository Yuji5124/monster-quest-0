## 2. 現在の開発段階
現時点では**仕様・素材整理が先行しており、Phaser本体の本格実装前**。

**全体ワールドマップ・主要地域配置・大枠の進行は変更しない。**
現在見直すのは、町・村・城の内部サイズ、NPC人数と配置、ダンジョンの広さ・階層・分岐量。

方向性は、世界や地域数を削るのではなく、各地点の内部移動と探索量を圧縮してテンポを上げること。

次の大きな到達点はVertical Slice:

タイトル
→ はじまりのまち
→ フィールド
→ ザコ戦
→ レベルアップ
→ 小ダンジョン
→ ボス
→ セーブ / ロード
→ iPhone Safari確認

この区間を製品版に近い品質で完成させてから本編を量産する。

## 3. クリエイティブ方針
- 全編を同じ密度で過剰に作り込まない
- 特に丁寧に描くのは、物語の始まり、主要人物の人生が交差する場面、終盤 / エンディング
- **全体ワールドマップと主要地域構成は維持する**
- 町・村・城の内部マップはコンパクト化する
- ダンジョンも旧案よりコンパクト化する
- NPC人数を増やすこと自体を「作り込み」としない
- NPC人数は小さくしたマップと地域の役割に合わせて再調整する
- 『こどもだってつらいよ』由来の設定・資料への敬意を優先する
- 原資料で確認できる情報はAI独自案より優先する
- 原作未確定事項とMonster Quest 0独自採用を区別する
- 「作れるから追加」ではなく、作品に必要なものだけ追加する

詳細: `docs/CREATIVE_DIRECTION.md`

## 7. NPC制作の現在地点
NPC会話原案は以下まで存在する。
- はじまりのまち
- ビーエのむら
- レインランドのまち
- レインランドじょう
- ザボンのむら

ただし、**既存の人数・配置・会話セットをそのまま実装する状態ではない。**
作成済み会話は素材として保持し、コンパクト化した町・村・城に合わせて必要なNPCだけを選抜・統合する。

会話バランスの固定原則:
- 全員を攻略ヒント役にしない
- 全員を主要人物の説明役にしない
- タロサ関連地域でも全員がタロサを話題にしない
- 主要人物に興味がない生活NPCも置く
- 地域で暮らしている人として自然な話題を持たせる

詳細: `docs/NPC_SPEC.md`

## 8. マップ・ダンジョンの現在地点
- **全体ワールドマップは変更しない**
- **主要地域名・地域配置・大枠の進行は保持する**
- 町・村・城の内部マップは旧案より小さくする
- 建物数、内部歩行距離、無意味な空きスペースを減らす
- NPC数は小さくした内部マップに合わせて再調整する
- ダンジョンも旧案より小さくする
- ダンジョンのフロア数、1フロアの広さ、分岐量、往復量を減らす
- ただし重要イベント、主要ボス、地域個性は削りすぎない
- 一律50%ではなく、地点ごとに必要な密度を見て縮小する
- 最終規模は初見約4時間30分 / 寄り道込み約5時間30分の体験から逆算する

詳細: `docs/MAP_FLOW_SPEC.md`

## 9. ストーリー・終盤の重要固定事項
- 序盤〜中盤は普通のレトロRPGとして成立させる
- 世界は**終盤に入ってから**段階的にバグり始める
- 最終戦は画面バグ → フーフーを連想する演出 → OP / タイトルへ戻るように見せる → 「もういちど」
- 通常の強さだけでは最終解決できない構造
- わたべが最終解決に関わる
- 「ふっかつのじゅもん」は使用せず、正式名称は「たびのあいことば」
- パッケージ / カセット自体を終盤の攻略情報として使う
- 公開素材では重大な終盤ネタバレを伏せる

詳細: `docs/STORY_FLOW.md` / `docs/GLITCH_SPEC.md`

## 10. 戦闘の重要固定事項
- クリティカル表記は「だいヒット」
- わたべ固有は「とくだいヒット」
- デーマス戦はダイダインと反射を利用する攻略構造
- デスタロッサはMonster Quest 0には登場させない
- 主要ボスはレベルだけでなく少ないヒントから攻略法へ気づく構造を重視
- デーマス区間はLv15程度、最終地点はLv20前後を一つの目安とするが最終数値ではない

詳細: `docs/BATTLE_SPEC.md` / `docs/CHARACTER_GROWTH.md`
