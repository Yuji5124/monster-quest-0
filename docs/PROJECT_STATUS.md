# Monster Quest 0 Project Status

最終更新: 2026-09-11 08:31 JST

このファイルは『モンスタークエスト0 ～幻の冒険の書～』の**現在地点を短時間で把握するための最優先スナップショット**。
詳細は各SPECを参照する。

## 1. 現在の固定値
- 正式タイトル: モンスタークエスト0
- サブタイトル: ～幻の冒険の書～
- 広告コピー: 「誰も知らないゲーム、やってみる？」
- 目標プレイ時間: **初見約4時間30分 / 寄り道込み約5時間30分**
- 主要パーティ: 主人公・タロサ・ミレイ
- わたべ: 特殊参加 / 終盤重要人物
- モンスター総数: 25体
- ジャンカード総数: 45枚
- ジャンカード料金: 1回20円
- ジャンカード: 固定順 / ダブりなし / 本編攻略必須ではない独立サブゲーム
- 実装中心: Phaser 3 / Phaser Game Agent
- Claude Code: メイン実装
- Codex: レビュー / デバッグ / QA
- Astra: 基本システム安定後の量産フェーズで必要に応じて使用
- ASRS: 使用しない
- 制作目安: 80% AI + 20% 人間の視覚・テンポ調整

## 2. 現在の開発段階
現時点では仕様・素材整理が先行しており、Phaser本体の本格実装前。

**全体ワールドマップ・主要地域配置・大枠の進行は変更しない。**
町・村・城の内部サイズ、NPC人数と配置、ダンジョンの広さ・階層・分岐量をコンパクト化してテンポを上げる。

一方で、**物語の始まりは通常区間より密度を高くする。**
長くするのではなく、演出・風景・音・短い操作へ密度を集中する。

## 3. 最新主人公設定
- 主人公は**男性**。
- 本来は別のモンスタークエスト作品／別バージョン世界にいた、特別な勇者ではない**ただのNPCだった人物**。
- 世界間の異常によってMonster Quest 0へ迷い込む。
- 主人公自身は序盤で自分の出自や世界の仕組みを理解していない。
- プレイヤーへ直接メタ発言しない。
- 子どもには普通のRPG主人公として理解でき、大人には別世界由来だと考察できる二重構造を持たせる。
- 固有魔法「エレキテル」は採用済み能力として維持する。

**旧女性勇者風主人公設定・旧歩行スプライトは現行主人公としてそのまま使用しない。**

## 4. オープニング最新方針
基本骨格:

タイトル
→ 「はじめから」
→ **約5秒の短い制御されたバグ／異常画面**
→ 夜のNo.18 **「はじまりのばしょ」**
→ 主人公が焚き火のそばで目覚める
→ 短い操作・風景・環境音・少ない台詞
→ 昼版「はじまりのばしょ」または次の導線
→ はじまりのまち／フィールド側の通常RPG進行

固定ルール:
- 開始直後の偽「ぼうけんのしょが きえました」は使わない
- 導入のバグは約5秒の短い違和感に限定
- 本格的な世界崩壊は終盤へ残す
- プレイヤーへ直接語りかけるメタ会話は行わない
- 長い説明ムービーにしない
- 始まりは作品内でも特に丁寧に作る重点区間

詳細: `docs/OPENING_SPEC.md`

## 5. 世界の裏構造
- Monster Quest 0には、異なるモンスタークエスト作品／バージョン由来のボス・モンスター・要素が混在する。
- 世界そのものが複数バージョン／世界の断片が混ざった状態として解釈できる構造を採用する。
- 主人公もその混線で別世界から迷い込んだ存在。
- 異なる世界の要素が重なったことは、終盤の異常や通常では説明しにくい強すぎる存在の背景につながる。
- ただしこの構造を序盤から説明しない。

詳細: `docs/STORY_FLOW.md`

## 6. クリエイティブ方針
- 全編を同じ密度で過剰に作り込まない
- 特に丁寧に描くのは、**物語の始まり**、主要人物の人生が交差する場面、終盤 / エンディング
- 始まりを濃くする = 長文化ではなく、焚き火・夜→昼・音・間・短い反応・最初の町・初戦闘までの流れを丁寧にすること
- 全体ワールドマップと主要地域構成は維持する
- 町・村・城の内部マップはコンパクト化する
- ダンジョンも旧案よりコンパクト化する
- NPC人数は小さくしたマップと地域の役割に合わせて再調整する
- 『こどもだってつらいよ』由来の設定・資料への敬意を優先する
- 原資料で確認できる情報はAI独自案より優先する
- 原作未確定事項とMonster Quest 0独自採用を区別する

詳細: `docs/CREATIVE_DIRECTION.md`

## 7. マップ最新方針
- 全体ワールドマップは変更しない
- 主要地域名・地域配置・大枠の進行は保持する
- 町・村・城内部は旧案より小さくする
- ダンジョンも旧案より小さくする
- 一律50%ではなく地点ごとに密度調整
- 重要イベント、主要ボス、地域個性は削りすぎない

### No.18 はじまりのばしょ
- 物語上は最初に登場
- マップ管理番号は18のまま
- イベント専用小規模マップ
- 夜版／昼版の同一ロケーション2種類
- 夜版で主人公が焚き火のそばで目覚める
- 大量NPCや広い探索ではなく、始まりの印象に集中する

詳細: `docs/MAP_FLOW_SPEC.md`

## 10. ストーリー・終盤の重要固定事項
- 導入に約5秒の短い異常を置く
- 序盤〜中盤の本編は普通のレトロRPGとして成立させる
- 世界の本格的な崩壊は終盤に入ってから段階的に強める
- 最終戦は画面バグ → フーフーを連想する演出 → OP / タイトルへ戻るように見せる → 「もういちど」
- 通常の強さだけでは最終解決できない構造
- わたべが最終解決に関わる
- 「ふっかつのじゅもん」は使用せず、正式名称は「たびのあいことば」
- パッケージ / カセット自体を終盤の攻略情報として使う
- 公開素材では重大な終盤ネタバレを伏せる

## 11. 戦闘の重要固定事項
- クリティカル表記は「だいヒット」
- わたべ固有は「とくだいヒット」
- デーマス戦はダイダインと反射を利用する攻略構造
- デスタロッサはMonster Quest 0には登場させない
- 主要ボスはレベルだけでなく少ないヒントから攻略法へ気づく構造を重視
- デーマス区間はLv15程度、最終地点はLv20前後を一つの目安とするが最終数値ではない

詳細: `docs/BATTLE_SPEC.md` / `docs/CHARACTER_GROWTH.md`
