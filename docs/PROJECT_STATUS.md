## 2. 現在の開発段階
現時点では**仕様・素材整理が先行しており、Phaser本体の本格実装前**。

現在はVertical Sliceの前に、**マップ規模・地域構成・NPC人数と役割をもう一度考え直す段階**。

旧大規模案と旧「約半分へ圧縮」案は、どちらも参考資料・検討履歴として保持するが、最終サイズとして固定しない。

次の大きな到達点はVertical Slice:

タイトル
→ はじまりのまち
→ フィールド
→ ザコ戦
→ レベルアップ
→ 小ダンジョン
→ ボス

→ iPhone Safari確認

この区間を製品版に近い品質で完成させてから本編を量産する。

## 3. クリエイティブ方針
- 全編を同じ密度で過剰に作り込まない
- 特に丁寧に描くのは、物語の始まり、主要人物の人生が交差する場面、終盤 / エンディング
- 町・村・ダンジョンの規模は機械的な比率ではなく、地域の役割とプレイテンポから決める
- NPC人数を増やすこと自体を「作り込み」としない
- NPC人数を単純に削ること自体も目的にしない
- 『こどもだってつらいよ』由来の設定・資料への敬意を優先する
- 原資料で確認できる情報はAI独自案より優先する
- 原作未確定事項とMonster Quest 0独自採用を区別する
- 「作れるから追加」ではなく、作品に必要なものだけ追加する

詳細: `docs/CREATIVE_DIRECTION.md`

## 4. オープニング最新方針
- タイトル → 「はじめから」 → 短い導入 → はじまりのまちで操作開始
- 導入は丁寧に作るが、長いムービーにはしない
- **ゲーム開始直後のリセット演出は使わない**
- **ゲーム開始直後の偽「ぼうけんのしょが きえました」は使わない**
- 世界の本格的な異常は後半へ回す

詳細: `docs/OPENING_SPEC.md`

## 7. NPC制作の現在地点
NPC会話原案は以下まで存在する。
- はじまりのまち
- ビーエのむら
- レインランドのまち
- レインランドじょう
- ザボンのむら

ただし、**既存の人数・配置・会話セットをそのまま実装する状態ではない。**
旧大人数案と旧縮小案の両方を素材として保持し、マップを再設計した後に必要なNPCだけを選抜・統合する。

会話バランスの固定原則:
- 全員を攻略ヒント役にしない
- 全員を主要人物の説明役にしない
- タロサ関連地域でも全員がタロサを話題にしない
- 主要人物に興味がない生活NPCも置く
- 地域で暮らしている人として自然な話題を持たせる

詳細: `docs/NPC_SPEC.md`

## 8. マップ・ダンジョンの現在地点
- 主要地域名と大枠の進行は保持する
- 中盤の正確な接続順には未確定部分がある
- 町・村・城の具体サイズ、建物数、NPC数は再検討中
- ダンジョンの広さ、フロア数、分岐数、宝箱数、想定攻略時間も再検討中
- 旧「半分程度」案を最終仕様として自動採用しない
- 最終規模は初見約4時間30分 / 寄り道込み約5時間30分の体験から逆算する

詳細: `docs/MAP_FLOW_SPEC.md`

## 9. ストーリー・終盤の重要固定事項
- 序盤〜中盤は普通のレトロRPGとして成立させる
- 世界は**終盤に入ってから**段階的にバグり始める
- 最終戦は画面バグ → フーフーを連想する演出 → OP / タイトルへ戻るように見せる → 「もういちど」
- 通常の強さだけでは最終解決できない構造
- わたべが最終解決に関わる
- 「ふっかつのじゅもん」は使用せず、正式名称は「たびのあいことば」
- パッケージ / カセット自体を終盤の攻略情報として使う
- 公開素材では重大な終盤ネタバレを伏せる

詳細: `docs/STORY_FLOW.md` / `docs/GLITCH_SPEC.md`

## 10. 戦闘の重要固定事項
- クリティカル表記は「だいヒット」
- わたべ固有は「とくだいヒット」
- デーマス戦はダイダインと反射を利用する攻略構造
- デスタロッサはMonster Quest 0には登場させない
- 主要ボスはレベルだけでなく少ないヒントから攻略法へ気づく構造を重視
- デーマス区間はLv15程度、最終地点はLv20前後を一つの目安とするが最終数値ではない

詳細: `docs/BATTLE_SPEC.md` / `docs/CHARACTER_GROWTH.md`
