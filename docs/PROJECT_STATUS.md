## 10. 真のエンディング
- 真の決着後、王・仲間・NPCの言葉を経て、主人公は`ここに のこる`／`もとの せかいへ かえる`を自ら選ぶ。
- 残留ルートでは、主人公が世界の修復とともに混線由来の存在として徐々に消えていく。帰還ルートでは、主人公はMQ0の記憶を持ったまま本来のNPCへ戻ったように見え、その後に自分の意思で歩き出す。
- レイはどちらの未来にも生まれる。隠しボス討伐時点でミレイは妊娠しておらず、タロサはレイの父親にしない。主人公の全体としての命の長さは両ルートで同じ。
- No.01の焚き火から始まり、「もういちど」で同じ場所へ戻る構造を終盤で回収する。
- 帰還ルートでは一度主人公を操作不能にする。
- 元世界の別の勇者／主人公役が主人公へ話しかける。
- 主人公がNPCとして短い定型台詞を返す。
- 説明文ではなく**操作できないこと**で「本来ただのNPCだった」と明かす。
