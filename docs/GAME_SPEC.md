# モンスタークエスト0 ゲーム仕様

最終更新: 2026-09-12 JST

## 1. 基本コンセプト
- タイトル: **モンスタークエスト0**
- 正式サブタイトル: **～幻の冒険の書～**
- 広告コピー: **「誰も知らないゲーム、やってみる？」**
- ジャンル: レトロRPG風コマンドRPG
- 想定プレイ時間: **初見約4時間30分 / 寄り道込み約5時間30分**
- フィールド・歩行キャラクター: FC〜初期SFC風2Dドット絵
- 戦闘・イベント背景: 高品質2D JRPG／アニメ背景方向
- UI: シンプルで読みやすいレトロデザイン
- 全編を均一に豪華化せず、**始まり・主要人物の交差・「もういちど」以降・終盤／ED**へ密度を集中する

## 3. オープニング
正式骨格:
1. タイトル
2. 「はじめから」
3. 約5秒の短い制御された異常
4. **No.01「はじまりのばしょ」夜版**
5. 主人公が焚き火のそばで目覚める
6. 短い操作・風景・環境音・少ない台詞
7. 昼版または次導線
8. **No.02「はじまりのまち」**へ

固定ルール:
- 開始直後の偽「ぼうけんのしょが きえました」は使わない
- 冒頭約5秒は主人公が元世界からMQ0へ迷い込む瞬間の断片という裏設定
- 初見で意味を説明しない
- プレイヤーへの直接メタ会話をしない
- 本格的な世界崩壊は終盤へ残す

詳細: `OPENING_SPEC.md`

## 4. 主要キャラクター
### 主人公
- 男性
- 別のモンスタークエスト作品／別バージョン世界にいた**ただのNPCだった人物**
- 世界間の異常でMQ0へ迷い込む
- 最初から選ばれた勇者ではない
- 特別な血筋にしない
- エレキテル採用
- 旧女性勇者風主人公・旧 `hero_walk.png` は現行主人公として使用しない

### タロサ
- 途中加入
- 青い逆立ち髪、尖耳、弓、緑の腰布
- 強さを求める人物
- No.06 ザボンのむらに関係する

### ミレイ
- 途中加入
- レインランドの姫
- 身分を隠して旅へ加わる
- 主人公への恋心は旅の積み重ねで自然に描く

### わたべ
- 主要3人とは別の特殊参加キャラクター
- 固有攻撃「とくだいヒット」
- 「もういちど」以降の真の最終解決に関わる

## 6. 世界の裏構造
- MQ0には異なるモンスタークエスト作品／バージョン由来の断片が混在する
- 異なる世界由来の敵・ボスが同居する
- 主人公も世界混線で入り込んだ存在
- 終盤の異常な強さもこの混線と意味的につなげる
- 序盤から真相説明しない
- 子どもには普通のRPG、大人には考察可能な二重構造とする

## 7. NPC・会話
- 基本2パターン程度の短い台詞
- 生活感、仕事、地域、人物関係、噂、事件を分散
- 全員を攻略ヒント役／主要人物説明役にしない
- コンパクト化後のマップに必要なNPCだけを選抜・統合
- 未採用アイテム等を勝手に会話へ追加しない
- ジャンカードの秘密を序盤のNPCへ混ぜない

詳細: `NPC_SPEC.md`

- 基本コマンド: たたかう / まほう / どうぐ / にげる

- わたべのみ **「とくだいヒット」**
- ボスは単純なHP勝負だけでなく攻略ギミックを重視

### デーマス
- 中ボス
- Lv15程度を目安
- ミラー／ダイダイン反射を利用して逆転

### 終盤
- バトラス
- オロチまおう
- **オロチゾンビ（裏ボス）**

### オロチゾンビ
- No.20で扱う重大ネタバレ対象
- 1回目を通常Game Overにしない
- 1回目 → 異常／フーフー → 偽リセット → 「もういちど」
- 「もういちど」後、わたべ加入／特殊参加 → 再戦
- この一連を**裏ワザ**として扱う
- 最終能力値・AI・勝敗条件はTBD

詳細: `BATTLE_SPEC.md` / `MONSTER_SPEC.md`

詳細: `SAVE_FLAG_SPEC.md`

## 17. 異常演出・「もういちど」
### 導入
約5秒の短い制御異常のみ。

### 終盤
世界の異常を段階的に強める。

### 正式「もういちど」骨格
1. オロチゾンビ1回目
2. バグ／フーフー等
3. データが消えた／初めからになったように見せる
4. OP／タイトル側
5. 「もういちど」
6. **同じNo.01「はじまりのばしょ」へ戻る**
7. 主人公・タロサ・ミレイは記憶を保持
8. わたべ加入／特殊参加
9. No.20でオロチゾンビ再戦

実データは絶対に削除しない。

## 18. 真のエンディング
- 真の最終解決後、主人公とわたべは主人公の元世界へ帰る
- ミレイは主人公に恋心を抱いており、最後に別れる
- 主人公と仲間の冒険の記憶は「なかったこと」にしない
- 元世界を正常なレトロRPG画面で見せ、冒頭5秒の断片を回収する
- 主人公を操作不能にする
- 元世界の別の勇者／主人公役が主人公へ話しかける
- 主人公がNPCとして短い定型台詞を返す
- これにより、説明ではなく操作体験で「本来ただのNPCだった」と明かす

正確な別れの台詞、NPC台詞、元世界名等はTBD。
