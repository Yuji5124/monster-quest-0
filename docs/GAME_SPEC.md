# Monster Quest 0 ～幻の冒険の書～ ゲーム仕様

更新日: 2026-09-09

## 1. 基本コンセプト
- 正式タイトル：Monster Quest 0 ～幻の冒険の書～
- 広告・紹介用コピー：「誰も知らないゲーム、やってみる？」
- ジャンル：FC後期〜初期SFCを思わせる2Dドット絵コマンドRPG
- 想定プレイ時間：約5時間
- 対象：子どもだけでなく、大人と子どもが一緒に遊べる構成
- Webブラウザで遊べることを優先し、iPhone Safari対応を重視する

## 2. 基本パーティ
- 主人公
- タロサ
- ミレイ
- タロサとミレイは物語の途中で仲間になる
- ミレイはレインランドの姫であることを隠して旅に加わる
- 終盤の重要な仕掛け・正体・ボス情報は公開仕様では伏せる

## 3. 本編方針
- 序盤から事件・探索・仲間との掛け合い・ボス攻略を入れ、単調なレベル上げだけにしない
- 主要ボスは、少ないヒントから攻略法を見つける楽しさを持たせる
- レベル上げは必要だが、長時間の作業にはしない
- 町・村・ダンジョンは必要以上に巨大化させず、約5時間で完走できる密度にする
- ジャンカードは独立したサブゲームとして楽しめるようにし、本編クリア必須にはしない

## 4. 基本システム
- 見下ろし型フィールド移動
- NPC会話
- 宝箱・イベント
- コマンド式戦闘
- 経験値・レベルアップ
- 所持金
- アイテム
- 魔法
- セーブ / ロード
- ジャンカード収集
- スマートフォン向けタッチ操作

## 5. 戦闘方針
- 昔ながらのコマンドRPGとして分かりやすくする
- 通常戦闘はテンポよく短めにする
- ボス戦はレベルだけでなく、行動・装備・魔法・ヒントの理解で攻略しやすくする
- 詳細は `BATTLE_SPEC.md` を正とする

## 6. 開発方針
- GitHubを仕様・ソースの中心にする
- ゲームエンジン：Phaser
- 制作基盤：Phaser Game Agent
- メイン実装：Claude Code
- コードレビュー / デバッグ：Codex
- 仕様整理 / 画像制作 / プロンプト設計：ChatGPT
- Astraは量産フェーズで必要に応じて使用
- ASRSは使用しない
- 独自RPGエンジンや独自マップエディタは作らない
- AI実装80% / 人間による視覚調整20%を基本とする

## 7. 実装順序
最初にVertical Sliceを完成させる。

1. タイトル
2. はじまりのまち
3. フィールド
4. ザコ戦
5. レベルアップ
6. 小ダンジョン
7. ボス
8. セーブ / ロード
9. iPhone Safari確認

この一連が製品版品質で通るまでは、エリアを大量追加しない。

## 8. 重要ルール
- 確定設定をAIが勝手に変更しない
- 既存の正式画像を仮素材へ置き換えない
- 新システムを必要以上に増やさない
- 量産フェーズでは、既存システムを再利用し、マップ・データ・画像・会話差し替えを中心にする
- ネタバレ要素は公開ドキュメント・広告・紹介素材では伏せる
