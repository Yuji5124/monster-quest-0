# モンスタークエスト0 ゲーム仕様

最終更新: 2026-09-24 JST

## 1. 基本コンセプト
- タイトル: **モンスタークエスト0**
- 正式サブタイトル: **～幻の冒険の書～**
- 広告コピー: **「誰も知らないゲーム、やってみる？」**
- ジャンル: レトロRPG風コマンドRPG
- 想定プレイ時間: **初見約4時間30分 / 寄り道込み約5時間30分**
- 歩行キャラクター・UI: FC〜初期SFC風2Dドット絵。ローカルマップ背景は高解像度の1枚絵を使用できる
- 戦闘・イベント背景: 高品質2D JRPG／アニメ背景方向
- UI: シンプルで読みやすいレトロデザイン
- 全編を均一に豪華化せず、**始まり・主要人物の交差・「もういちど」以降・終盤／ED**へ密度を集中する

## マップ制作とワールド移動
- 新規の町・村・城・ダンジョン・イベント地点は、高解像度背景画像を正本とする。
- 歩行判定は制作時に背景から生成し、人間が修正したCollision Maskを利用する。ゲーム実行中にAI画像認識は行わない。
- ローカルマップは `BACKGROUND` / `COLLISION` / `EVENT` / `OBJECT` の4レイヤーで管理する。
- 地域間はポイント選択式ワールドマップで移動する。巨大フィールドを全面徒歩横断する方式は採用しない。
- 詳細は `MAP_SYSTEM.md` を正とする。既存Tiled実装は削除せずlegacyとして保持する。

## 3. オープニング
正式骨格:
1. タイトル
2. 「はじめから」
3. 黒背景の内部プログラム断片とデジタルノイズだけを映す、5秒の制御された起動ノイズ
4. 完全な暗闇から始まる**No.01「はじまりのばしょ」夜版の焚き火導入**（0:02〜0:07で明転）
5. ナレーション、焚き火を見る主人公の「…………。」
6. BGMなし・焚き火／風／水辺の環境音だけで最初の操作を解放
7. 昼版または次導線
8. **No.02「はじまりのまち」**へ

固定ルール:
- 開始直後の偽「ぼうけんのしょが きえました」は使わない
- 初見で意味を説明しない
- プレイヤーへの直接メタ会話をしない
- 本格的な世界崩壊は終盤へ残す

詳細: `OPENING_SPEC.md`

## 4. 主要キャラクター
### 主人公
- 男性
- 別のモンスタークエスト作品／別バージョン世界にいた**ただのNPCだった人物**
- 世界間の異常でMQ0へ迷い込む
- 最初から選ばれた勇者ではない
- 特別な血筋にしない
- エレキテル採用
- 原則ほとんど喋らない。まとまった会話はNo.18いしのまちとオロチゾンビ初回戦を基準に絞り、人格は行動で示す
- 旧女性勇者風主人公・旧 `hero_walk.png` は現行主人公として使用しない

### タロサ
- 途中加入
- 青い逆立ち髪、尖耳、弓、緑の腰布
- 努力すれば強くなり、強くなれば守れると信じる人物
- No.08ザボンのむらの出身。No.09いわやまのどうくつで一時参加し、共闘後に正式同行する
- No.19で毒の矢が届いた経験を踏まえ、終盤は帰る場所があってもさらに先へ進むことを自分で選ぶ。本編でデスタロッサ本人にはならない

### ミレイ
- 途中加入
- レインランドの姫
- No.10かくれざとで出会い、魔法を覚えたばかりの状態で身分を隠す。No.11みずうみの古城で正式同行する
- 主人公への恋心は旅の積み重ねで自然に描く
- 終盤は「戻される」のではなく、自分の意思でレインランド城へ帰ると決める

### わたべ
- 主要3人とは別の特殊参加キャラクター
- 固有攻撃「とくだいヒット」
- 「もういちど」以降の真の最終解決に関わる

## 6. 世界の裏構造
- MQ0には異なるモンスタークエスト作品／バージョン由来の断片が混在する
- 異なる世界由来の敵・ボスが同居する
- 主人公も世界混線で入り込んだ存在
- 終盤の異常な強さもこの混線と意味的につなげる
- 序盤から真相説明しない
- 子どもには普通のRPG、大人には考察可能な二重構造とする

## 7. NPC・会話
- 基本2パターン程度の短い台詞
- 生活感、仕事、地域、人物関係、噂、事件を分散
- 全員を攻略ヒント役／主要人物説明役にしない
- コンパクト化後のマップに必要なNPCだけを選抜・統合
- 未採用アイテム等を勝手に会話へ追加しない
- ジャンカードの秘密を序盤のNPCへ混ぜない

詳細: `NPC_SPEC.md`

## 17. 異常演出・「もういちど」
### 導入
開始直後には、内部プログラム層が一瞬だけ見える5秒の制御された起動ノイズを置いてから、No.01夜の焚き火導入へ入る。詳細は`OPENING_SPEC.md`を正とする。

### 終盤
世界の異常を段階的に強める。

### 正式「もういちど」骨格
1. オロチゾンビ1回目
2. バグ／フーフー等
3. データが消えた／初めからになったように見せる
4. OP／タイトル側
5. 「もういちど」
6. **同じNo.01「はじまりのばしょ」へ戻る**
7. 主人公・タロサ・ミレイは記憶を保持
8. わたべ加入／特殊参加
9. No.20でオロチゾンビ再戦

実データは絶対に削除しない。

## 18. 真のエンディング
- 真の決着後、旅で聞いた王・仲間・NPCの言葉をゆっくり表示してから、主人公が`ここに のこる`か`もとの せかいへ かえる`かを選ぶ。NPCは正解を教えない。
- `ここに のこる`では、主人公はMQ0世界に残り、世界の修復とともに混線由来の存在として徐々に消えていく。`もとの せかいへ かえる`では、本来のNPCとして操作不能になったように見えてから、MQ0の記憶を取り戻し、自分の意思で一歩を踏み出す。
- レイはどちらの未来にも生まれる。隠しボス討伐時点でミレイは妊娠しておらず、タロサはレイの父親にしない。主人公の全体としての命の長さは両ルートで同じとする。
- どちらの道でも主人公と仲間の冒険の記憶を「なかったこと」にしない。旧「ミレイは出産時に亡くなり、主人公がレイを育てる」案は**SUPERSEDED**。

選択条件、正式な分岐名、台詞、NPC台詞、元世界名等はTBD。
