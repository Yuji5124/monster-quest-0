# モンスタークエスト0 ゲーム仕様

最終更新: 2026-09-09 19:22 JST

## 1. 基本コンセプト
- タイトル: モンスタークエスト0
- 正式サブタイトル: ～幻の冒険の書～
- 広告・紹介用コピー: 「誰も知らないゲーム、やってみる？」
- ジャンル: 昔懐かしいレトロRPG風のコマンドRPG
- 想定プレイ時間: 約5時間を目標
- マップ・キャラクター: 2Dドット絵を基本とする
- 戦闘背景: 単純なFC風より一段きれいなレトロRPG背景
- 対象: 子どもだけでなく、大人と子どもが一緒に遊べる構成

## 2. 主要パーティ
主要パーティは3人。
- 主人公
- タロサ
- ミレイ

タロサとミレイは物語途中で仲間になる。
ミレイはレインランドの姫であることを隠して旅に加わる。

わたべは主要3人パーティとは分け、イベント・特殊参加キャラクターとして管理する。

## 3. 世界・進行方針
- 序盤から事件、探索、NPC会話、仲間との掛け合い、ボス攻略を入れる。
- 町・村・ダンジョンには地域ごとの生活・文化・役割を持たせる。
- レインランドを正式な国として実装する。
- 序盤から中盤は、普通の昔ながらのRPGとして成立させる。
- 終盤の真相やボスに関する情報は公開仕様では伏せる。
- 主要ボスは、少ないヒントから攻略法を見つける遊びを重視する。

## 4. 基本システム
- 見下ろし型フィールド移動
- NPC会話
- 宝箱・イベント
- コマンド式戦闘
- 経験値・レベルアップ
- 所持金
- アイテム・装備
- 魔法
- セーブ／ロード
- ジャンカードガチャ／コレクション

## 5. ジャンカード
- 正式総数は45枚。
- 1回20円を基本とする。
- 収集は独立したサブゲームとして成立させる。
- 本編攻略必須にはしない。
- カード仕様の正本は `docs/CARD_SPEC.md`。

## 6. モンスター
- 正式総数は25体。
- 公開用資料では終盤ネタバレ対象の名前・姿を伏せる。
- 実装用画像は `assets/monsters/battle/` で管理する。

## 7. 画像・アセット
- 正式ファイル名・状態: `docs/ASSET_INDEX.md`
- 画像制作仕様: `docs/IMAGE_SPEC.md`
- 機械可読アセット一覧: `assets/asset_catalog.json`
- 実装コード側では画像パスを散在させず、preload / manifestへ集約する。

## 8. 開発方針
- GitHubを仕様・ソース・アセット管理の中心にする。
- ゲーム実装の中心: Phaser 3
- マップ制作はTiled等との連携を想定する。
- ChatGPT: 仕様整理、画像制作、命名、設計
- Phaser Game Agent: Phaser実装の基本担当
- Codex / Claude Code: 複数ファイル修正、デバッグ、参照パス更新、検証
- Webブラウザで遊べる構成を優先し、iPhoneでもプレイ可能な操作設計を目指す。

## 9. 公開時のネタバレ管理
- 終盤ボスの姿・名前は広告、雑誌風ページ、パッケージ等に掲載しない。
- 必要な場合はシルエットまたは `？？？` を使用する。
- 内部仕様・内部ファイル名では正式名称を保持する。
