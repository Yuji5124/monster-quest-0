# モンスタークエスト0 ゲーム仕様

## 1. 基本コンセプト
- タイトル：モンスタークエスト0
- キャッチコピー：誰も知らないゲーム、やってみる？
- ジャンル：昔懐かしいドット絵風コマンドRPG
- 想定プレイ時間：約1時間
- マップ・キャラクター：2Dドット絵風
- 対象：子どもだけでなく、大人と子どもが一緒に遊べる構成

## 2. パーティ
- 通常プレイ時の仲間は計3人
- 仲間加入はゲーム進行に合わせて行う
- 終盤の重要な仕掛けについては公開仕様には記載しない

## 3. プレイ構成
- 0〜5分：導入・最初の町
- 5〜15分：草原・初戦闘・レベル上げ
- 15〜25分：仲間加入・小ダンジョン
- 25〜35分：仲間加入・中盤エリア
- 35〜45分：3人パーティ完成・中ボス
- 45〜60分：最終エリア・終盤イベント・エンディング

## 4. 基本システム
- 見下ろし型フィールド移動
- NPC会話
- 宝箱・イベント
- コマンド式戦闘
- 経験値・レベルアップ
- 所持金
- アイテム
- セーブ／ロード
- ジャンカード収集

## 5. 開発方針
- GitHubを仕様・ソースの中心にする
- 実装：Claude Code
- コードレビュー／デバッグ：Codex
- 仕様書・コンセプト・画像仕様：ChatGPT
- 画像生成：ChatGPT
- Webで遊べる構成を優先
- エンジン候補：RPGJS + Tiled + TypeScript

## 6. 重要方針
- 序盤〜中盤は、普通の昔ながらのRPGとして成立させる
- 特殊な違和感・異常演出は終盤に限定する
- ネタバレ要素は公開仕様書から分離する
