# モンスタークエスト0 ゲーム仕様

最終更新: 2026-09-21 JST

## 1. 基本コンセプト
- タイトル: **モンスタークエスト0**
- 正式サブタイトル: **～幻の冒険の書～**
- 広告コピー: **「誰も知らないゲーム、やってみる？」**
- ジャンル: レトロRPG風コマンドRPG
- 想定プレイ時間: **初見約4時間30分 / 寄り道込み約5時間30分**
- 歩行キャラクター・UI: FC〜初期SFC風2Dドット絵。ローカルマップ背景は高解像度の1枚絵を使用できる
- 戦闘・イベント背景: 高品質2D JRPG／アニメ背景方向
- UI: シンプルで読みやすいレトロデザイン
- 全編を均一に豪華化せず、**始まり・主要人物の交差・「もういちど」以降・終盤／ED**へ密度を集中する

## 2. タイトル画面

旧名称「ふっかつのじゅもん」は使わず、**「たびのあいことば」**へ統一する。

## マップ制作とワールド移動
- 新規の町・村・城・ダンジョン・イベント地点は、高解像度背景画像を正本とする。
- 歩行判定は制作時に背景から生成し、人間が修正したCollision Maskを利用する。ゲーム実行中にAI画像認識は行わない。
- ローカルマップは `BACKGROUND` / `COLLISION` / `EVENT` / `OBJECT` の4レイヤーで管理する。
- 地域間はポイント選択式ワールドマップで移動する。巨大フィールドを全面徒歩横断する方式は採用しない。
- 詳細は `MAP_SYSTEM.md` を正とする。既存Tiled実装は削除せずlegacyとして保持する。

## 特殊ゲームプレイ
- 通常はレトロRPGを基盤とする。
- 世界混線・破損が強い地点では、見た目・描画方式・ゲームルールが一時的に変化する。
- 正式採用: ビーエの荒れた／バグ景観、ザボンの壊れた景観、まじんのどうくつのターン制ダンジョンRPG、まじんの段階巨大化、ブロック／ボクセル風の城内部、ぬまちのどうくつのアクション、多数敵、**横アクション区間、縦アクション区間、後半シューティング区間**。
- 特殊区間は本編と無関係なミニゲームではなく、世界の混線をプレイヤーが操作感で体験するためのものとする。
- 特殊区間の具体的な配置・尺・操作・ステータス連携は `SPECIAL_GAMEPLAY_SPEC.md` と `TBD_REGISTRY.md` を正とする。

## 3. オープニング
正式骨格:
1. タイトル
2. 「はじめから」
3. 完全な暗闇から始まる**No.01「はじまりのばしょ」夜版の焚き火導入**（0:02〜0:07で明転）
4. ナレーション、焚き火を見る主人公の「…………。」
5. BGMなし・焚き火／風／水辺の環境音だけで最初の操作を解放
6. 昼版または次導線
7. **No.02「はじまりのまち」**へ

固定ルール:
- 開始直後の偽「ぼうけんのしょが きえました」は使わない
- 初見で意味を説明しない
- プレイヤーへの直接メタ会話をしない
- 本格的な世界崩壊は終盤へ残す

詳細: `OPENING_SPEC.md`

## 4. 主要キャラクター
### 主人公
- 男性
- 別のモンスタークエスト作品／別バージョン世界にいた**ただのNPCだった人物**
- 世界間の異常でMQ0へ迷い込む
- 最初から選ばれた勇者ではない
- 特別な血筋にしない
- エレキテル採用
- 旧女性勇者風主人公・旧 `hero_walk.png` は現行主人公として使用しない

### タロサ
- 途中加入
- 青い逆立ち髪、尖耳、弓、緑の腰布
- 強さを求める人物
- No.06 ザボンのむらに関係する

### ミレイ
- 途中加入
- レインランドの姫
- 身分を隠して旅へ加わる
- 主人公への恋心は旅の積み重ねで自然に描く

### わたべ
- 主要3人とは別の特殊参加キャラクター
- 固有攻撃「とくだいヒット」
- 「もういちど」以降の真の最終解決に関わる

## 5. 世界・マップ
- **物語上のプレイ順は `PLAY_ORDER_SPEC.md` を正とし、既存No.01〜20の互換番号順をストーリー順として使わない**

## 6. 世界の裏構造
- MQ0には異なるモンスタークエスト作品／バージョン由来の断片が混在する
- 異なる世界由来の敵・ボスが同居する
- 主人公も世界混線で入り込んだ存在
- 終盤の異常な強さもこの混線と意味的につなげる
- 序盤から真相説明しない
- 子どもには普通のRPG、大人には考察可能な二重構造とする

## 7. NPC・会話
- 基本2パターン程度の短い台詞
- 生活感、仕事、地域、人物関係、噂、事件を分散
- 全員を攻略ヒント役／主要人物説明役にしない
- コンパクト化後のマップに必要なNPCだけを選抜・統合
- 未採用アイテム等を勝手に会話へ追加しない
- ジャンカードの秘密を序盤のNPCへ混ぜない

## 17. 異常演出・「もういちど」
### 導入
開始直後は異常画面を使わず、No.01夜の焚き火導入を使う。詳細は`OPENING_SPEC.md`を正とする。

### 終盤
世界の異常を段階的に強める。

### 正式「もういちど」骨格
1. オロチゾンビ1回目
2. バグ／フーフー等
3. データが消えた／初めからになったように見せる
4. OP／タイトル側
5. 「もういちど」
6. **同じNo.01「はじまりのばしょ」へ戻る**
7. 主人公・タロサ・ミレイは記憶を保持
8. わたべ加入／特殊参加
9. No.20でオロチゾンビ再戦

実データは絶対に削除しない。

## 18. 真のエンディング
- 真の最終解決後、主人公とわたべは主人公の元世界へ帰る
- ミレイは主人公に恋心を抱いており、最後に別れる
- 主人公と仲間の冒険の記憶は「なかったこと」にしない
- 元世界を正常なレトロRPG画面で見せ、冒頭5秒の断片を回収する
- 主人公を操作不能にする
- 元世界の別の勇者／主人公役が主人公へ話しかける
- 主人公がNPCとして短い定型台詞を返す
- これにより、説明ではなく操作体験で「本来ただのNPCだった」と明かす

正確な別れの台詞、NPC台詞、元世界名等はTBD。
