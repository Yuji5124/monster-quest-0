# モンスタークエスト0 戦闘仕様

最終更新: 2026-09-12 JST

このファイルは戦闘システム・ボス攻略・数値管理の正本。最終バランス値は `TBD_REGISTRY.md` に従い、根拠なく確定しない。

## 1. 基本
- 昔ながらのコマンド式RPG戦闘。
- 通常戦闘で経験値・所持金を得てレベルアップする。
- 草原・森・洞窟等のエリアごとにエンカウントテーブルを持つ。
- ボス戦は単純なレベル勝負だけでなく、少ないヒントから攻略法を見つける遊びを入れる。
- 初見約4時間30分 / 寄り道込み約5時間30分の作品として過度なレベル上げを要求しない。

## 2. 基本コマンド
最低限:
- たたかう
- まほう
- どうぐ
- にげる

必要に応じて防御等を追加する場合はユーザー確定後に正式化する。

## 3. 行動処理
- 1ターン内の行動順は素早さを基本にする想定。
- 最終式はTBD。
- 同速処理、命中率、回避率、状態異常成功率等も最終値はTBD。
- Scene内へ計算式を散在させずBattleSystemへ集約する。

## 4. ダメージ
最終ダメージ式はTBD。

実装段階では以下を守る:
- 攻撃力・防御力・技倍率等をデータ側で管理する。
- 最低ダメージ、乱数幅、属性倍率は一か所に集約する。
- TEMP値は `TEMP_TEST_VALUE` と明記する。
- 最終値として固定しない。

## 5. だいヒット
- 一般的な「クリティカル」という表示は使わない。
- 正式戦闘メッセージは **「だいヒット」**。
- 発生率・倍率はTBD。

## 6. わたべ
- わたべは主要3人パーティとは別の特殊参加キャラクター。
- 固有攻撃 **「とくだいヒット」** を使用できる。
- 通常の「だいヒット」より強い特別な攻撃として扱う。
- **「もういちど」以降のオロチゾンビ再戦／最終解決に関わる。**
- 最終倍率はTBD。

## 7. 戦闘不能・回復
- HPが0になったキャラクターは戦闘不能。
- `ライフ` は回復系魔法として扱う。
- `リライフ` はMQ0内では戦闘不能からの復活魔法として採用する。
- 原作でのリライフの意味は未確定のため「原作確定情報」と混同しない。
- 通常全滅時の最終ペナルティ・復帰地点はTBD。
- **オロチゾンビ1回目の失敗／異常遷移は通常全滅処理と分離し、`GLITCH_SPEC.md` のストーリーイベントとして扱う。**

## 8. 魔法

## 9. デーマス戦
正式な攻略骨格:
- デーマスは中ボス級。
- Lv15程度の進行帯を目安とする。
- デーマスは「ミラー」に関係する攻略構造を持つ。
- 強力な「ダイダイン」で主人公側を追い込む。
- 反射を利用して逆転することが戦闘の核。
- NPCや周辺情報から少ないヒントを与える。
- 正解を戦闘開始時に説明しない。

原作資料で確認されたデーマスのHP1000 / MP500 / 攻撃300等は「原作側参考値」であり、MQ0最終ゲームバランス値として自動採用しない。

## 10. 終盤ボス
- バトラス
- オロチまおう
- **オロチゾンビ（裏ボス / 重大ネタバレ）**

公開資料では重大ネタバレの名前・姿を伏せる。

### オロチゾンビ
- **裏ボス**として扱う。
- No.20 最終地点（内部名「オロチゾンビのま」）で扱う。
- 1回目は通常のレベル／火力だけで押し切る戦闘として設計しない。
- 1回目 → 異常／フーフー → 偽リセット → 「もういちど」へ接続する。
- 「もういちど」後、わたべ加入／特殊参加を経て再戦する。
- この一連を**裏ワザ**として扱う。
- 再戦ではわたべの「とくだいヒット」等、通常進行では得られない要素を最終解決へ関与させる。
- 異常な強さは、複数のモンクエ世界／バージョンが重なったMQ0世界の裏構造と意味的につなげる。
- 1回目と再戦のHP・攻撃・AI・強制イベント条件・勝敗条件はTBD。

最終特殊戦は通常戦闘だけで完結せず `GLITCH_SPEC.md` / `STORY_FLOW.md` へ接続する。

## 11. エンカウント設計
- 草むら・危険地域等で通常戦闘が発生する。
- 地域ごとの敵構成・出現率はJSON管理。
- 移動数を水増しするほど高エンカウントにしない。
- レベル上げが必要でも、短時間で成長実感が出る調整を優先する。

## 12. 戦闘終了
勝利時:
- EXP
- G
- 必要に応じてドロップ
- レベルアップ判定
- ボス時は進行フラグ

通常敗北時:
- 実セーブを壊さない。
- 進行不能状態を作らない。

オロチゾンビ1回目:
- 通常の敗北／Game Overへそのまま落とさない。
- ストーリー用の異常遷移として「もういちど」シーケンスへ接続する。
- 実セーブ状態・ジャンカード取得状態を保護する。

## 13. 実装禁止
- 未確定数値をAIが最終値として確定する。
- ボス攻略を単なるHP増加だけで難しくする。
- 「クリティカル」表記へ戻す。
- デスタロッサをMQ0の敵として追加する。
- オロチゾンビ1回目を通常のGame Overとして処理して「もういちど」導線を失う。
- わたべ参加前提の再戦を、通常周回／New Game扱いにする。
