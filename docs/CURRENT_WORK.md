## マップ / NPCの現在状態
全体ワールドマップと主要地域構成は維持する。
見直すのは、各町・村・城の内部マップサイズとNPC配置。

これまで以下の地域に会話原案がある。
- はじまりのまち
- ビーエのむら
- レインランドのまち
- レインランドじょう
- ザボンのむら

既存会話案は**会話素材**として保持する。
小さくした町・村・城に合わせて、必要なNPCだけを選抜・統合する。

今後は地域ごとに、以下を先に決めてからNPC会話を確定する。
1. その地域が物語で果たす役割
2. 想定滞在時間
3. コンパクト化後の内部マップサイズと移動量
4. 必要な施設・建物
5. 必要NPCと役割
6. 必要な戦闘・イベント
7. 再訪の有無

NPCは主要人物の話題へ偏らせず、生活NPC・地域NPC・事件NPC・ヒントNPC・遊びNPCを自然に配置する。
