これまで以下の地域に会話原案がある。
- はじまりのまち
- ビーエのむら
- レインランドのまち
- レインランドじょう

ただし、旧大人数案・旧半減案ともに**会話素材 / 検討履歴**として扱い、最終人数・配置・建物数・地域サイズは未確定に戻す。

今後は地域ごとに、以下を先に決めてからNPC会話を確定する。
1. その地域が物語で果たす役割
2. 想定滞在時間
3. マップサイズと移動量
4. 必要な施設・建物
5. 必要NPCと役割
6. 必要な戦闘・イベント
7. 再訪の有無

NPCは主要人物の話題へ偏らせず、生活NPC・地域NPC・事件NPC・ヒントNPC・遊びNPCを自然に配置する。
