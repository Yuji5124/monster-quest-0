# モンスタークエスト0 モンスター仕様

最終更新: 2026-09-11 JST

このファイルはモンスター総数・役割・公開ネタバレ管理・戦闘データ方針の正本。

## 1. 固定値
- モンスター総数は **25体**。
- デスタロッサは別作品側の設定であり、Monster Quest 0には登場させない。
- 公開用一覧では重大ネタバレ対象の名前・姿を伏せる。
- 最終ネタバレ対象は必要に応じて `？？？` 表記とする。
- MQ0には異なるモンクエ作品／バージョン由来のモンスターやボスが混在する。これは単なる寄せ集めではなく、世界の混線を示す裏設定と結びつける。

## 3. 原作資料とMQ0ゲーム値の分離
原作／ジャンカード等で確認した数値は `sourceReference` として保持できるが、そのままゲームバランス値にしない。

確認済み参考例:
- デーマス: HP1000 / MP500 / 攻撃300
- まじん: HP800 / MP0 / 攻撃500
- ダイジャ: HP40 / MP0 / 攻撃20

これらは「原作側確認値」。MQ0の `hp`, `attack` 等へ自動コピーしない。

## 4. 25体一覧の扱い
- 25枠を最終総数として維持する。
- 未確定枠は `TBD` のまま残す。
- AIが穴埋め目的で新モンスター名を勝手に確定しない。
- 既存資料・ジャンカードから候補を取り込む場合も、採用確定と資料確認を区別する。
- 各敵について元作品／元バージョンが確実に分かる場合は、内部メタデータとして `sourceReference` 等に保持できる。
- 出典が分からない敵にAIが勝手なバージョン由来を設定しない。

## 5. データ項目
各モンスターは最低限以下を持つ。
- `id`
- `name`
- `publicName`
- `role`
- `hp`
- `mp`
- `attack`
- `defense`
- `speed`
- `exp`
- `gold`
- `skills`
- `encounterAreas`
- `sprite`
- `spoiler`
- `sourceReference`

未確定ゲーム値はnull。

## 6. 強さ設計
大枠:
序盤通常敵
→ 中盤通常敵／強敵
→ まじん級
→ デーマス級
→ バクラー級
→ バトラス
→ オロチまおう
→ 裏ボス／最終特殊戦

単純にHPだけを増やして強くしない。行動・魔法・攻略ギミックで違いを出す。

### 終盤の異常な強さ
- 終盤存在、とくにオロチゾンビの通常進行では説明しにくい強さは、**複数のモンクエ世界／バージョンの断片が重なったMQ0世界**と物語上つなげる。
- 「強いから数値を極端に高くした」だけにせず、世界構造と攻略ギミックの両方で理由を持たせる。
- 1回目は通常の強さだけでは解決できず、「もういちど」からの裏ワザ／わたべ参加を経た再戦へつなげる。
- 最終HP・攻撃力・行動パターンはTBD。

## 7. 出現設計
- 通常敵は地域ごとのencounter tableで管理する。
- ボスはイベント開始で戦闘へ入る。
- 地域の背景・生態と敵を可能な範囲で対応させる。
- 同じ敵を長時間出し続けない。
- 異なるバージョン由来の混在は、序盤から長文説明せず自然に同居させる。

## 8. 画像
- 正式画像パスと状態は `ASSET_INDEX.md` を正とする。
- 実装用素材と原資料を分離する。
- 公開資料に終盤ボス画像を不用意に出さない。
- オロチゾンビは公開用の一覧・進捗では `？？？` 扱いを基本とする。

## 9. 禁止
- 総数を25体から勝手に変更する。
- デスタロッサを追加する。
- 原作参考値をMQ0最終バランス値と誤認する。
- 公開用画面に重大ネタバレ内部名をそのまま表示する。
- 出典未確認の敵へ勝手に元バージョンを割り当てる。
- 裏ボスの異常な強さを物語・攻略と無関係な単純インフレだけで処理する。
