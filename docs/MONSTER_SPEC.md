# モンスタークエスト0 モンスター仕様

最終更新: 2026-09-12 JST

このファイルはモンスター総数・役割・公開ネタバレ管理・戦闘データ方針の正本。

## 1. 固定値
- モンスター総数は **25体**。
- デスタロッサは別作品側の設定であり、Monster Quest 0には登場させない。
- 公開用一覧では重大ネタバレ対象の名前・姿を伏せる。
- 最終ネタバレ対象は必要に応じて `？？？` 表記とする。

## 3. オロチゾンビ
- 内部正式名: オロチゾンビ。
- 公開用表示: 原則 `？？？`。
- **裏ボス**として扱う。
- 1回目は通常Game Overではなく、「もういちど」シーケンスへ接続する特殊戦。
- 「もういちど」→わたべ加入／特殊参加→再戦の一連は**裏ワザ**。
- 1回目／再戦の最終HP・MP・攻撃・AI・勝敗条件はTBD。
- 異常な強さは、複数のモンクエ世界／バージョンの断片が重なったMQ0世界の裏構造と意味的につなげる。

## 4. 原作資料とMQ0ゲーム値の分離
原作／ジャンカード等で確認した数値は `sourceReference` として保持できるが、そのままゲームバランス値にしない。

確認済み参考例:
- デーマス: HP1000 / MP500 / 攻撃300
- まじん: HP800 / MP0 / 攻撃500
- ダイジャ: HP40 / MP0 / 攻撃20

これらは「原作側確認値」。MQ0の `hp`, `attack` 等へ自動コピーしない。

## 5. 25体一覧の扱い
- 25枠を最終総数として維持する。
- 未確定枠は `TBD` のまま残す。
- AIが穴埋め目的で新モンスター名を勝手に確定しない。
- 既存資料・ジャンカードから候補を取り込む場合も、採用確定と資料確認を区別する。

## 6. データ項目
各モンスターは最低限以下を持つ。
- `id`
- `name`
- `publicName`
- `role`
- `hp`
- `mp`
- `attack`
- `defense`
- `speed`
- `exp`
- `gold`
- `skills`
- `encounterAreas`
- `sprite`
- `spoiler`
- `sourceReference`

未確定ゲーム値はnull。

## 7. 強さ設計
大枠:
序盤通常敵
→ 中盤通常敵／強敵
→ まじん級
→ デーマス級
→ バクラー級
→ バトラス
→ オロチまおう
→ **オロチゾンビ（裏ボス）**

単純にHPだけを増やして強くしない。行動・魔法・攻略ギミック・物語上の特殊条件で違いを出す。

## 8. 出現設計
- 通常敵は地域ごとのencounter tableで管理する。
- ボスはイベント開始で戦闘へ入る。
- オロチゾンビは通常encounter tableへ入れない。
- 地域の背景・生態と敵を可能な範囲で対応させる。
- 同じ敵を長時間出し続けない。

## 9. 画像
- 正式画像パスと状態は `ASSET_INDEX.md` を正とする。
- 実装用素材と原資料を分離する。
- 公開資料に終盤ボス画像を不用意に出さない。

## 10. 禁止
- 総数を25体から勝手に変更する。
- デスタロッサを追加する。
- 原作参考値をMQ0最終バランス値と誤認する。
- オロチゾンビを通常ラスボス扱いへ戻す。
- 公開用画面に重大ネタバレ内部名をそのまま表示する。
