# Monster Quest 0 ～幻の冒険の書～ Project Overview

更新日: 2026-09-09

## 1. このゲームは何か
『Monster Quest 0 ～幻の冒険の書～』は、FC後期〜初期SFCを思わせる2Dドット絵のコマンドRPG。

目標は、懐かしい見た目を保ちながら、マップ・キャラクター・戦闘背景・UIを丁寧に仕上げた約5時間の作品にすること。

## 2. 制作の最優先事項
1. 短期間で完成させる
2. 正式素材を早い段階から実ゲームへ入れる
3. AIに実装を任せつつ、見た目の最終20%は人間が調整する
4. iPhone Safariで遊べることを常に確認する
5. 仕様の正解はGitHub上のMarkdownに集約する

## 3. 開発スタック
- Phaser
- Phaser Game Agent
- Claude Code
- Codex
- ChatGPT
- GitHub
- 必要に応じてPhaser Tilemap Editor等の視覚編集ツール
- Astraは量産フェーズから必要に応じて導入

## 4. 使用しないもの
- ASRS
- 独自RPGエンジン
- 独自マップエディタ
- 汎用RPG制作ツール化

## 5. AIの役割
### ChatGPT
- 全体仕様の整理
- ストーリー・NPC・マップ設計
- 画像仕様と画像制作
- Claude Code / Codex向け指示書作成
- GitHub仕様書更新

### Claude Code + Phaser Game Agent
- メイン実装
- マップ、戦闘、イベント、UI、セーブ、タッチ操作
- 正式素材の組み込み
- Vertical Slice制作

### Codex
- 節目ごとのレビュー
- バグ修正
- モバイル検証
- セーブ、イベント、戦闘、パフォーマンス等のQA

### Astra
- 基本システム完成後の並列制作
- 町、ダンジョン、QA等を分担する量産フェーズで使用

## 6. 基本制作方法
AI 80% / 人間の視覚調整20%。

AIに大枠を作らせ、以下のみ人間が重点調整する。
- 木・建物・道などの配置
- キャラクターの数ピクセル単位の修正
- 色・輪郭・視認性
- マップ密度
- UIの余白

## 7. 最初の完成目標
Vertical Sliceを先に完成させる。

タイトル
→ はじまりのまち
→ フィールド
→ ザコ戦
→ レベルアップ
→ 小ダンジョン
→ ボス
→ セーブ / ロード
→ iPhone Safari実機確認

ここが完成するまで、全世界を同時に作らない。

## 8. 現在の主要確定事項
- プレイ時間：約5時間
- 基本パーティ：主人公・タロサ・ミレイ
- モンスター総数：25体
- ジャンカード：全45枚
- ジャンカードは本編攻略必須ではない
- 正式素材として、主要3人歩行スプライト、基本タイルセット、NPC基本10体、モンスター素材、共通UIを用意している
- 戦闘背景は地域ごとに高品質ピクセルアートを使用する

## 9. Source of Truth
仕様が食い違う場合は以下の順で優先する。

1. `docs/DECISIONS.md`
2. 各専門仕様書

4. 実装コード
5. 古いコメント・過去資料
