# モンスタークエスト0 QA仕様

最終更新: 2026-09-10 23:46 JST

## 1. 目的
Claude Code / Codex / Phaser Game Agentが、同じ品質基準で確認する。

## 2. 毎回の最低回帰
- 起動
- タイトル
- はじめから
- 町へ入る
- NPC会話
- フィールド移動
- 戦闘開始 / 終了
- メニュー
- セーブ / ロード

未実装部分は除外してよいが、既存部分を壊していないか確認する。

## 3. マップ
- 壁抜けしない
- 出入口が正しい
- 進行不能になる閉じ込めがない
- NPCへ話しかけられる
- イベントが二重発火しない
- Foreground表示が破綻しない
- マップ再入場で状態が不自然に巻き戻らない

## 4. NPC / イベント
- 基本会話が表示される
- 進行による会話変化
- 一度きりイベントの再発火防止
- 宝箱開封状態
- 仲間二重加入防止
- ボス再戦条件
- タッチ連打でイベントが重複しない

## 5. 戦闘
- こうげき
- まほう
- アイテム
- にげる
- 敵行動
- HP / MP
- 戦闘不能
- 全滅
- 勝利
- EXP
- レベルアップ
- だいヒット表記

特殊ボスは共通戦闘を壊していないか確認する。

## 6. セーブ
- versionあり
- マップ / 座標
- パーティ
- レベル / HP / MP
- 所持品 / 装備 / 所持金
- ストーリーフラグ
- 宝箱
- ボス
- NPC進行
- ジャンカード

偽データ消失演出後も実データが残ること。

## 7. ジャンカード
- 1回20円
- No.順の固定排出
- ダブりなし
- 45枚取得後の挙動
- 所持金不足
- 図鑑反映
- セーブ / ロード

## 8. iPhone Safari
- 起動
- タッチ移動
- 決定 / キャンセル
- 会話送り
- 戦闘コマンド
- メニュー
- Safe Area
- 画面回転 / リサイズ時の致命的崩れなし
- 音声開始
- 長押し / ダブルタップ等による誤操作が致命的でない

## 9. パフォーマンス
- 長時間プレイで極端に重くならない
- Scene移動でListener / Timer / BGMが増殖しない
- 戦闘反復でオブジェクトが残留しない
- 高品質背景で操作が重くならない

## 10. 終盤演出
- 本当のフリーズなし
- 本当のデータ削除なし
- 無限ループなし
- 長時間操作不能なし
- 演出終了後に進行できる

## 11. Visual QA
人間が確認する。
- 木 / 道 / 建物の自然さ
- 装飾密度
- 主人公の見やすさ
- NPCの配置
- 敵と戦闘背景の視認性
- UI余白
- 文字サイズ
- 会話テンポ
- 戦闘テンポ

## 12. 不具合優先度
### P0
起動不可、セーブ破損、進行不能、無限ループ。

### P1
主要機能が使えない、ボス / 戦闘 / マップ遷移が壊れる。

### P2
表示崩れ、軽微なイベント誤動作、バランス問題。

### P3
装飾、微調整、表現改善。

## 13. 完了
`DEFINITION_OF_DONE.md` の基準を満たすまでDONEにしない。
