# モンスタークエスト0 QA仕様

最終更新: 2026-09-11 08:31 JST

## 1. 目的
Claude Code / Codex / Phaser Game Agentが、同じ品質基準で確認する。

## 2. 毎回の最低回帰
- 起動
- タイトル
- はじめから
- 約5秒の導入異常
- No.18「はじまりのばしょ」夜版
- 主人公歩行
- はじまりのまちへ入る
- NPC会話
- フィールド移動
- 戦闘開始 / 終了
- メニュー
- セーブ / ロード

未実装部分は除外してよいが、既存部分を壊していないか確認する。

## 3. オープニング
- 導入異常は約5秒の短い制御された演出である
- 本当のエラー / フリーズを起こさない
- No.18夜版へ確実に遷移する
- 最新男性主人公が表示される
- 旧女性 `hero_walk.png` が使われていない
- 焚き火付近で開始する
- 操作開始が遅すぎない
- 直接メタ会話がない
- 開始直後の偽セーブ消失がない
- 夜→昼または次導線が破綻しない
- BGM / 環境音 / 無音切替が二重再生しない

## 4. マップ
- 壁抜けしない
- 出入口が正しい
- 進行不能になる閉じ込めがない
- NPCへ話しかけられる
- イベントが二重発火しない
- Foreground表示が破綻しない
- マップ再入場で状態が不自然に巻き戻らない
- No.18夜 / 昼の状態が混同されない

## 5. NPC / イベント
- 基本会話が表示される
- 進行による会話変化
- 一度きりイベントの再発火防止
- 宝箱開封状態
- 仲間二重加入防止
- ボス再戦条件
- タッチ連打でイベントが重複しない

## 6. 戦闘
- こうげき
- まほう
- アイテム
- にげる
- 敵行動
- HP / MP
- 戦闘不能
- 全滅
- 勝利
- EXP
- レベルアップ
- だいヒット表記

特殊ボスは共通戦闘を壊していないか確認する。

## 7. セーブ
- versionあり
- マップ / 座標
- パーティ
- レベル / HP / MP
- 所持品 / 装備 / 所持金
- ストーリーフラグ
- 宝箱
- ボス
- NPC進行
- ジャンカード

後半で偽データ消失演出を使う場合も実データが残ること。
開始直後には偽セーブ消失を出さないこと。

## 8. ジャンカード
- 1回20円
- No.順の固定排出
- ランダムではない
- ダブりなし
- 45枚取得後の挙動
- 所持金不足
- 図鑑反映
- セーブ / ロード

## 9. iPhone Safari
- 起動
- 導入異常から正常に復帰
- No.18でタッチ移動
- 決定 / キャンセル
- 会話送り
- 戦闘コマンド
- メニュー
- Safe Area
- 画面回転 / リサイズ時の致命的崩れなし
- 音声開始
- 長押し / ダブルタップ等による誤操作が致命的でない

## 10. パフォーマンス
- 長時間プレイで極端に重くならない
- Scene移動でListener / Timer / BGMが増殖しない
- 導入異常用Effect / Timerが終了後に残留しない
- 戦闘反復でオブジェクトが残留しない
- 高品質背景で操作が重くならない

## 11. 終盤演出
- 本当のフリーズなし
- 本当のデータ削除なし
- 無限ループなし
- 長時間操作不能なし
- 演出終了後に進行できる
- 導入約5秒異常との差が十分にある

## 12. Visual QA
人間が確認する。
- 始まりの夜の雰囲気
- 焚き火の見え方
- 夜→昼の変化
- 主人公の見やすさ
- 木 / 道 / 建物の自然さ
- 装飾密度
- NPCの配置
- 敵と戦闘背景の視認性
- UI余白
- 文字サイズ
- 会話テンポ
- 戦闘テンポ

## 13. 不具合優先度
### P0
起動不可、セーブ破損、進行不能、無限ループ。

### P1
主要機能が使えない、オープニング遷移・ボス・戦闘・マップ遷移が壊れる。

### P2
表示崩れ、軽微なイベント誤動作、バランス問題。

### P3
装飾、微調整、表現改善。

## 14. 完了
`DEFINITION_OF_DONE.md` の基準を満たすまでDONEにしない。
