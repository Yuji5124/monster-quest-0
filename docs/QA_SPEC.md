# モンスタークエスト0 QA仕様

最終更新: 2026-09-12 JST

## 1. 目的
Claude Code / Codex / Phaser Game Agentが同じ品質基準で確認する。

## 2. 毎回の最低回帰
- 起動
- タイトル
- はじめから
- 約5秒の導入異常
- **No.01「はじまりのばしょ」夜版**
- 主人公歩行
- **No.02「はじまりのまち」**
- NPC会話
- フィールド移動
- 戦闘開始 / 終了
- メニュー
- セーブ / ロード

未実装部分は除外してよいが、既存部分を壊していないか確認する。

## 3. オープニング
- 導入異常は短い制御演出
- 本当のエラー / フリーズなし
- No.01夜版へ確実に遷移
- 最新男性主人公
- 旧女性 `hero_walk.png` 不使用
- 焚き火付近開始
- 操作開始が遅すぎない
- 直接メタ会話なし
- 開始直後の偽セーブ消失なし
- 夜→昼 / No.02導線正常
- BGM / 環境音 / 無音切替正常

## 4. マップ
- 正式No.01〜No.20を使用
- 壁抜けなし
- 出入口正常
- 閉じ込めなし
- NPC操作正常
- イベント二重発火なし
- Foreground正常
- 再入場状態正常
- No.01初回 / 昼 / 「もういちど」再訪を混同しない
- No.02内部マップの親子transfer正常

## 5. NPC / イベント
- 基本会話表示
- 進行による変化
- 一度きりイベント再発火防止
- 宝箱状態
- 仲間二重加入防止
- タッチ連打による重複なし
- 序盤NPCがジャンカード秘密を漏らさない

## 6. 戦闘
- たたかう
- まほう
- どうぐ
- にげる
- 敵行動
- HP / MP
- 戦闘不能
- 通常全滅
- 勝利
- EXP / レベルアップ
- だいヒット

## 7. オロチゾンビ / 「もういちど」
- オロチゾンビは裏ボスとして扱われる
- 1回目が通常Game Overへ落ちない
- 異常演出が実エラーを起こさない
- フーフー演出後に偽リセットへ進む
- 実セーブ / カードが残る
- 「もういちど」が表示される
- 「もういちど」はNew Gameではない
- 選択後に**No.01**へ戻る
- 主人公・タロサ・ミレイの記憶保持がイベント上成立する
- わたべ加入 / 特殊参加が一度だけ起きる
- No.20再戦へ進める
- 再戦後に真エンディングへ進める

## 8. セーブ
確認対象:
- version
- マップ / 座標
- パーティ
- レベル / HP / MP
- 所持品 / 装備 / 所持金
- ストーリーフラグ
- 宝箱
- ボス
- NPC進行
- ジャンカード
- 「もういちど」状態
- No.01再訪
- わたべ最終参加
- オロチゾンビ再戦

偽データ消失演出後も実データが残ること。

## 9. ジャンカード
- 1回20円
- No.順固定排出
- ランダムではない
- ダブりなし
- 45枚取得後の挙動
- 所持金不足
- 図鑑反映
- セーブ / ロード
- 「もういちど」後も取得状態保持

## 10. iPhone Safari
- 起動
- 導入異常から正常復帰
- No.01タッチ移動
- 決定 / キャンセル
- 会話送り
- 戦闘コマンド
- メニュー
- Safe Area
- 回転 / リサイズ
- 音声開始
- 長押し / ダブルタップ誤操作が致命的でない
- 「もういちど」演出後も操作復帰

## 11. パフォーマンス
- 長時間プレイで極端に重くならない
- Scene移動でListener / Timer / BGM増殖なし
- 導入 / 終盤Effectが終了後に残留しない
- 戦闘反復でオブジェクト残留なし
- 高品質背景で操作が重くならない

## 12. 真エンディング
- 主人公 + わたべが元世界へ戻る
- ミレイとの別れが進行する
- 冒頭5秒と対応する元世界画面が正常表示される
- 主人公操作権が意図通り外れる
- 別の勇者が主人公へ話しかけられる
- 主人公がNPCとして台詞を返す
- 最後に操作不能のまま進行不能バグに見えない終了処理がある

## 13. Visual QA
人間が確認:
- 始まりの夜
- 焚き火
- 夜→昼
- No.01再訪時の初回との差
- 主人公の見やすさ
- マップ自然さ
- NPC配置
- 戦闘背景視認性
- UI余白
- 会話 / 戦闘 / 終盤演出テンポ

## 14. 不具合優先度
### P0
起動不可、実セーブ破損、進行不能、無限ループ。

### P1
オープニング、戦闘、マップ遷移、「もういちど」、再戦、真エンディング等の主要機能が壊れる。

### P2
表示崩れ、軽微なイベント誤動作、バランス問題。

### P3
装飾、微調整、表現改善。
