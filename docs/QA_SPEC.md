# Monster Quest 0 QA仕様

更新日: 2026-09-09

## 1. 目的
Claude Code / Phaser Game Agentで実装した機能を、Codexを中心に節目ごとに検証する。

## 2. 毎回確認する基本項目
- 起動できる
- タイトルからゲーム開始できる
- 主人公を移動できる
- 決定 / キャンセル / メニューが動く
- NPC会話から復帰できる
- マップ遷移できる
- 戦闘開始 / 終了できる
- 戦闘後にフィールドへ戻れる
- ゲームオーバー / 全滅処理で進行不能にならない
- セーブ / ロードが成立する

## 3. 戦闘QA
- 通常攻撃
- 魔法
- アイテム
- 逃走
- MP消費
- 戦闘不能
- 復活
- 経験値
- レベルアップ
- 敵撃破
- ボス撃破
- イベント戦の特殊処理

数値だけでなく、テンポ・入力待ち・連打による二重処理も確認する。

## 4. マップQA
- Collision抜け
- 壁抜け
- 水面 / 崖への侵入
- 出入口
- ワープ先座標
- NPCとの重なり
- 宝箱二重取得
- イベント二重発火
- 前景レイヤー表示
- 木や屋根の後ろを通る表現

## 5. セーブQA
- 新規ゲーム
- 仲間加入前後
- レベルアップ前後
- 装備変更後
- 重要アイテム取得後
- ボス撃破後
- ジャンカード取得後
- Safari再読み込み後
- 古いversionのセーブが存在する場合

## 6. モバイルQA
主要対象：iPhone Safari

確認：
- 画面内に全UIが収まる
- Safe Area
- タップ判定
- 長押し / 連打
- スクロール誤作動
- ピンチズーム誤作動
- 画面回転
- バックグラウンド復帰
- BGM再開
- 音声二重再生
- 長時間プレイ

## 7. パフォーマンス
- マップ移動を繰り返してメモリが増え続けない
- 戦闘を繰り返してSprite / Particleが残留しない
- BGM / SEインスタンスが増殖しない
- 高解像度背景を不要に常駐させない
- 主要場面で操作感を損なうフレーム低下がない

## 8. ビジュアルQA
人間の20%視覚調整で確認する。
- タイル継ぎ目
- 不自然な直線
- 装飾密度
- キャラクターと背景の視認性
- モンスターサイズ
- UI余白
- 文字切れ
- 背景と戦闘UIの干渉

## 9. 回帰テスト
基本システム修正後は、修正箇所だけでなく最低限以下を再確認する。
- 開始
- 町
- フィールド
- 戦闘
- ダンジョン
- ボス
- セーブ / ロード

## 10. バグ修正ルール
- 症状だけを隠す修正より原因を優先する
- ただし完成を遅らせる大規模リファクタリングは避ける
- 修正で仕様変更が発生した場合は関連Markdownも更新する
- ネタバレをIssue名や公開ログへ不用意に書かない
