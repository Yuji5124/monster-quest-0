# モンスタークエスト0 NPC会話 正本

最終更新: 2026-09-24 JST  
優先参照: `PLAY_ORDER_SPEC.md` / `STORY_FLOW.md` / `NPC_SPEC.md`

このファイルは、町・村・城・ほこらに配置するNPC会話の現行正本。
旧大人数版・旧縮小版の会話案は参考素材へ降格し、実装時は本書を優先する。

---

## 0. 全体ルール

- 町・村内部の縮小後サイズを前提に、NPC数を必要最小限へ整理する。
- **同じ重要情報を複数NPCが繰り返さない。**
- 1人につき主題は原則1つ。
- 生活NPCを必ず置き、全員を攻略ヒント役にしない。
- 主人公たちは無名の旅人として扱い、町中から勇者扱いされない。
- タロサを詳しく話すNPCはザボンでも少数に限定する。
- ミレイの正体は確定開示イベントまでNPCが断定しない。
- ジャンカードは通常本編では独立サブゲームとして扱い、秘密・暗号・終盤解法をNPCが早出ししない。
- 世界異常の会話は序盤では少数。終盤に近づくほど認識者を増やす。
- 重要NPCのみイベント前後で会話を変更する。
- 台詞はFC〜初期SFC風に短くする。
- 未確定設定をNPCに説明させない。
